自动 ROS 2 命名空间生成#

学习目标#

在本教程中，我们将：

  • 学习如何配置 Isaac Sim 资产，以便为每个 ROS 2 OmniGraph 节点自动生成 ROS 2 命名空间

入门指南#

先决条件

  • 已完成 ROS 2 安装，确保 ROS 2 可用且 ROS 2 扩展已启用。

  • 阅读有关 ROS 2 命名空间 的内容。

ROS 2 命名空间#

在 ROS 2 中管理命名空间对于多机器人仿真至关重要，这能确保每个机器人的话题（topic）具有唯一可识别性。

目前在 OmniGraph 中，有两种主要方法可以为 ROS 发布者（publisher）、订阅者（subscriber）和服务（service）设置命名空间。

  1. 在 nodeNamespace 字段中手动设置命名空间。

  2. （推荐）配置资产以自动为所有 Isaac Sim ROS OmniGraph 节点生成命名空间。本教程将指导您完成在 Isaac Sim 中设置命名空间的过程，从而实现高效的话题管理并避免冲突。

配置资产#

设置基础资产#

  1. 打开一个新的 Stage。打开 Script Editor (Window > Script Editor)，然后添加并运行以下代码片段。这将创建一组 XForms，其排列方式模拟机器人的关节结构。

    # Import necessary modules
from pxr import UsdGeom
import omni.usd

# Retrieve the current stage
stage = omni.usd.get_context().get_stage()

# Ensure a stage is loaded
if not stage:
    print("No stage is currently loaded. Please load a stage and try again.")
else:
    # Create the mock_robot Xform as the root
    mock_robot = UsdGeom.Xform.Define(stage, "/mock_robot")

    # Create the base_link Xform under mock_robot
    base_link = UsdGeom.Xform.Define(stage, "/mock_robot/base_link")

    # Create lidar_link and position it 0.4 meters above the base_link (Z-axis)
    lidar_link = UsdGeom.Xform.Define(stage, "/mock_robot/base_link/lidar_link")
    lidar_link.AddTranslateOp().Set(value=(0, 0, 0.4))  # Offset along Z-axis

    # Create camera_link and position it 0.2 meters above the base_link (Z-axis)
    camera_link = UsdGeom.Xform.Define(stage, "/mock_robot/base_link/camera_link")
    camera_link.AddTranslateOp().Set(value=(0, 0, 0.2))  # Offset along Z-axis

    # Create wheel_left and wheel_right Xforms under base_link
    wheel_left = UsdGeom.Xform.Define(stage, "/mock_robot/base_link/wheel_left")
    wheel_right = UsdGeom.Xform.Define(stage, "/mock_robot/base_link/wheel_right")

    # Position wheel_left 0.2 meters to the left of the center (X-axis)
    wheel_left.AddTranslateOp().Set(value=(-0.2, 0, 0))

    # Position wheel_right 0.2 meters to the right of the center (X-axis)
    wheel_right.AddTranslateOp().Set(value=(0.2, 0, 0))

  2. 通过导航至 Create > Sensors > RTX Lidar > NVIDIA > Example Rotary 2D 添加一个 2D RTX Lidar 传感器，并将其拖拽到 /mock_robot/base_link/lidar_link 下。

  3. 通过导航至 Create > Sensors > Camera and Depth Sensors > LeopardImaging > Hawk 添加一个 Hawk 立体相机系统，并将其拖拽到 /mock_robot/base_link/camera_link 下。新创建的 prim 将被命名为 hawk_v1_1_nominal；请将其重命名为 Hawk（在 Stage 面板中右键单击该 prim 并选择 Rename），以便后续步骤中的 prim 路径保持一致。

  4. 通过导航至 Tools > Robotics > ROS 2 OmniGraphs > Generic Publisher 创建一个 Generic Publisher。将 Generic Publisher Graph 设置为 Publish String，并将 Graph Path 设置为 /mock_robot/base_link/wheel_left/String_graph。然后单击 OK。

  5. 通过导航至 Tools > Robotics > ROS 2 OmniGraphs > TF Publisher 创建一个 TF Publisher。将 Target Prim 设置为 /mock_robot，并将 Graph Path 设置为 /mock_robot/base_link/wheel_left/TF_graph。然后单击 OK。

  6. 通过转到 Tools > Robotics > ROS 2 OmniGraphs > Camera 来创建 Camera Publisher。将 Camera Prim 设置为 /mock_robot/base_link/camera_link/Hawk/left/camera_left，将 Graph Path 设置为 /mock_robot/base_link/camera_link/Hawk/Camera_Left_Graph。取消选中 Depth 主题，然后单击 OK。

  7. 通过转到 Tools > Robotics > ROS 2 OmniGraphs > Camera 来创建第二个 Camera Publisher。将 Camera Prim 设置为 /mock_robot/base_link/camera_link/Hawk/right/camera_right，将 Graph Path 设置为 /mock_robot/base_link/camera_link/Hawk/Camera_Right_Graph。取消选中 Depth 主题，然后单击 OK。

  8. 通过转到 Tools > Robotics > ROS 2 OmniGraphs > RTX Lidar 来创建 2D RTX Lidar Publisher。将 Lidar Prim 设置为 /mock_robot/base_link/lidar_link/Example_Rotary_2D，将 Graph Path 设置为 /mock_robot/base_link/lidar_link/Lidar_Graph。确保仅启用 Laser Scan，然后单击 OK。

配置命名空间属性#

现在基础资产已设置完毕，必须为每个需要命名空间值的 prim 添加一个 isaac:namespace 属性。命名空间将通过将从 prim 层级顶部向下到每个 ROS publisher 设置的每个 isaac:namespace 属性值追加生成。命名空间生成行为取决于 ROS publisher 的类型及其在 stage 中的位置。

ROS 2 TF OmniGraph Nodes：生成的命名空间将仅包含设置了命名空间属性的顶层 prim 的命名空间值。这是因为从一个机器人内部发布的所有 TF 都仅位于该特定机器人的命名空间下（即 robot1/tf）。

ROS 2 Camera & Lidar OmniGraph Helper Nodes：Camera 或 Lidar 渲染产品路径用于确定命名空间搜索算法所采用的路径，并相应地追加命名空间值。因此，在这种情况下，Camera/Lidar Helper 节点的位置并不重要，而是使用 Camera/Lidar 传感器 prim 的位置。

所有其他 OmniGraph 节点：OmniGraph 节点的路径用于确定命名空间搜索算法所采用的路径，并相应地追加命名空间值。在这种情况下，这些 OmniGraph 节点的位置是相关的。

添加 isaac:namespace Prim 属性#

若要向 prim 添加 isaac:namespace 属性，请按照以下步骤操作：

  1. 选择该 prim，并在属性窗口中单击 Add。在弹出菜单中，转到 Isaac > Namespace。这会将该属性应用于该 prim。

  2. 在属性面板中，在 Namespace 字段中添加您的命名空间值。

测试 isaac:namespace Prim 属性#

将 isaac:namespace 属性应用于以下 prims。在本教程中，将每个命名空间值设置为 prim 名称（尽管您可以尝试任何自定义命名空间值）：

  • /mock_robot/base_link/lidar_link

  • /mock_robot/base_link/camera_link

  • /mock_robot/base_link/camera_link/Hawk

  • /mock_robot/base_link/camera_link/Hawk/left

  • /mock_robot/base_link/camera_link/Hawk/right

  • /mock_robot/base_link/wheel_left

  1. 单击 Play 并启动仿真。

  2. 打开一个 ROS 源终端并输入 ros2 topic list，验证您至少观察到以下主题：

    • /camera_link/Hawk/left/camera_info

    • /camera_link/Hawk/left/rgb

    • /camera_link/Hawk/right/camera_info

    • /camera_link/Hawk/right/rgb

    • /lidar_link/laser_scan

    • /wheel_left/tf

    • /wheel_left/topic

    从上述列表中，您可以观察到自动生成的主题。如果您的命名空间需要自定义命名方案，可以为每个 ROS OmniGraph 节点填写 nodeNamespace 输入字段。

  3. 停止仿真。选择 /mock_robot prim 并为其添加 isaac:namespace 属性。然后，将 namespace 值设置为 prim 名称。

  4. 通过选择、右键单击并按 Duplicate 来复制 /mock_robot prim。对于新生成的 /mock_robot_01，选择该 prim，转到属性面板，并将 isaac:namespace 属性更改为 mock_robot_01。

  5. 单击 Play 并启动仿真。

  6. 打开一个 ROS 源终端并输入 ros2 topic list。验证您至少观察到以下主题：

    来自 mock_robot 的主题

    • /mock_robot/camera_link/Hawk/left/camera_info

    • /mock_robot/camera_link/Hawk/left/rgb

    • /mock_robot/camera_link/Hawk/right/camera_info

    • /mock_robot/camera_link/Hawk/right/rgb

    • /mock_robot/lidar_link/laser_scan

    • /mock_robot/tf

    • /mock_robot/wheel_left/topic

    来自 mock_robot_01 的主题

    • /mock_robot_01/camera_link/Hawk/left/camera_info

    • /mock_robot_01/camera_link/Hawk/left/rgb

    • /mock_robot_01/camera_link/Hawk/right/camera_info

    • /mock_robot_01/camera_link/Hawk/right/rgb

    • /mock_robot_01/lidar_link/laser_scan

    • /mock_robot_01/tf

    • /mock_robot_01/wheel_left/topic

    重要

    从上述列表中可以看出，主题已自动生成。如果您的命名空间需要自定义命名方案，可以为每个 ROS OmniGraph 节点填写 nodeNamespace 输入字段。

总结#

本教程涵盖了：

  • 演示如何在机器人上的 prim 上设置 isaac:namespace 属性以自动生成命名空间
