ROS 2 综合应用#

学习目标#

在本示例中，您将运用其他多个 ROS 2 和 Isaac Sim 教程中介绍的概念，实现从机器人 URDF 定义到完全由 ROS 2 驱动的机器人系统的构建。

  • 将 URDF 机器人模型导入 Isaac Sim

  • 在机器人模型中整合物理和碰撞属性

  • 为模型附加物理精确的传感器

  • 使用代码或 OmniGraph 构建发布者和订阅者，将机器人连接到 ROS 2 网络

  • 集成导航栈，使机器人能够在环境中移动

本教程使用 Clearpath Robotics Dingo-D 作为机器人模型。 这是一款专为室内使用设计的差速驱动机器人。

入门指南#

先决条件

  • 已完成 ROS 2 安装，确保 ROS 2 可用且 ROS 2 扩展已启用。

  • 通过导航至 Window > Extensions，在 Extension Manager 窗口中启用 isaacsim.ros2.bridge 扩展。

  • 已克隆 IsaacSim-ros_workspaces 仓库并加载了工作空间。

警告

本教程仅支持 PhysX SDK 后端；由于这些资产使用了负缩放的网格，因此不支持 Newton。请参阅 Newton 资产兼容性。

导入 URDF#

使用 URDF Importer Extension 将机器人导入 Isaac Sim。这涉及首先生成 URDF，然后将其发布到 /robot_description 主题。

提示

有关详细的 URDF 导入和物理调整指南，请参阅 URDF 导入：Turtlebot。

生成机器人描述#

  1. 在已 source ROS 的终端中，安装 Clearpath Robotics 软件包及其他必要依赖项。

    sudo apt install ros-$ROS_DISTRO-clearpath-common ros-$ROS_DISTRO-xacro

    本教程中所有 Windows 命令均使用 PowerShell 语法。请在已 source ROS 2 工作区的 PowerShell 终端中运行这些命令。

    这些软件包已包含在您已 source 的 ROS 2 工作区中；无需额外的安装步骤。

  2. 设置一个指向 isaacsim_clearpath_nav2 包的 params 目录的便捷变量。所有生成的文件都将存储在此处。任何 Clearpath 机器人配置均可使用；本教程使用 Dingo-D（dd100）。

    export ROBOT_PARAMS=$(ros2 pkg prefix isaacsim_clearpath_nav2)/share/isaacsim_clearpath_nav2/params/dd100

    $env:ROBOT_PARAMS = "$(ros2 pkg prefix isaacsim_clearpath_nav2)\share\isaacsim_clearpath_nav2\params\dd100"

  3. 将示例 Dingo-D 配置复制为 robot.yaml。

    cp $(ros2 pkg prefix clearpath_config)/share/clearpath_config/sample/dd100_default.yaml $ROBOT_PARAMS/robot.yaml

    Copy-Item "$(ros2 pkg prefix clearpath_config)\share\clearpath_config\sample\dd100_default.yaml" `
          "$env:ROBOT_PARAMS\robot.yaml"

  4. 使用 Clearpath 生成器生成机器人描述。

    ros2 run clearpath_generator_common generate_description -s $ROBOT_PARAMS

    python "$(ros2 pkg prefix clearpath_generator_common)\lib\clearpath_generator_common\generate_description" -s $env:ROBOT_PARAMS

  5. 启动机器人描述节点，在 /robot_description 话题上发布 URDF。请保持此终端开启。

    ros2 launch clearpath_platform_description description.launch.py -- setup_path:=$ROBOT_PARAMS

    ros2 launch clearpath_platform_description description.launch.py -- setup_path:=$env:ROBOT_PARAMS
Full copy-paste command

导入到 Isaac Sim#

使用 URDF Importer Extension 直接从您在上一节中创建的正在运行的机器人描述节点导入机器人描述。

  1. 在已 source IsaacSim-ros_workspaces 构建的终端中启动 Isaac Sim。

  2. 通过导航到 Window > Extensions，在 Extension Manager 窗口中安装并启用 isaacsim.ros2.urdf 扩展。

  3. 导航到 File > Import from ROS2 URDF Node。

  4. 在 ROS 2 Node 文本框中输入 robot_state_publisher，然后单击 Find Node。如果成功，应显示“ROS package paths resolved”。

  5. 单击 Import 以导入机器人描述。

  6. 将默认 prim 重命名为 dd100。

  7. 使用 SHIFT+CTRL+S 将 stage 保存为 dd100.usd。

调整模型物理属性#

默认情况下，导入的 URDF 模型存在一些需要修正的异常。

  1. 禁用非物理关节。URDF 以及由此生成的 USD 包含一些不必要的关节。请禁用 除 front_left_wheel_joint、front_right_wheel_joint 和 rear_caster_joint 关节之外的所有关节。这可以通过在 Stage Tree 中使用 CTRL+LMB 单击每个关节，并在 Physics 下取消选中 Joint Enabled 来完成。

  2. 将 front_left_wheel_joint 和 front_right_wheel_joint 的 Damping（阻尼）更新为 10000。这使机器人能够进行速度控制。您可以在每个关节的 Property（属性）选项卡下的 Physics > Drive（物理 > 驱动）中找到 Damping。

  3. 添加更准确的摩擦系数。该机器人是差速驱动机器人，因此后万向轮应能自由滑动，而驱动轮需要良好的抓地力。

    1. 在 /dd100/Materials 下创建两个物理材质：将 CasterMaterial 的 Dynamic Friction（动态摩擦）和 Static Friction（静态摩擦）设置为 0.0，将 WheelMaterial 的两者都设置为 1.0。您可以通过点击 Create > Physics > Physics Material（创建 > 物理 > 物理材质）并选择 Rigid Body Material（刚体材质）来创建新材质。

    2. 将 CasterMaterial 分配给 rear_caster，将 WheelMaterial 分配给 front_left_wheel_link 和 front_right_wheel_link。您可以使用搜索栏找到这些 prim，然后通过 Materials on selected models（所选模型上的材质）下拉菜单应用材质。

  4. 通过点击 Create > Xform（创建 > Xform）创建一个空的 Xform，将其移动到 /dd100/Geometry/base_link/chassis_link，并将其命名为 base_link。这将在 ROS 中用于表示机器人的基础变换。

确保保存 Stage。

在 Isaac Sim 中测试 URDF#

为了验证导入结果，请构建一个简单的环境并将机器人添加到其中。

  1. 使用 CTRL+N 创建新的 Stage。

  2. 通过 Create > Environments > Flat Grid（创建 > 环境 > 平面网格）添加现有环境。

  3. 在 Content 浏览器中，将上一步创建的 USD 文件拖放到 Stage 上。

  4. 将 Transform 中的 Translate 分量归零，以将机器人放置在原点。如果不存在 Transform，请点击 Add Transforms。

作为快速测试，将两个车轮关节的 Target Velocity 设置为 100。你可以在 front_left_wheel_joint 和 front_right_wheel_joint 关节的 Property 选项卡下的 Physics > Drive 中找到 Target Velocity。

添加传感器#

为了让机器人能够感知环境，请创建几个传感器。

提示

有关详细的传感器操作指南，请参阅 ROS 2 Cameras 和 RTX Lidar Sensors。

  1. 使用 File > Open 或在 Content 浏览器中双击，打开你之前创建的机器人 USD。

  2. 将舞台保存为 dd100_with_sensors.usd。

  3. 首先添加一款常见的现成相机 RealSense D455。

    • 在 Content Browser 中，导航至 Isaac Sim > Sensors > RealSense > D455。

    • 将 rsd455.usd 拖到 Stage 面板中的 /dd100/Geometry/base_link/chassis_link 上。

    • 选择生成的 /dd100/Geometry/base_link/chassis_link/rsd455 prim。如果它没有 Transform 部分，请点击 Add Transforms。将其 Translate 分量设置为 (0.3, 0, 0.05)，以将其定位在底盘的前部。

    • 默认情况下，RealSense 是受重力影响的 Rigid Body。要将其固定到机器人上，请点击 /dd100/Geometry/base_link/chassis_link/rsd455/RSD455，并在 Property 选项卡的 Physics 下取消选中 Rigid Body Enabled。

  4. 接下来添加一个 LiDAR。

    • 通过点击 Create > Sensors > RTX Lidar > SICK > microScan3 来创建传感器。

    • 将传感器拖到 /dd100/Geometry/base_link/chassis_link 并将其重命名为 sim_lidar。

    • 将 Translate 分量设置为 (0.0, 0.0, 0.15)，以将其定位在底盘上方。

  5. 保存 Stage。

接下来，将机器人放置在一个视觉上有趣的环境中。

  1. 使用 CTRL+N 创建新的 Stage。

  2. 从 Content Browser 中拖入仓库环境，路径为 Isaac Sim > Environments > Simple_Warehouse > warehouse.usd。

  3. 将 Translate 分量归零。

  4. 将 dd100_with_sensors.usd USD 文件拖到舞台上。

  5. 将 Translate 分量设置为 (-5.0, 10.0, 0.0)，将 Orient 分量设置为 (0.0, 0.0, 135.0)。

  6. 要查看机器人视角，请点击 Window > Viewports > Viewport 2 以创建额外的视口。

  7. 在第二个视口中，点击左上角的 Perspective 并选择 Cameras > Camera_OmniVision_OV9782_Color 以更改相机。

ROS 2 集成#

  3. 由于机器人是扁平的，且只需要前进速度和偏航角，因此使用两个 Break 3-Vector 节点分别提取线速度的 X 分量和角速度的 Z 分量。

import omni.kit.app
import omni.usd
from pxr import Sdf

extension_manager.set_extension_enabled_immediate("isaacsim.core.nodes", True)
extension_manager.set_extension_enabled_immediate("isaacsim.robot.wheeled_robots", True)
extension_manager.set_extension_enabled_immediate("isaacsim.ros2.nodes", True)

ROBOT_PRIM = "/dd100"
CHASSIS_LINK = f"{ROBOT_PRIM}/Geometry/base_link/chassis_link"

        keys.CREATE_NODES: [
            ("OnPlaybackTick", "omni.graph.action.OnPlaybackTick"),
            ("Context", "isaacsim.ros2.bridge.ROS2Context"),
            ("SubscribeTwist", "isaacsim.ros2.bridge.ROS2SubscribeTwist"),

            ("BreakAngVel", "omni.graph.nodes.BreakVector3"),

            ("SubscribeTwist.outputs:angularVelocity", "BreakAngVel.inputs:tuple"),
            ("BreakAngVel.outputs:z", "DiffController.inputs:angularVelocity"),
            ("DiffController.outputs:velocityCommand", "ArtController.inputs:velocityCommand"),
            ("OnPlaybackTick.outputs:tick", "ArtController.inputs:execIn"),
            ("Context.outputs:context", "SubscribeTwist.inputs:context"),

    namespace:=dd100_0000

    ros2 launch isaacsim_clearpath_nav2 clearpath_navigation.launch.xml `
    map:=C:\path\to\dd100_warehouse_navigation.yaml `
    namespace:=dd100_0000

  3. 当 rviz 打开时，通过单击窗口顶部的 2D Pose Estimate 按钮，并在地图上机器人的当前位置处单击以放置位姿估计，从而设置机器人的初始位姿。

  4. 在 Adaptive Monte Carlo Localization (AMCL) 完成机器人定位后，使用 Nav2 Goal 按钮发送导航目标。将目标放置在通道中设备上方。

由于机器人配备了 LiDAR，且 Nav2 会在障碍物出现时主动重新计算路径，因此你可以通过环境对机器人进行交互。

总结#

在本教程中，你：

  • 使用 URDF Importer Extension 将 Clearpath Dingo-D URDF 机器人模型导入 Isaac Sim。

  • 集成了物理和碰撞属性，包括驱动轮和万向轮的关节阻尼及物理材质。

  • 在机器人模型上附加了 RealSense D455 深度相机和 SICK microScan3 LiDAR 传感器。

  • 构建了 OmniGraph 发布者和订阅者，以将机器人连接到 ROS 2 网络（关节状态、里程计、TF、激光扫描、时钟和 cmd_vel）。

  • 集成了 Nav2 导航栈，使机器人在仓库环境中自主地在两点之间移动。
