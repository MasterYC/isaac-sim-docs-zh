ROS 2 压缩图像#

学习目标#

在本教程中，您将学习如何：

  • 使用 ROS 2 bridge 从 Isaac Sim 发布 H.264 或 HEVC 压缩相机图像。

  • 在订阅端使用轻量级 ROS 2 解码器节点对压缩图像进行解码和可视化。

入门指南#

先决条件

  • 已完成 ROS 2 Cameras 教程，熟悉如何在 OmniGraph 中设置相机发布者。

  • 已完成 ROS 2 Installation：已安装 ROS 2，启用了 ROS 2 扩展，并构建或加载了本教程所需的 ROS 2 工作区。

  • 已启用 ROS 2 Bridge。

  • 安装 python3-av 包，该包提供了 isaac_compressed_image_decoder 解码器节点所需的 PyAV（Python FFmpeg 绑定）依赖项：

    sudo apt install python3-av

构建压缩图像发布者的图#

  1. 通过前往 Isaac Sim Content browser 并点击 Isaac Sim > Samples > ROS2 > Scenario > turtlebot_tutorial.usd 来打开 turtlebot 场景。

  2. 在 Stage 面板中，选择 /World/Camera_1，以便创建一个新的 Action Graph，并将其放置在它所发布的相机 prim 旁边。将图作为其直接影响的传感器的子级，可以保持资产的可组合性：当 Camera_1 被引用到另一个场景中时，发布器图会随之一起移动。

  3. 打开 Graph Editors：Window > Graph Editors > Action Graph。

  4. 点击 Action Graph 窗口中间的 New Action Graph 图标。将该图命名为 Camera_1_Graph；生成的图路径为 /World/Camera_1/Camera_1_Graph。

  5. 使用下表中的参数，按照下图所示的节点和连接构建 Action Graph：

    节点

    输入字段

    值

    Isaac Create Render Product

    cameraPrim

    /World/Camera_1

    enabled

    True

    ROS 2 Camera Helper

    type

    rgb_h264 或 rgb_hevc

    topicName

    image_raw/compressed

    frameId

    sim_camera

    按如下方式连接节点：

    • On Playback Tick Tick 输出到 Isaac Create Render Product Exec In。

    • Isaac Create Render Product Exec Out 连接到 ROS 2 Camera Helper Exec In。

    • Isaac Create Render Product Render Product 输出到 ROS 2 Camera Helper renderProductPath 输入。

    可选：如果需要特定的 ROS 2 Domain ID，请添加一个 ROS 2 Context 节点，并将其 Context 输出连接到 ROS 2 Camera Helper context 输入。

图解说明#

  • On Playback Tick：在仿真播放时产生一个 tick。

  • Isaac Create Render Product：为指定的相机 prim 创建渲染产品，该产品每帧捕获渲染数据。

  • ROS 2 Camera Helper：当 type 设置为 rgb_h264 或 rgb_hevc 时，此节点会自动激活匹配的硬件编码器流水线。编码器将 RGB 相机输出压缩为 H.264 或 HEVC 比特流，并将其作为 sensor_msgs/CompressedImage 消息发布。每条发布的消息包含一个完整的 IDR（即时解码刷新）帧，这意味着每一帧都可以独立解码，无需参考之前的帧。

验证 ROS 连接#

  1. 按 Play 以启动仿真。

  2. 可选地，使用键盘驱动 Turtlebot 移动，以观察相机视图的变化。在已加载 ROS 2 环境的终端中，运行：

    ros2 run teleop_twist_keyboard teleop_twist_keyboard

    注意

    如果未安装 teleop_twist_keyboard，请使用以下命令安装：sudo apt-get install ros-$ROS_DISTRO-teleop-twist-keyboard

  3. 在已加载 ROS 2 环境的终端中，验证压缩话题是否可用：

    ros2 topic list

    您应该在话题列表中观察到 /image_raw/compressed。

  4. 验证话题上是否正在发布数据：

    ros2 topic hz /image_raw/compressed

    您应该观察到非零的发布速率。Greenwave Monitor 已包含在 Isaac Sim ROS Workspaces 中，可以从 ROS 2 节点监控话题到达率。要使用 Greenwave Monitor 运行相同的基于墙钟时间的到达率检查：

    ros2 run greenwave_monitor greenwave_monitor --ros-args \
    -p gw_monitored_topics:='["/image_raw/compressed"]' \
    -p gw_time_check_preset:=nodetime_only

  5. 检查消息格式：

    ros2 topic echo /image_raw/compressed --no-arr

    format 字段应显示 h264 或 hevc，而 data 字段将包含压缩后的比特流。

解码压缩图像#

压缩的 H.264 或 HEVC 图像无法在 RViz2 等工具中直接查看。需要一个解码器节点将它们转换回原始的 sensor_msgs/Image 消息。isaac_compressed_image_decoder 包使用 PyAV（Python FFmpeg 绑定）提供此功能，以实现基于软件的压缩视频解码。

运行解码器节点#

  1. 在已 source 工作空间的 ROS 2 终端中，运行解码器节点：

    ros2 run isaac_compressed_image_decoder decoder_node

    默认情况下，解码器会自动发现 sensor_msgs/msg/CompressedImage 话题，并解码 format 字段为 h264 或 hevc 的消息。它还将 h265 作为 HEVC 的别名接受。以 /compressed 结尾的话题会被重新发布到对应的原始话题；例如，/image_raw/compressed 变为 /image_raw。

  2. 若要将解码限制为单个输入话题或自定义输出话题，请使用 ROS 2 参数：

    注意

    此自定义设置对于本教程是可选的。当您希望单个解码器实例仅处理特定的相机流，或者压缩话题不遵循 /compressed 后缀约定时，此设置很有用。

    ros2 run isaac_compressed_image_decoder decoder_node --ros-args -p input_topic:=/camera2/image_raw/compressed -p output_topic:=/camera2/image_raw

    如果传入的 CompressedImage.format 字段缺失，请设置 codec:=h264 或 codec:=hevc 以强制解码器进行解码。

  3. 验证解码后的图像是否正在发布：

    ros2 topic hz /image_raw

    要同时监控压缩流和解码流，请运行 Greenwave Monitor 并指定这两个话题：

    ros2 run greenwave_monitor greenwave_monitor --ros-args \
    -p gw_monitored_topics:='["/image_raw/compressed","/image_raw"]' \
    -p gw_time_check_preset:=nodetime_only

在 RViz2 中可视化#

  1. 在已 source 的 ROS 2 终端中，打开 RViz2：

    rviz2

  2. 在 Displays 面板中单击 Add，然后选择 By topic，并在 Image 显示类型下选择 /image_raw。

  3. 验证解码后的相机视图是否显示在 Image 面板中。

注意

WSL2 用户：在 Windows WSL2 上，解码后的图像可视化可能会出现卡顿或延迟。这是由于软件解码开销降低了解码图像的发布速率，加上 DDS 数据包在 WSL2 端口转发网络上的丢失所致。有关详细信息，请参阅 WSL2 FAQ 条目。

总结#

本教程涵盖了以下主题：

  • 使用 ROS 2 Camera Helper 节点中的 rgb_h264 或 rgb_hevc 类型，从 Isaac Sim 发布 H.264 或 HEVC 压缩的相机图像。

  • 使用 isaac_compressed_image_decoder ROS 2 包解码压缩图像。

  • 在 RViz2 中可视化解码后的图像。

注意

与原始图像发布相比，H.264 和 HEVC 压缩显著降低了带宽需求，使其适用于网络带宽受限的场景。

后续步骤#
