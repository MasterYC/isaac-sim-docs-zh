Gain Tuner 扩展#

Gain Tuner 用于调整所选机器人关节的驱动增益，并通过一系列测试对其进行验证。在导入新机器人或微调现有机器人的增益时使用该工具。它从负责生成增益的后端读取并编辑增益数据——包括 PhysX UsdPhysics.DriveAPI 驱动、MuJoCo (mjc:*) 执行器参数以及 Newton 执行器架构——并根据当前激活的物理引擎调整其字段、列和保存目标。

此扩展默认启用。如果它被禁用，请从 Extension Manager 中重新启用 isaacsim.robot_setup.gain_tuner 和 isaacsim.robot_setup.gain_tuner.ui。要打开该工具，请前往 Tools > Robotics > Asset Editors > Gain Tuner。舞台上应用了 Robot Schema 的机器人会自动出现在窗口标题栏的 Robot 下拉列表中。如果选定的机器人没有应用 Robot Schema，面板将显示一个 ADD ROBOT SCHEMA 按钮，用于就地应用该架构。

该窗口包含两个选项卡：Gain Settings（增益设置），用于检查和编辑每个关节的增益；以及 Test Gains（测试增益），用于配置和运行验证测试并查看其结果。标题栏中有一个只读的 Backend（后端）和 Solver（求解器）标签，标明了当前激活的物理引擎和求解器；Gain Tuner 会报告这些信息，但不会更改它们。

有关使用 UR10 机械臂的实操指南，请参阅 Tutorial 11: Tuning Joint Drive Gains 教程。

概述#

Gain Tuner 的目的是为每个机器人关节找到驱动增益，以便机器人能够根据预期行为跟随指令轨迹。

Gain Tuner 提供了一个用于手动编辑增益的表格，以及一套用于评估增益质量的测试。

  • Gain Settings：一个连续的表格，将每个可调关节列为一行。您可以直接在表格中编辑刚度（stiffness）和阻尼（damping）（或 Kp/Kd/Ki，具体取决于关节的后端），多选行以同时编辑多个关节，并打开每个关节的详细信息面板以调整高级参数。请参阅 The Gain Settings Page。

  • Test Gains：用于评估关节行为的一组测试：

    • Snap to Limits — 命令关节运动至其下限和上限，以验证其能否达到完整的运动范围。

    • Sinusoidal — 使用连续的正弦轨迹驱动关节。

    • Step Function — 使用阶跃函数轨迹驱动关节。

    • Stress — 使用极端的随机命令驱动关节，以暴露强化学习训练期间可能出现的稳定性问题。

    • dt Sweep — 在一系列物理时间步长下运行每个关节的阶跃响应，以表征随着时间步长增加，其位置控制精度如何下降。

  • Test Results：包含每个关节和所有关节的结果表格，以及场景级别的判定横幅，位于跟踪的关节位置（以及当活动后端报告测量到的关节力时的关节力矩）与命令轨迹对比的图表上方。

理解 Joint Drives#

Joint Drives 是用于将关节设置为给定目标的双比例控制器。一个比例增益用于调节位置误差，另一个增益用于调节速度误差。出于历史原因，这些增益分别被称为 Stiffness（刚度）和 Damping（阻尼）。

注意

这些 Joint drive 是隐式的——这意味着位置和速度约束由 drive 根据当前时间步施加。在工程中，这通常通过闭环控制来实现，即读取上一时间步的位置和速度读数，并据此进行未来的控制响应。请参阅 Articulation Joint Drives。

Stiffness（刚度）类似于弹簧刚度常数乘以位置误差，就好像弹簧被拉伸了该量一样。Damping（阻尼）源于将目标速度设为零的效果，因此任何运动都会产生试图阻止该运动的反作用力。实际上，您可以让它跟踪一个非零速度，其效果与刚度在位置上的作用相同。

\[\tau = \text{stiffness} * (q - q_{\text{target}}) + \text{damping} * (\dot{q} - \dot{q}_{\text{target}})\]

其中 \(q\) 和 \(\dot{q}\) 分别为关节位置和速度。当 \(\dot{q}_{target} = 0\) 时，系统简化为对关节位置的传统 PD 控制器。

此公式适用于旋转关节（revolute joints）和平移关节（prismatic joints）。

关节最大力（joint max force）将作为 \(\tau\) 的钳制值，最后，drive 类型将决定该力矩或力是直接作为扭矩或力施加，还是转换为施加于连接到该关节的刚体上的加速度。Acceleration drive 会根据关节的质量进行归一化，因此不受机器人配置的影响，并表现为理想执行器。

驱动模式#

该双比例控制器提供了两种控制机器人的主要方式：

  • 位置目标 - 用于受控关节，通过定义连接体应达到的目标距离/角度来驱动。

  • 速度目标 - 通常用于车轮或其他自由旋转物体。

若要实现位置控制关节：将 Stiffness 设置为大于零的值，Damping 可设为任意值。 若要实现速度控制关节：将 Stiffness 设置为零，Damping 设置为大于零的任意值。

增益设置页面#

Gain Settings 选项卡包含一个可折叠的 Gains Settings 部分：这是一个连续的表格，左侧为关节列表，下方为每个关节的详细信息面板。每个可调关节显示为一行，包含索引、关节名称以及增益和高级列。Mimic 关节由约束驱动而非独立可调，因此不会作为行显示。

在表格中编辑增益#

  • 直接编辑。 在表格单元格中输入新值以编辑关节的增益。

  • 多选批量编辑。 使用 Ctrl-click（切换行选择）或 Shift-click（选择范围）选择多行，然后编辑增益单元格，即可将该列中所有选中的、可编辑的关节一次性应用新值。只读和不适用单元格将被跳过。若仅选中单行，则编辑仅应用于该关节。

  • 搜索。搜索字段可按关节名称筛选行。

动态列#

显示的列会根据所选机器人自适应调整，而非遵循固定目录：

  • 刚度 / 阻尼（对于 Newton 执行器标记为 Kp / Kd）始终存在，当关节使用 PID Newton 执行器时，会出现 Ki 列。

  • 高级列（Armature、Max Force、Max Joint Velocity、Joint Friction）会在至少一个显示的关节在这些列中有值可显示时自动出现，并在没有值时隐藏。Armature 和 Joint Friction 会从携带任一底层关节 schema 的关节中解析出值，因为当前引擎自身的默认值会替代未编写的参数，并标记为 (default)。Max Joint Velocity 仅在显示的关节编写了有限限制时出现，因为未受限的关节读取 unlimited 而非数值，而 Max Force 仅对编写了显式驱动力量限制的关节出现。没有内容可显示的单元格渲染为 - 且不可编辑。参见 高级执行器参数。

  • 单位显示在刚度和阻尼列标题中，以及每个单元格的工具提示中。在 PhysX 下，旋转（角度）关节以度为单位读取，在 Newton 后端下以弧度为单位读取；棱柱关节使用 stage 的线性单位。混合角度/线性选择标记为 mixed。

  • 工具栏上的汉堡菜单列选择器用于选择显示的列。它根据加载的关节树动态生成，仅列出适用于当前显示关节的类别和列，因此纯 UsdPhysics.DriveAPI 资产不会显示 MuJoCo 或 Ki 条目。每列均从模式驱动的默认值开始；切换复选框可强制开启或关闭该列。

注意

如果表中未显示所有可用列，请加宽 Gain Tuner 面板或 Isaac Sim 应用程序窗口，或从汉堡菜单选择器中启用该列。当窗口过窄时，某些列会被隐藏。

关节详情面板#

选择单行会聚焦该关节，并在表格下方构建一个紧凑的详情编辑器。它包含 Controller Gains 表单（根据关节的活动增益源进行标注和单位注释）、高级执行器参数 中描述的可折叠 Advanced Actuator Parameters 部分，以及验证摘要。详情面板仅在单选时出现。

当关节定义了多个增益源时，详情面板会显示每个关节的 Source 切换开关，表格中也会显示对应的 Source 列；两者保持同步。该切换开关允许您查看每个定义增益的后端（PhysicsDriveAPI / MuJoCo-native / Newton Actuator）的增益，活动源会标记为 (Active)。切换源仅用于查看和比较视图——只有活动源是可编辑的。

物理后端与增益源#

增益调节器支持在同一机器人上使用多个物理后端和多个增益源。它会自动检测这些配置，并根据当前激活的状态动态调整其字段、列、可编辑性以及保存目标。

物理后端与求解器#

增益调节器会检测 Isaac Sim 当前激活的物理引擎和求解器，并在窗口标题栏中以只读的 Backend 和 Solver 标签显示：

  • PhysX — 经典后端。它没有单独命名的求解器，因此标签显示为 PhysX。

  • Newton 搭配 MuJoCo 求解器 — 即运行 MuJoCo 求解器的 Newton 后端，在 Backend 标签中显示为 Newton，在 Solver 标签中显示为 MuJoCo。

增益调节器仅报告后端和求解器信息，绝不会更改它们。它会读取每个后端所定义的增益，并动态重新标记增益参数以匹配当前激活的源 — 对于 PhysX DriveAPI 驱动显示为 Stiffness / Damping，而对于 Newton 执行器显示为 Kp / Kd（以及 Ki）。如果在增益调节器打开时切换物理后端或 Newton 求解器，它会重新检测变化，更新 Backend/Solver 标签，并重建 Gain Settings 视图，以确保参数标签以及可编辑与只读状态对于新激活的后端保持正确。

关节上的增益源#

单个关节可能包含多个增益源。Gain Tuner 会读取所有增益源，并允许您为每个关节选择其中一个作为活动源：

  • PhysX ``UsdPhysics.DriveAPI`` — 标准的刚度/阻尼驱动增益，除非由 Newton 执行器驱动关节，否则由当前活动的物理后端使用。

  • MuJoCo (``mjc:*``) — 资产上携带的 MuJoCo 原生执行器参数，用于仿真到仿真（sim-to-sim）工作。

  • Newton 执行器架构 — 一个 NewtonActuator prim，应用 NewtonPDControlAPI 或 NewtonPIDControlAPI 并带有 newton:kp / newton:kd / newton:ki，链接到其驱动的单个自由度（DOF）。

当关节定义了多个源时，表格会显示 Source 列，详情面板也会显示对应的每个关节的 Source 选择器；两者保持同步。选择一个源会显示该后端的增益，其中活动源会标记为 (Active)：

  • 哪个源是活动的。 Newton 执行器与后端无关：当它驱动关节时，无论选择哪个后端，其 Kp/Kd/Ki 都是活动源。MuJoCo (mjc:*) 增益仅在运行 Newton MuJoCo 求解器且没有 Newton 执行器驱动关节时才是活动源；否则，PhysX DriveAPI 驱动是活动源。

  • 可编辑与只读。 仅活动源可编辑和测试。其他源以只读形式显示，供检查和比较——特别是，mjc:* 增益仅在 Newton MuJoCo 求解器下可编辑和测试，否则为只读。

  • 测试路由。测试命令始终路由到活动源：位置/速度目标通过当前对该关节生效的 DriveAPI、MuJoCo 求解器或 Newton 执行器来驱动关节。

对于可编辑的 PhysX DriveAPI 增益，详情编辑器还提供自然频率调节模式。请参阅 调节增益。

高级执行器参数#

关节详情面板的 高级执行器参数 部分显示了除驱动增益之外的每个关节的设置：电枢惯量 (Armature)、最大驱动力、最大关节速度 和 关节摩擦。对于由 Newton 执行器驱动的关节，该部分以只读方式显示该执行器的控制范围、力限制、饱和值和抗积分饱和值。该部分不显示驱动类型。增益调节器仅读取驱动类型以在增益和自然频率之间进行转换；若要更改驱动类型，请在 属性 面板中编辑关节的 UsdPhysics.DriveAPI 驱动。

电枢惯量 (Armature)、最大关节速度和关节摩擦是按后端在运行引擎所消费的关节架构上编写的：

  • 在 Newton 下，面板读取和写入 newton:armature、newton:velocityLimit 和 newton:friction。

  • 在 PhysX 下，它读取和写入 physxJoint:armature、physxJoint:maxJointVelocity 和 physxJoint:jointFriction。

在编辑时，只会写入当前激活后端的架构，而不会修改另一个后端的值。两个不同的值是有意为之的编辑选择，而非错误：这两种公式需要分别进行调优，而且 PhysX 的无量纲 jointFriction 系数根本无法转换为牛顿的与负载无关的 newton:friction 力矩。当两者不一致时，字段下方的行会分别列出每个后端的值、当前生效的值，以及编辑操作将写入哪个架构。相同的文本也作为对应表格单元格的工具提示提供。

在 PhysX 下没有链式回退机制：仅读取 physxJoint:*。在牛顿下，生效的值是运行中的求解器按顺序解析时遇到的第一个已编辑的值——首先是 newton:*，然后在 MuJoCo 求解器下是 mjc:*，最后是 physxJoint:*。因此，如果某个关节仅编辑了 PhysX 部分的值，则在您编辑该字段之前，模拟将基于该值进行，而编辑操作会将值移至 newton:*。牛顿自身的解析器带来了两个例外：关节摩擦力没有 physxJoint:* 回退机制，因此仅在 PhysX 下编辑的摩擦力值在牛顿下不会被任何机制模拟，并且 mjc:* 从不参与速度限制的解析。当已编辑的值与当前生效的值不同时，面板会显示一个当前激活后端从不读取的已编辑值。面板读取 mjc:* 用于报告，但从不写入它。

由于 newton:* 在每个求解器中都处于首位，因此在该处编辑的值无论运行哪个求解器都会生效。只有当该层级没有任何编辑值时，结果才取决于求解器，因此如果一个关节的 mjc:* 和 physxJoint:* 部分不一致，则在 Solver 标签指定求解器之前，其显示为空白，并且面板会提示无法确定该值，而不是猜测一个值。

引擎默认值#

没有 schema 作者设置过值的参数在仿真中仍具有值，因此该字段显示引擎自身的默认值，呈灰色并标记为 (default)，而非无人选择的零值。在 Newton 下，Armature 默认为 0.1，在 PhysX 下默认为 0，未钳制的速度限制显示为 unlimited。当时间轴播放时，面板优先使用运行中的引擎报告的 armature 和速度限制值，而非文档中的默认值，因为该值是测量所得而非假设的。

(default) 读数表示引擎将仿真的值，而非资产中记录的意见。除非您在字段中输入值，否则不会写入 USD，且保存操作绝不会将默认值转换为已编写的值。

将值复制到另一个后端#

Copy To PhysX 和 Copy To Newton——标签名称为当前未激活的后端——将聚焦关节的值写入未激活后端的架构中，此处显示的值保持不变。Copy All To PhysX 和 Copy All To Newton 以单次可撤销编辑的方式对所有可调关节执行相同操作。两者均为选择性启用且单向操作，并且会更改另一个后端模拟的内容，因此会显示一条通知，报告写入的数据量。跳过以下两种情况：另一个后端已模拟的参数，以及显示 (default) 的参数（后者没有可传递的已授权值）。使用这些按钮为尚未授权任何内容的后端提供初始值，而不是使两个后端保持同步。

面板无法为其授权内容的后端#

这三个字段必须知道正在运行的引擎读取的是哪个关节 schema。当活动引擎是 Gain Tuner 没有对应 schema 的引擎时——remotesim、一个它无法识别的引擎，或者返回空结果的引擎查询——这些字段将被禁用，该部分会说明原因，并且相应的表格列会被隐藏。如果抱着引擎可能会读取它的侥幸心理写入 physxJoint:*，就会写入一个没有任何东西消费的值，这看起来与成功编辑完全相同。在此状态下，Backend 标签显示引擎自身的名称，或者在完全无法读取引擎时显示 unknown。驱动增益、测试和图表不受影响。

注意

Newton 在模拟开始时从 stage 中一次性读取 armature、joint friction 和 velocity limit，因此在时间轴播放期间进行的编辑不会传递到正在运行的求解器。请停止并重新播放以应用更改——当 Newton 正在播放时，面板会提示这一点。PhysX 会在下一步中拾取此类编辑。

有关每个 schema 的调优值在保存时写入的位置，请参阅 Save Targets and Backend Mirroring。

调整增益#

Joint Gains 是一对 Stiffness 和 Damping 值，用于驱动关节。它们以驱动的形式应用于关节，该驱动根据期望位置与速度（或两者）之间的误差，向关节施加力/力矩（Effort）。该 Effort 的计算公式如下：

\[Effort = K_p * (Position_{Desired} - Position_{Current}) + K_d * (Velocity_{Desired} - Velocity_{Current})\]

其中 \(K_p\) 是 Stiffness，\(K_d\) 是 Damping。

根据此公式，可以描述关节驱动的不同模式：

  • 位置驱动：当关节驱动处于位置模式时，期望位置即为目标位置。这要求刚度大于 0，阻尼为任意值。

  • 速度驱动：当关节驱动处于速度模式时，期望位置为当前位置，期望速度为目标速度。这要求刚度为 0，阻尼为任意值。

  • 无：当关节驱动处于无模式时，关节驱动未激活。仍可通过施加直接力矩来控制关节。这要求刚度为 0，阻尼为 0。

  • 模仿：当关节驱动处于模仿模式时，关节驱动由模仿关节驱动。这意味着关节驱动将不处于激活状态，但仍可通过 Tuner 配置模仿关节的固有频率和阻尼比属性。

阻尼-弹簧模型也可以用固有频率和阻尼比来描述：

\[ \begin{align}\begin{aligned}\omega_n = \sqrt{\frac{K_p}{m}}\\\zeta = \frac{K_d}{2 m \omega_n}\end{aligned}\end{align} \]

其中 \(\omega_n\) 是固有频率，\(\zeta\) 是阻尼比，\(m\) 是基于关节两侧机器人质量计算出的关节惯量。阻尼比的含义如下：\(\zeta = 1.0\) 为临界阻尼系统，\(\zeta < 1.0\) 为欠阻尼，\(\zeta > 1.0\) 为过阻尼。

从上述公式可以看出，有两种方法可以调整 PhysX DriveAPI 增益：

  • Stiffness / Damping — 直接在表格或详情面板的 Controller Gains 表单中编辑刚度和阻尼值。

  • Natural Frequency / Damping Ratio — Gain Tuner 根据目标固有频率 (Hz) 和无量纲阻尼比，结合关节的有效惯量和驱动类型，自动计算刚度和阻尼。

注意

由于机器人是由多个连杆和运动关节组成的结构，每个关节的固有频率取决于机器人的配置。为了建立标准，使用机器人处于初始配置时的固有频率。

调优模式#

对于具有可编辑 PhysX DriveAPI 增益的关节，详情面板的 Controller Gains 表单中有一个切换开关，可在 Stiffness / Damping 和 Natural Frequency / Damping Ratio 之间切换。在固有频率模式下，两个增益字段显示目标固有频率和阻尼比；编辑内容会转换回驱动刚度和阻尼，并写入相同的 DriveAPI 属性，因此保存时这些值保持不变。固有频率模式需要关节的有效惯量，该惯量在时间轴播放后计算得出；在此之前，字段会提示您播放时间轴。对于 Newton 执行器增益、MuJoCo 原始参数和模仿关节，此切换开关是隐藏的。

固有频率模式在转换过程中使用关节的驱动类型，但不允许您更改它。有关详情面板中显示的其他每个关节的设置，请参阅 高级执行器参数。

机器人的可调自由度 (DOF) 根据机器人关节列表中定义的内容进行显示。

调优工作流#

增益调优是一个迭代过程。推荐的工作流分为两个阶段：

  1. 设置初始增益，使用以下位置或速度驱动启发式方法。

  2. 调优和评估，使用内置测试模式，每种模式针对关节行为的不同方面：

    • Snap to Limits (默认) — 命令关节移动到其下限和上限。使用此模式验证增益是否足够强以达到全运动范围，以及限位、增益和碰撞几何体是否相互一致。

    • Sinusoidal — 使用连续重复的波形驱动关节。使用此模式评估增益对平滑运动的跟踪效果，并从跟踪曲线的形状识别欠阻尼或过阻尼。

    • Step Function — 使用突然的位置变化驱动关节。使用此模式评估增益对离散命令的响应速度和准确性，这更接近于策略在训练期间发出目标的方式。

当这些测试模式下的增益参数均令人满意后，运行 Stress（压力）测试以确认其在强化学习训练中典型的极端指令下具有鲁棒性，并可选地运行 dt Sweep（时间步长扫描）以确认增益在您计划部署的物理仿真时间步长下仍能准确跟踪，然后再迁移至 Isaac Lab。

注意

具体的调优过程可能会因机器人及其控制系统的特性而异。

位置驱动#

对于机器人的每个关节：

  1. 首先将阻尼设为零，仅调优刚度。这有助于您在不受微分项影响的情况下建立稳定的响应。

  2. 增加刚度，直到关节能够收敛至目标位置附近。

  3. 将刚度降低一个数量级。

  4. 设置刚度后，添加比刚度低一个数量级的阻尼。这将成为参数的基准值，通常不会产生超调。如果您需要更快的响应，请进一步降低阻尼。

  5. 围绕此建立的基准值微调两个增益，以达到所需的性能，同时考虑稳定性、响应时间和超调等因素。

  6. 如果您想模拟包含重力补偿的控制，请选择机器人的所有刚体，并在属性面板中勾选 Disable Gravity（禁用重力）。

速度限制与工业机器人#

许多机器人（包括大多数工业机器人）的关节驱动器都配备了预先调校的 PD 控制器，并可设置为具有完美的位置控制响应，始终以给定的关节速度限制运行。要重现此行为，请将先前调校启发式方法中的关节刚度增加一倍，并在 Properties 面板中的 Joint > Advanced > Maximum Joint Velocity 下定义最大关节速度。运行仿真以验证关节速度是否符合规格，并微调刚度，直到关节最大速度限制在容差范围内。如果刚度过高，仍可能违反最大速度限制，因此不建议为关节添加无限刚度——而是使用与未设置最大关节速度时校准的数值相似的刚度进行操作。

速度驱动#

对于机器人的每个关节：

  1. 首先将 Stiffness 设置为零，仅调校阻尼。

  2. 增加阻尼，直到关节能够收敛到接近目标速度。

  3. 如果机器人可能承载额外负载，请略微增加阻尼（例如，额外增加 10%）以考虑额外负载。

  4. 您可以通过设置最大关节速度，或限制最大关节力以施加最大关节负载力矩，来限制关节的输出。

保存目标与后端镜像#

调优后的增益会写入 USD 图层，位置在关节表下方的 Save Target 行。遵循 NVIDIA Isaac Sim 的 Asset Structure，关节增益属于物理配置，因此保存在物理图层上。

  • DriveAPI 保存目标。刚度（Stiffness）和阻尼（Damping）默认保存到中性、可人工编辑的 payloads/Physics/physics.usda 图层，该图层在 Save Target 下拉列表中始终位于首位。下拉列表还会列出舞台上发现的所有其他 payloads/Physics/*.usda 图层——例如特定后端的 physx.usda 覆盖层——以便您可以将 DriveAPI 的写入操作路由到特定图层。如果您未明确选择，则使用 physics.usda。

  • 镜像到 MuJoCo（可选启用）。当 DriveAPI 为活动源时，Mirror tuned DriveAPI gains to MuJoCo 复选框控制保存操作是否同时将调优后的 Kp/Kd 写入机器人的 MuJoCo (mjc:*) 执行器参数。该选项默认关闭，因此除非您主动启用，否则保存操作绝不会触及 MuJoCo 执行器 prim，且 PhysX 和 MuJoCo 的增益可以有意不同。仅当机器人具有 MuJoCo 原生增益且 MuJoCo 求解器未激活时，才会显示该复选框；勾选后，其目标图层默认为 mujoco.usda。当 MuJoCo 求解器处于激活状态时，mjc:* 为活动源，直接对其进行编辑和保存，而不是进行镜像。

  • Newton 执行器写回。当关节由 Newton 执行器驱动时，保存操作会将调优后的增益写回执行器 prim 的 newton:kp / newton:kd / newton:ki 属性。此选项默认开启，因为执行器是关节自身的有效源；其目标图层默认为定义该执行器 prim 的图层。

  • 高级关节参数。惯量（Armature）、关节摩擦和速度限制按架构（schema）分别路由，而非写入单一图层。已编写的 newton:* 值是引擎中立的，因此它会与 DriveAPI 增益一起写入选定的 Save Target 图层（默认为 physics.usda）。已编写的 physxJoint:* 值是 PhysX 的观点（opinion），因此如果机器人具有 physx.usda 覆盖层，它将写入该覆盖层；否则，它将保留在已定义该值的图层上，而不会泄漏到中立图层。仅写入显式编写的值：保持为引擎默认值的参数绝不会写入资产。请参阅 高级执行器参数。

按 Save 将收集的编辑写入选定的图层。

测试增益#

测试增益选项卡包含两个可折叠部分，用于执行验证工作流：测试增益设置（包含运行按钮、持续时间、模式选择器、各模式选项以及逐关节测试配置表）和图表（包含结果表格和轨迹图）。测试运行期间会显示进度条。该选项卡提供了一整套测试，可让您快速评估当前增益组在不同条件下的质量。每个测试按序列划分，序列是指一起测试的一组关节。序列按关节定义，是测试运行顺序的索引。在每个序列开始前，机器人会重置到其初始配置。

所有测试对位置驱动器发送位置命令，对速度驱动器发送速度命令。在位置命令中，目标速度始终为零，以便正确评估关节阻尼。在实际控制场景中，应发送适当的轨迹命令，其中速度命令等同于指定轨迹位置的积分。由 Newton 执行器或 MuJoCo 原生主动增益驱动的关节在测试期间也会受到指令；其目标由执行器或 MuJoCo 求解器转换为运动。

测试模式共享相同的设置步骤：

  1. 在逐关节测试配置表中，为要评估的关节启用 测试 复选框。

  2. 将关节分配到序列中。同一序列中的关节同时测试；不同序列中的关节逐组测试，机器人在序列之间重置到其初始配置。将预期一起运动的关节分组。

  3. 在 Test Mode 选择器中选择所需的测试模式（Snap to Limits、Sinusoidal、Step Function、Stress 或 dt Sweep），配置其参数，然后按下 Run Test。无需先按下 Play：如果仿真尚未播放，Run Test 会自动启动时间轴。测试运行期间，该按钮将变为 Cancel Test。

重复“调整增益、重新运行、观察”这一过程，直到结果令人满意。每种测试模式都会呈现不同的信息，因此建议结合多种模式进行测试，而不是仅依赖某一种模式作为最终判定依据。

查看结果#

每种测试模式的结果都显示在 Test Gains 选项卡的顶部，位于轨迹图表上方，以便首先读取场景级结果。判定横幅位于包含所有关节的结果表格上方，该表格每个受测关节占一行，并包含一个颜色编码的 Result 单元格。在颜色选择器中选择一个关节后，下方的 Position 图表将显示该关节的逐关节轨迹。仅当当前后端报告测量到的关节力时，才会出现 Effort 图表；请参阅 Visualizing Results。

  • Snap to Limits — 判定横幅（ALL JOINTS PASSED、ALL GAINS OK - SOME JOINTS BLOCKED 或 SOME JOINTS FAILED）位于包含每个限位平均误差、最大误差和稳定时间的表格上方，并带有颜色编码的结果（绿色表示通过，琥珀色表示受阻，红色表示失败）。此处报告稳定时间是因为它对 snap-to-limits 响应具有意义。

  • Stress — 模式/种子上下文行和判定横幅（ALL JOINTS STABLE 或 INSTABILITY DETECTED）位于包含最大速度、触发时间、触发速度和结果的表格上方（绿色表示稳定，红色表示不稳定）。

  • dt Sweep — 判定横幅（例如 ALL ACCURATE AT TARGET DT 或 ACCURACY DEGRADED AT TARGET DT）位于包含目标 dt 下的稳定时间、稳态误差和精度断崖的表格上方，以及 Settle Time vs dt 和 Steady-State Error vs dt 图表。

Step Function 模式额外报告每个关节的 overshoot 指标（占阶跃幅度的百分比）。仅针对 Step Function 报告超调量，因为它是唯一命令为干净阶跃并保持的模式；Snap to Limits 报告其自身的每个限位误差和稳定时间指标，而 Sinusoidal 和 Stress 模式报告峰值/RMS 跟踪而非超调量。

吸附到限制#

评估新建或修改后的机器人的推荐起始点。该测试命令每个关节运动至其下限，保持，然后运动至其上限，保持，最后返回至 Home 位置。该测试验证所编写的关节限位、驱动增益和碰撞几何体是否全部相互一致。

每个关节接近其目标位置并等待稳定，之后保持阶段开始。如果关节在十秒内未稳定，测试仍将继续进入保持阶段。在保持阶段期间，连续采样位置误差，并在整个保持时长内报告平均误差和最大误差，从而使该指标对残余振荡具有鲁棒性。

保持阶段结束后，每个关节将被归类为以下三种情况之一：

  • Pass：在容差范围内到达两个限位。

  • Fail：未到达限位，且关节仍在运动或振荡，表明存在增益或动力学问题。

  • Blocked：未到达限位，且关节停滞，通常由自碰撞或其他物理约束引起，而非增益问题。

总测试时间可变：快速机器人能迅速稳定，测试在几秒内完成，而缓慢或弱驱动则会在每个阶段消耗完整的超时时间。

每个关节的结果包括稳定时间（分别报告下限和上限阶段）以及每个限位处的平均保持误差和最大保持误差。

压力测试#

压力测试通过向关节施加极端的随机指令，来暴露可能在强化学习训练期间出现但在常规 GUI 测试中不可见的求解器不稳定性。该测试针对当前激活的物理后端运行，因此结果表征的是该后端求解器下的增益特性，而非另一个后端下的特性。在使用许多并行环境训练策略时，探索空间很大，关节可能会在其全范围内接收快速且无约束的指令。在 GUI 中（迭代速度快且可使用机器人检查器）发现这些不稳定性，比在训练运行期间诊断它们要容易得多。

提供两种子模式：

随机游走 — 在每个物理步长中，向每个关节的当前位置目标添加一个高斯分布的增量。指令会被限制在关节限位内。这模拟了早期策略训练期间无约束的神经网络探索。标准差（sigma）以每个关节范围的百分比表示，因此范围较宽的关节会接收到按比例较大的扰动。

对抗性 — 每 N 个物理步长，所有活动关节同时被强制设定到随机选择的下限或上限（每个关节 50/50 的概率）。这通过驱动极端的相关配置来最大化最坏情况下的求解器负载，这些配置在随机游走中很少出现，旨在针对当许多并行训练环境同时将机器人推向相反极端时出现的相同故障模式。

每个关节的不稳定性检测每步运行：

  • 速度超过可配置阈值会将关节标记为 不稳定。

  • 位置或速度中出现 NaN 会将关节标记为 不稳定。

  • 如果在整个持续时间内未发生上述情况，则关节被分类为 稳定。

记录 RNG 种子，以便可以精确复现导致不稳定的运行。

  • 启用自碰撞时不稳定，禁用自碰撞时稳定：不稳定性由接触事件驱动，而非由增益驱动。不要根据此结果调整增益。相反，应检查关节限制是否允许发生自接触的配置，并相应地收紧限制或调整碰撞几何体。

  • 禁用自碰撞时不稳定：增益是潜在原因。检查记录的不稳定发生时间和触发命令。在低 sigma 下极短的不稳定发生时间表明，即使在轻微扰动下增益也处于临界状态，需要进行显著调整。在高 sigma 下较长的不稳定发生时间表明，增益在现实条件下具有鲁棒性，不稳定性仅在训练后的策略很少产生的扰动水平下才会出现。

  • 在随机游走中不稳定但在对抗模式中稳定（或反之）：两种子模式下的故障模式不同，结果有助于缩小诊断范围。随机游走中的不稳定性通常源于目标逐渐漂移进入问题区域。对抗模式中的不稳定性通常源于求解器难以处理耦合关节同时出现的极端配置。

隔离负责关节：

发现不稳定性后，使用记录的 RNG 种子精确复现运行。然后使用序列器在逐步缩小的关节子集上重新运行测试，通过二分法逼近能够复现不稳定性的最小关节集合。这可以隔离出负责的运动链部分，并且比推理整个机器人的结果要快得多。Robot Inspector 可以协助检查隔离出的子系统。

dt 扫描#

dt 扫描用于表征每个关节的位置控制精度如何随物理时间步长变化。它在最细和最粗边界之间的几何阶梯时间步长上运行单时间步长阶跃响应探测，然后将每个级别与最细 dt 参考值进行比较，以报告稳定时间退化、稳态误差以及精度悬崖——即精度仍能跟踪参考值的最粗时间步长。使用它来确认在细时间步长下通过的增益在您打算模拟的时间步长下仍表现可接受。

每个关节都会根据一个 目标 dt（即您计划发布的物理时间步长）进行分类。在扫描运行期间，进度读数会显示当前级别，例如 dt level 3/10: 120 Hz (dt=0.00833 s)。

参数分为 时间步长范围（dt Max、dt Min）、探测（步数、目标 dt、每级稳定超时、保持持续时间）和 精度阈值（稳定容差，以及在关节被标记之前允许的最大稳定时间和稳态误差退化）。每个字段都带有单位标签和解释性工具提示。在扫描运行之前会验证 dt Max / dt Min 边界：如果边界反转、相等、非正或非有限，则会拒绝并显示通知，且扫描不会启动。

结果解读： 判定结果包括 ALL ACCURATE AT TARGET DT、ACCURACY DEGRADED AT TARGET DT、JOINTS DID NOT SETTLE AT TARGET DT 或 REFERENCE DT DID NOT SETTLE (INDETERMINATE)。当关节在最细 dt 参考运行中从未稳定时，该关节为不确定状态，因此没有有效的基线来衡量退化程度。Settle Time vs dt 和 Steady-State Error vs dt 图表针对颜色选择器中选定的关节，绘制扫描得到的指标随时间步长变化的曲线。

可视化结果#

Position图表将每个被跟踪关节的测量轨迹与指令轨迹进行对比绘制。在报告测量关节力的后端（如 PhysX）上，还会显示Effort图表，并以相同方式绘制测量力。在颜色选择器中选择要显示的关节；结果按关节进行颜色编码，测量值以指令轨迹颜色的淡化版本显示。

每个图表都带有其自身的控件。绘图上方的图例行中，每个系列组有一个复选框——在 Position 图表上是 Command Joint 和 Observed Joint，在 Effort 图表上是 Effort——用于显示或隐藏该组，并为该组绘制的每个关节显示一个彩色圆点。圆点从轨迹颜色中读取，因此图例条目与其轨迹始终一致。带有输入值字段的范围滑块设置每个轴上的可见窗口，Fit Frame View 将两个轴重置为完整记录范围。水平网格线落在整数值上，当零位于可见范围内时，它始终是其中之一，并以自己的颜色高亮显示，以便您可以直接从图表上读取超调的符号和大小。

在轴控件下方，可折叠的 Value Readout 部分报告您在悬停绘图时每个可见系列的数据，每个关节一行，每个图例组一列。它默认处于关闭状态，并位于其他所有内容下方，因此打开它不会移动绘图或轴控件。如果在悬停时间没有可报告数据的关节——例如，在缩放窗口内样本过少的系列——将显示 - 而不是空白单元格。

重要

Effort 图表需要来自物理后端的测量关节力。目前 Newton 后端不提供这些数据，因此当 Newton 处于激活状态时——例如使用 ./isaac-sim.newton.sh 或 isaac-sim.newton.bat 启动后——将省略 Effort 图表。Position 图表和数值结果表格不受影响。在 Newton 后端下仅看到 Position 图表是预期行为，并非测试失败或不完整。

注意

如果在测试过程中关节失去稳定性，它将停止产生可用样本——要么记录非有限值，要么远远超出其自身的行程限制。在 Position 图表中，这些样本会被排除：轨迹在响应发散处结束，两个坐标轴仅针对仍可读取的运行部分进行缩放，并且页脚注释会报告这两点。如果没有此处理，单个非有限值或极大值样本会设定共享坐标轴范围，并将所有轨迹压平，使其看起来像空图表。请将提前终止的轨迹解读为需要重新调参的发散关节，而非该关节的响应，并使用 Fit Frame View 查看完整记录的范围。

每个关节所受的约束边界来自其自身的位置限制，因此它不会随测试模式、指令幅度或所选其他关节而改变。对于限制未约束任何内容的关节——例如连续旋转关节——则回退使用其自身的指令峰值。Effort 图表没有等效的参考基准，因此仅省略非有限的力样本；发散到较大但有限力的关节仍会拉伸该图表的范围。

即使某个关节未列在 Robot Schema 中，只要它是物理机器人的一部分，仍会在图表中进行可视化。

若要选择多个关节，请按住 Ctrl 并点击所需的关节，或者选择第一个关节，然后按住 Shift 并点击最后一个关节，以选择它们之间的所有关节。

注意

仅在测试运行结束后才能查看可视化结果。根据测试配置的不同，这可能需要一些时间。

提示#

  • 如果您的机器人内置了重力补偿功能或拥有独立的重力补偿控制器，请禁用重力。

  • 将预期协同运动的关节分组，先单独调整每个组的参数，然后再将它们组合进行最终测试。例如，对于人形机器人，您可能需要将腿部和手臂分开处理。

  • 如果预期某个关节在实际应用中不会以最高速度运动，请降低该关节的最大速度。USD 中的大多数默认最大速度可能高得不切实际。

  • 运行 Stress 测试时，记录所有关节均处于 Stable 状态时的最高 sigma 值——这是 Isaac Lab 训练配置的一个实用安全裕度。

  • 如果在 Snap to Limits 中某个关节显示为 Blocked，请使用 Disable Self-Collisions 在调整增益之前确认原因。
