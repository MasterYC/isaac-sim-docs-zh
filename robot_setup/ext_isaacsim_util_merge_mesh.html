Mesh 合并工具#

自 6.0 版本起弃用： 独立的 isaacsim.util.merge_mesh 扩展已弃用，并将在未来版本中移除。请改用 Scene Optimizer merge 操作，可通过 URDF/MJCF 导入器的 Merge Mesh 选项、Scene Optimizer 面板（Window > Utilities > Scene Optimizer）、Asset Transformer MergeMeshRule，或直接从 Python 调用该操作来实现。

关于#

Mesh 合并将共享同一刚体父级的多个视觉几何 prim 合并为单个 mesh。减少几何 prim 的数量可降低绘制调用（draw-call）开销，从而提升渲染和物理性能。

NVIDIA Isaac Sim 通过 Scene Optimizer Kit 扩展（omni.scene.optimizer.core）执行 mesh 合并。Scene Optimizer merge 操作会将材质保留为结果 mesh 上的 GeomSubset 条目，支持顶点去重，并可对 mesh 进行空间分组。

NVIDIA Isaac Sim 中有四种集成路径可暴露 Scene Optimizer 合并操作：

集成方式

使用位置

适用场景

URDF / MJCF 导入器

File > Import > Merge Mesh 复选框

在导入机器人资产时一次性完成合并

Scene Optimizer 面板

窗口 > 实用工具 > 场景优化器

对现有资产进行交互式合并，使用临时预设

Asset Transformer 配置文件

资产转换器 > MergeMeshRule

可重复、版本控制的资产管线

Python API

isaacsim.asset.importer.utils.merge_mesh_utils

自定义脚本和无头模式资产准备

使用 URDF / MJCF 导入器#

URDF 和 MJCF 导入器均在导入器 UI 的 Options（选项）部分下暴露了一个 Merge Mesh（合并网格）复选框。启用此选项会在转换后的 USD 阶段上依次运行三个 Scene Optimizer（场景优化器）操作：

  1. meshCleanup — 合并重复顶点，移除退化面，修复非流形几何体。

  2. generateNormals 和 generateProjectionUVs — 重新生成顶点法线和投影 UV。

  3. merge — 对于阶段中的每个刚体，将所有子视觉网格 prim（具有 default 或 render 用途的 prim）合并到该刚体下的单个网格中。

导入器通过遍历每个 UsdPhysics.RigidBodyAPI prim 并收集其子几何体来自动确定合并组，并在嵌套的刚体边界处停止。无需额外配置。

有关完整的导入器工作流，请参阅 URDF Importer Extension 和 MJCF Importer Extension。

使用 Scene Optimizer UI#

Scene Optimizer 扩展自带 UI 面板，可直接暴露 merge 操作，无需中间的 Asset Transformer 规则。使用此路径可在现有 Stage 上进行一次性交互式合并，或将 merge 与 Scene Optimizer 的其他操作（如去重和材质合并）相结合。

使用 Scene Optimizer 面板交互式地合并网格。

  1. 启用 Scene Optimizer 扩展。 在标准的 NVIDIA Isaac Sim 体验中，默认未启用 Scene Optimizer。打开 Extension Manager（Window > Extensions），搜索 omni.scene.optimizer.bundle 并将其开启。该捆绑包会引入 core、ui、analysis 和 validators 扩展。

  2. 加载要合并的资产。 使用 File > Open 将 USD 加载到当前活动 Stage 中。

  3. 打开 Scene Optimizer 面板。 选择 Window > Utilities > Scene Optimizer。

  4. 选择工作流：

    • 要使用内置预设，请点击 Load Preset 并选择一个与合并相关的预设：

      • Modify Stage - Merge Meshes — 扁平化层级结构，并按材质将网格合并到 /World/Geometry/merged 中。

      • Modify Stage - Spatial Merge Meshes — 基于空间包围体合并所有网格，忽略材质差异；适用于非常密集的场景。

      • Modify Instances - Merge Meshes — 在每个原型内部合并网格，同时保留实例层级结构。当资产使用场景图实例化时效果最佳。

    • 要合并手动选择的网格集合，请点击 Add Scene Optimizer Process，然后在 Geometry 组下选择 Merge Static Meshes（注册为 merge 的操作）。配置其字段：

      • Static Meshes to Merge (meshPrimPaths)：输入 prim 路径或路径表达式（例如 /World/Robot/left_wheel//Mesh* — 前导 // 匹配 left_wheel 下任意深度的后代）。点击 pencil 图标从 stage 中选择路径，或在视口中选中 prims 后点击 Add。留空则处理 stage 上所有符合条件的网格。

      • Keep Materials Separate (considerMaterials，默认 off)：当设置为 off 时，具有不同材质的网格将合并为单个网格，该网格为每种材质携带一个按材质划分的 GeomSubset。当设置为 on 时，将为每种材质创建一个单独的合并网格 prim。保持 off 以复现旧版 Combine Materials 的行为。

      • Compute Display Colors (materialAlbedoAsVertexColors，默认 off)：根据绑定材质的反照率设置每个顶点的显示颜色和不透明度。

      • Original Mesh Handling (originalGeomOption，默认 Delete)：合并后对源网格的处理方式 — Ignore (0)、Delete (1)、Deactivate (2) 或 Hide (3)。

      • Merge Boundary (mergePoint，默认 Stage)：网格分组和合并的边界范围 — Stage (0)、Parent Xform (1)、Kind: 级别 Assembly (2)、Group (3)、Component (4)、Model (5)、Subcomponent (6)、Root Prim (7)、Parent Prim (8) 或 Original Prim (9)。使用 Root Prim 或 Kind: 级别以防止合并跨越模型边界。

      • Output Name (rootPath)：合并结果的可选名称/路径；默认为 Merged_0。

      • Strict Attribute Mode (considerAllAttributes，默认 off) 和 Allow Single Meshes (allowSingleMeshes，默认 off)：对于典型的机器人资产，请保持默认设置。

      • Spatial Clustering Mode (spatialMode，默认 None)：None (0)、Bounding Box (1)、Vertex Count ([[[ 2 Coincident Boundary Vertices 3

  5. 添加前置清理步骤（可选但建议执行）。再次点击 Add Scene Optimizer Process 两次，依次添加 Mesh Cleanup (meshCleanup) 和 Generate Normals (generateNormals)。拖动每个流程卡片左上角的手柄，使它们在 Merge Static Meshes 之前执行。这与 URDF/MJCF 导入器内部运行的流程一致。

  6. 执行并验证。

    • 点击 Execute All。控制台日志会报告正在运行的操作。

    • 检查 Stage。每个合并组会被替换为一个以配置的 Output Name 命名的单一网格 Prim。如果 Original Mesh Handling 设置为 Deactivate，源网格将作为已禁用的 Prim 保留在 Stage 中（Delete 会完全移除它们，而 Ignore 则保持它们不变）。

    • 使用 File > Save As 保存结果。

  7. 保存配置以便复用（可选）。点击 Save Preset 将当前的流程栈写入 JSON 文件。之后可以从该 UI 加载相同的 JSON，或将其提供给 Scene Optimizer CLI 进行批处理。

注意

Scene Optimizer UI 直接在内存中的 active stage 上执行操作。合并后请显式保存 Stage —— 该面板不会自动写入磁盘。

Scene Optimizer 面板读取和写入其自身的 JSON 预设格式。一个模拟导入器流程（清理、法线 + UV、合并）的最小预设如下所示：

[
  {
    "operation": "meshCleanup",
    "paths": [],
    "mergeVertices": true,
    "tolerance": 0.0,
    "mergeBoundaries": true,
    "mergeNeighbors": true,
    "contractDegenerateEdges": true,
    "removeDegenerateFaces": true,
    "removeIsolatedVertices": true,
    "removeDuplicateFaces": true,
    "makeManifold": true
  },
  {
    "operation": "generateNormals",
    "paths": [],
    "binding": 0,
    "sharpnessAngle": 60.0,
    "gpuThreshold": 500000
  },
  {
    "operation": "generateProjectionUVs",
    "paths": [],
    "projectionType": 4,
    "useWorldSpaceScales": true,
    "scaleFactor": 0.01,
    "overwriteExisting": true
  },
  {
    "operation": "merge",
    "meshPrimPaths": ["/World/Robot/left_wheel//Mesh*"],
    "considerMaterials": false,
    "materialAlbedoAsVertexColors": false,
    "originalGeomOption": 1,
    "mergePoint": 0,
    "rootPath": "",
    "considerAllAttributes": true,
    "allowSingleMeshes": false,
    "spatialMode": 0,
    "spatialThreshold": 10.0,
    "spatialMaxSize": 0.0,
    "spatialVertexCount": 10000,
    "spatialDebug": false
  }
]

编辑 meshPrimPaths 以指定要合并的网格。使用 USD 路径表达式 — // 运算符可匹配任意深度的后代节点，因此 /World/Robot//Mesh* 会在 /World/Robot 下的任意位置查找所有名为 Mesh* 的 prim。

通过 Scene Optimizer 面板的 Load Preset > Browse… 按钮加载此文件。

有关完整的操作目录、内置预设说明以及 Scene Optimizer CLI 用法，请参阅 Scene Optimizer 扩展文档。

使用资产转换器#

如果您需要将网格合并与其他 USD 重构规则（如 schema 路由、几何去重、材质路由、接口生成）串联起来，请将合并步骤封装在 Asset Transformer 配置文件中。Asset Transformer 提供了一个 Merge Mesh 配置文件 (source/extensions/isaacsim.asset.transformer.rules/data/merge_mesh.json)，它执行与导入器相同的刚体感知合并操作：

{
  "profile_name": "Merge Mesh",
  "version": "1.0",
  "rules": [
    {
      "name": "Merge Meshes",
      "type": "isaacsim.asset.transformer.rules.isaac_sim.merge_mesh.MergeMeshRule",
      "destination": "",
      "params": {},
      "enabled": true
    }
  ],
  "interface_asset_name": null,
  "output_package_root": null,
  "flatten_source": false,
  "base_name": null
}

MergeMeshRule 会遍历 stage 中的所有刚体，并对每个刚体的子视觉网格应用 Scene Optimizer 的 merge 操作 — 无需任何参数。

使用 Python API#

isaacsim.asset.importer.utils.merge_mesh_utils 模块封装了导入器使用的 Scene Optimizer 操作。可用于无头模式下的资产准备、批量处理，或不适合导入器或 Transformer 流程的自定义资产“整理”操作。

以下代码块取自一个可运行的脚本 docs/isaacsim/snippets/robot_setup/merge_mesh.py，您可以使用 Isaac Sim 的 python.sh 执行该脚本。传入 --test 以导入捆绑的 carter.urdf 测试资产，并端到端地运行每个代码片段。

注意

在调用这些辅助函数之前，必须启用 omni.scene.optimizer.core 扩展。独立脚本必须显式启用它：

import omni.kit.app

omni.kit.app.get_app().get_extension_manager().set_extension_enabled_immediate("omni.scene.optimizer.core", True)

可用的辅助函数：

函数

用途

clean_mesh_operation(stage)

运行 meshCleanup：合并重复顶点，移除退化面，使网格成为流形。

generate_mesh_uv_normals_operation(stage)

Scene Optimizer（现称 USD Optimize）操作参考#

如需更精细的控制，请直接调用 usd_optimize.core 操作。构建一个 UsdOptimizeCore 实例和一个绑定到当前 stage 的 ExecutionContext，然后通过名称和配置字典分发操作：

from pxr import Usd
from usd_optimize.core import ExecutionContext, UsdOptimizeCore

# stage_path = "/path/to/asset.usd"
# mesh_paths = ["/World/A", "/World/B", "/World/C"]
stage = Usd.Stage.Open(stage_path)

context = ExecutionContext()
context.set_stage(stage)
context.generateReport = 0
context.captureStats = 0

core = UsdOptimizeCore.getInstance()

core.executeOperation(
    "merge",
    context,
    {
        "meshPrimPaths": list(mesh_paths),
        "considerMaterials": False,
        "materialAlbedoAsVertexColors": False,
        "originalGeomOption": 1,
        "mergePoint": 0,
        "rootPath": mesh_paths[0],
        "considerAllAttributes": True,
        "allowSingleMeshes": False,
        "spatialMode": 0,
        "spatialThreshold": 10.0,
        "spatialMaxSize": 0.0,
        "spatialVertexCount": 10000,
        "spatialDebug": False,
    },
)
stage.Save()

导入器将 considerMaterials 保留为其默认值 False。使用 considerMaterials = False 时，该操作会将使用不同材质的网格合并为单个网格，并将每个材质保留为 GeomSubset — 这相当于旧版工具的 Combine Materials 选项。若要改为按材质发出单独的合并网格 prim（例如，当下游材质路由（如 asset transformer 的 MaterialsRoutingRule）期望每个材质对应一个网格时），请将 considerMaterials = True 设置为相应值。

从旧版网格合并工具迁移#

旧版选项

Scene Optimizer 等效项

Source Prim（首次选择 = 原点）

将网格路径传递给 merge_mesh(stage, paths)；第一个路径用作 rootPath。

清除父级变换

选择 Merge Boundary (mergePoint)：Stage (0) 在整个 stage 中进行分组，Parent Xform (1) 使用父级变换，而 Root Prim (7) 或 Kind: 级别将合并限制在模型内。

停用源资产

设置 Original Mesh Handling (originalGeomOption)：Ignore (0) 保留原始网格，Delete (1) 移除原始网格，Deactivate (2) 停用原始网格，Hide (3) 隐藏原始网格。

合并材质

将 considerMaterials 保持为 False（默认值）：具有不同材质的网格将合并为一个网格，并且每个材质都作为 GeomSubset 保留。将 considerMaterials = True 设置为其他值，则使每个材质保留在单独的合并网格上。

首先选择一个空的 Xform 以设置原点

使用 Output Name (rootPath) 为合并结果命名，并将其放置在任意 prim 路径下。
