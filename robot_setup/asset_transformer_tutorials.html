Asset Transformer 教程#

Tutorial

这些教程将逐步演示常见的 Asset Transformer 工作流程。每个教程都建立在前一个教程的基础上，因此建议按顺序学习。

如需深入了解 UI 和概念，请参阅 Asset Transformer。

开始之前，请从 Tools > Robotics > Asset Editors > Asset Transformer 打开 Asset Transformer。

教程 1：使用 Isaac Sim 结构配置文件转换资产#

本教程演示如何使用内置的 Isaac Sim Structure 配置文件，将机器人 USD 资产转换为推荐的 Isaac Sim 资产结构。

先决条件#

  • 已在 stage 中加载或存在于磁盘上的机器人 USD 资产。本教程使用 Isaac Sim 资产库中 Isaac/Robots/ 里的示例机器人。在本教程中，我们将使用 Isaac/Robots/Fraunhofer/Evobot/evobot.usd 资产。

操作说明#

选择输入资产#

  1. 在 Input Section 中，选择 Active Stage 以转换当前打开的 stage，或选择 Pick File 并浏览至磁盘上的机器人 USD 文件。

  2. 将 Output Directory 设置为可写文件夹，转换后的资产包将保存在此处（例如 /tmp/my_robot_transformed/）。

  3. 如果希望输出文件在执行后自动打开，请勾选 Load Restructured File。

加载内置配置文件#

  1. 在 Actions Section 中，点击 Load Preset 按钮。

  2. 从最近使用的预设菜单中，选择 Isaac Sim Structure。

  3. 操作列表将填充 Isaac Sim Structure 配置文件中定义的所有规则。

  1. 展开操作列表中的一两个规则以检查其参数。每个规则显示其 Rule Type、Destination 和 Parameters。

执行转换#

  1. 在 Execute Section 中点击 Execute Actions。当至少启用一个操作且设置了输出目录时，该按钮将被启用。

  2. 等待流水线完成。控制台日志将显示每个规则的进度。

验证输出#

  1. 由于勾选了 Load Restructured File，转换后的资产会自动打开。请注意，加载的资产不再包含地面平面，因为它不在原始机器人资产的默认 prim 中。这是预期且期望的行为。

  2. 检查输出文件夹结构。它应遵循 Isaac Sim Asset Structure：

output_directory/
├── payloads/
│   ├── base.usd
│   ├── robot.usda
│   ├── geometries.usd
│   ├── instances.usda
│   ├── materials.usda
│   ├── Textures/
│   │   └── ...
│   └── Physics/
│       ├── physics.usda
│       ├── physx.usda
│       └── mujoco.usda
├── <asset_name>.usda          (interface layer)
└── transform_report.json

  1. 检查机器人 prim 结构，验证所有网格现在均通过引用添加，且之前的 looks 范围现在为空，因为所有材质现在都已添加到 materials.usda 层中，并通过网格添加。

  2. 检查默认 prim 属性，验证是否存在用于物理引擎的 Variant set，且已选中 physx 变体。

  3. 打开 transform_report.json 以查看每个规则的执行日志，并确认所有规则均已成功完成。

教程 2：创建新配置文件#

本教程演示如何从头构建自定义转换配置文件。示例配置文件将物理 schema 和材质路由到专用层中，这是不需要完整 Isaac Sim Asset Structure 处理的资产的常见工作流。

说明#

清除操作列表#

  1. 点击 Clear All Actions 以从空管道开始。

  2. 展开 Profile Settings 框架并填写元数据：

    • Profile Name：My Custom Profile

    • Version：1.0

    • Base Name：base.usd

    • Flatten Source：除非您的源资产具有希望先展平的复杂子层组合，否则请保持未选中状态。

添加 Schema 路由规则#

  1. 点击 Add Action 以向流水线添加新规则。

  2. 展开新操作并设置：

    • Rule Type：搜索 SchemaRoutingRule 并选择 isaacsim.asset.transformer.rules.core.schemas.SchemaRoutingRule。

    • Name：Route Physics Schemas

    • Destination：payloads/Physics

    • Parameters：

      • stage_name：physics.usda

      • schemas：["Physics*", "Newton*"]（点击 [+] 按钮为列表中的每个项目添加新的 schema 行）

添加 Materials 路由规则#

  1. 再次点击 Add Action 以添加第二条规则。

  2. 展开该规则并设置：

    • Rule Type：搜索 MaterialsRoutingRule 并选择 isaacsim.asset.transformer.rules.perf.materials.MaterialsRoutingRule。

    • Name：Route Materials

    • Destination：payloads

    • Parameters：

      • materials_layer：materials.usda

      • textures_folder：Textures

      • deduplicate：true

      • download_textures：true

添加 Geometry 去重规则#

  1. 再次点击 Add Action。

  2. 展开并设置：

    • Rule Type：搜索 GeometriesRoutingRule 并选择 isaacsim.asset.transformer.rules.perf.geometries.GeometriesRoutingRule。

    • Name：Deduplicate Geometries

    • Destination：payloads

    • Parameters：

      • geometries_layer：geometries.usd

      • instance_layer：instances.usda

      • deduplicate：true

      • save_base_as_usda：true

检查 Pipeline#

操作列表现在按顺序包含三条规则：

  1. 路由物理架构

  2. 路由材质

  3. 几何体去重

验证执行顺序是否正确。如有需要，可拖动操作以重新排序。在测试期间，使用复选框可禁用单个规则。

注意

规则执行顺序很重要。规则按顺序执行，每条规则都在前一条规则修改后的工作阶段上运行。请将 schema 路由规则放置在 material 和 geometry 规则之前，以便在去重发生之前分离 schema。

教程 3：保存 Profile#

在 教程 2 中构建自定义 profile 后，将其保存以供重复使用。

说明#

  1. 展开 Profile Settings 框架以验证 profile 元数据。确认 Profile Name、Version 和其他字段是否正确。

  2. 在 Actions Section 中点击 Save Preset 按钮。

  3. 在文件选择器中，导航到所需的保存位置并输入文件名（例如 my_custom_profile.json）。

  4. 点击 Save。

配置文件将保存为 JSON 文件，并添加到最近使用的预设列表中，以便将来快速加载。

通过在文本编辑器中打开该文件来验证保存的文件。其结构与 Rule Profile 格式 匹配：

{
   "profile_name": "My Custom Profile",
   "version": "1.0",
   "rules": [
      {
         "name": "Route Physics Schemas",
         "type": "isaacsim.asset.transformer.rules.core.schemas.SchemaRoutingRule",
         "destination": "payloads/Physics",
         "params": {
         "schemas": [
            "Physics*",
            "Newton*"
         ],
         "ignore_schemas": [],
         "stage_name": "physics.usda",
         "prim_names": [
            ".*"
         ],
         "ignore_prim_names": []
         },
         "enabled": true
      },
      {
         "name": "Route Materials",
         "type": "isaacsim.asset.transformer.rules.perf.materials.MaterialsRoutingRule",
         "destination": "payloads",
         "params": {
         "scope": "/",
         "materials_layer": "materials.usda",
         "textures_folder": "Textures",
         "deduplicate": true,
         "download_textures": true
         },
         "enabled": true
      },
      {
         "name": "Deduplicate Geometries",
         "type": "isaacsim.asset.transformer.rules.perf.geometries.GeometriesRoutingRule",
         "destination": "payloads",
         "params": {
         "scope": "/",
         "geometries_layer": "geometries.usd",
         "instance_layer": "instances.usda",
         "deduplicate": true,
         "save_base_as_usda": true,
         "verbose": false
         },
         "enabled": true
      }
   ],
   "flatten_source": false,
   "base_name": "base.usd"
}

教程 4：修改 Rule Profile#

本教程演示如何加载现有配置文件、修改其规则和参数，并重新保存。示例修改了 教程 3 中保存的配置文件，以添加 Interface Connection Rule 并更改几何去重设置。

说明#

加载现有配置文件#

  1. 点击 Load Preset 并选择之前保存的 my_custom_profile.json 文件。操作列表将填充教程 3 中的三个规则。

添加新规则#

  1. 点击 Add Action 以添加第四个规则。

  2. 展开该规则并设置：

    • Rule Type：Interface Connection Rule

    • Name：Connect Interfaces

    • Destination：payloads

    • Parameters：

      • Base Layer：payloads/base.usda

      • Base Connection Type：Reference

      • Generate Folder Variants：true

      • Payloads Folder：payloads

      • Custom Connections：[]

      • Default Variant Selections：{}

修改现有规则#

  1. 展开 Deduplicate Geometries 规则。

  2. 将 deduplicate 参数从 true 更改为 false，以在保持几何体路由活动的同时禁用去重。

重新排序规则#

  1. 将 Deduplicate Geometries 规则拖动到第二个位置，使其在 Route Materials 规则之前执行。

禁用规则#

  1. 取消勾选 Route Materials 旁边的启用复选框，以在不将其从流水线中移除的情况下禁用该规则。这对于迭代特定转换非常有用。

更新配置文件元数据#

  1. 展开 Profile Settings。

  2. 将 Version 更改为 1.1 以跟踪修改。

保存修改后的配置文件#

  1. 点击 Save Preset。

  2. 覆盖现有文件或选择新的文件名。

教程 5：通过代码添加资产转换管道#

本教程演示如何使用 Asset Transformer API 以编程方式运行转换管道。这对于批处理、CI/CD 集成，或将资产转换嵌入到自定义扩展和工作流中非常有用。

以下代码块取自单个脚本 docs/isaacsim/snippets/robot_setup/asset_transformer_tutorials.py，您可以将其作为独立应用运行（例如，列出已注册的规则类型），使用 Isaac Sim 的 python.sh。

加载并运行已保存的配置文件#

最简单的方法是加载现有的配置文件 JSON 文件，并针对输入资产执行该配置。

import json

from isaacsim.asset.transformer import AssetTransformerManager, RuleProfile

# profile_path = "/path/to/my_custom_profile.json"
# input_stage = "/path/to/my_robot.usd"
# package_root = "/output/my_robot_package"
# Load a saved profile from disk
with open(profile_path, "r") as f:
    profile_data = json.load(f)

profile = RuleProfile.from_dict(profile_data)

# Create the manager and run the transformation
manager = AssetTransformerManager()
report = manager.run(
    input_stage=input_stage,
    profile=profile,
    package_root=package_root,
)

# Inspect results
print(f"Output asset: {report.output_stage_path}")
for result in report.results:
    status = "OK" if result.success else "FAILED"
    print(f"  [{status}] {result.rule.name}")
    if result.error:
        print(f"    Error: {result.error}")

以编程方式构建配置文件#

若要在代码中完全定义配置文件而无需 JSON 文件：

from isaacsim.asset.transformer import (
    AssetTransformerManager,
    RuleProfile,
    RuleSpec,
)

# input_stage = "/path/to/my_robot.usd"
# package_root = "/output/my_robot_package"

profile = RuleProfile(
    profile_name="Code-Defined Profile",
    version="1.0",
    base_name="base.usd",
    flatten_source=False,
    rules=[
        RuleSpec(
            name="Route Physics Schemas",
            type="isaacsim.asset.transformer.rules.core.schemas.SchemaRoutingRule",
            destination="payloads/Physics",
            params={
                "stage_name": "physics.usda",
                "schemas": ["Physics*", "Newton*"],
            },
        ),
        RuleSpec(
            name="Route Materials",
            type="isaacsim.asset.transformer.rules.perf.materials.MaterialsRoutingRule",
            destination="payloads",
            params={
                "materials_layer": "materials.usda",
                "assets_folder": "Textures",
                "download_textures": True,
            },
        ),
        RuleSpec(
            name="Deduplicate Geometries",
            type="isaacsim.asset.transformer.rules.perf.geometries.GeometriesRoutingRule",
            destination="payloads",
            params={
                "geometries_layer": "geometries.usd",
                "instance_layer": "instances.usda",
                "deduplicate": True,
            },
        ),
    ],
)

manager = AssetTransformerManager()
report = manager.run(
    input_stage=input_stage,
    profile=profile,
    package_root=package_root,
)

print(f"Transformation complete: {report.output_stage_path}")

在代码中使用 Isaac Sim 结构配置文件#

若要以编程方式使用内置的 Isaac Sim 结构配置文件，请从扩展的数据目录中加载它：

import json
from pathlib import Path

from isaacsim.asset.transformer import AssetTransformerManager, RuleProfile
from isaacsim.core.utils.extensions import get_extension_path_from_name

# input_stage = "/path/to/my_robot.usd"
# package_root = "/output/my_robot_isaacsim_structure"
# Locate the built-in profile shipped with the rules extension (use get_extension_path_from_name so the path is absolute)
ext_path = Path(get_extension_path_from_name("isaacsim.asset.transformer.rules"))
profile_path = ext_path / "data" / "isaacsim_structure.json"

with open(profile_path, "r") as f:
    profile = RuleProfile.from_dict(json.load(f))

manager = AssetTransformerManager()
report = manager.run(
    input_stage=input_stage,
    profile=profile,
    package_root=package_root,
)

批量处理多个资产#

结合该 API 与标准 Python 代码来转换多个资产：

import json
from pathlib import Path

from isaacsim.asset.transformer import AssetTransformerManager, RuleProfile

# profile_path = "/path/to/my_custom_profile.json"
# asset_paths = ["/assets/robot_a.usd", "/assets/robot_b.usd", "/assets/robot_c.usd"]
# output_base_dir = "/output"

with open(profile_path, "r") as f:
    profile = RuleProfile.from_dict(json.load(f))

manager = AssetTransformerManager()

for asset_path in asset_paths:
    asset_name = Path(asset_path).stem
    output_dir = f"{output_base_dir.rstrip('/')}/{asset_name}_transformed"

    report = manager.run(
        input_stage=asset_path,
        profile=profile,
        package_root=output_dir,
    )

    all_ok = all(r.success for r in report.results)
    print(f"{asset_name}: {'PASS' if all_ok else 'FAIL'} -> {report.output_stage_path}")

保存并检查执行报告#

manager.run() 返回的 ExecutionReport 可以序列化为 JSON，用于日志记录或 CI 验证：

import json
from pathlib import Path

# report = <ExecutionReport from manager.run() in any example above>

report_path = Path(report.package_root) / "transform_report.json"
with open(report_path, "w") as f:

发现可用的规则类型#

要在运行时列出所有已注册的转换规则：

from isaacsim.asset.transformer import RuleRegistry

registry = RuleRegistry()
for rule_type in registry.list_rule_types():
    print(rule_type)

这将打印所有可在 RuleSpec.type 中使用的完全限定规则类名。有关每个规则的文档，请参阅 Asset Transformer Rules Reference。
