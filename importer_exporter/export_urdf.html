教程：导出 URDF#

Tutorial

学习目标#

本教程探讨如何在 NVIDIA Isaac Sim 中从 USD 导出 URDF 文件。 完成本教程后，您将能够使用 NVIDIA Isaac Sim 将机器人 USD 文件转换为 URDF 文件。

10-20 分钟教程

入门指南#

先决条件

  • 在开始本教程之前，请先阅读 Isaac Sim 基础。

导出机器人#

要将机器人 USD 文件转换为 URDF 文件并了解一些高级选项：

启用导出器扩展#

要启用导出器扩展：

  1. 导航至 Windows > Extensions，在搜索栏中输入 urdf，然后启用 USD to URDF exporter 扩展。

    这将添加 File > Export to URDF 菜单选项。

  2. 选择该选项以打开扩展，验证用户界面是否类似于：

  3. 打开 Franka 机器人的 USD 文件，该文件位于 Isaac 资产根路径下的 /Isaac/Robots_Multiphysics/FrankaRobotics/FrankaPanda/franka/franka.usda。

    USD 文件加载完成后：

  4. 打开 File > Export to URDF 菜单选项。此时将出现一个文件选择对话框。

  5. 选择目标文件和文件夹。

  6. 点击 Export。

  7. 打开输出文件夹以查看生成的文件。

  8. 验证是否存在 franka.urdf 文件和 meshes 目录。meshes 目录包含机器人的网格文件。

要检查结果：

  • URDF 可以重新导入到 USD 并在 Isaac Sim 中打开。有关具体步骤，请参阅 Import URDF 教程。

  • 使用此 URDF Viewer Example 网站查看结果。将输出目录直接拖放到该网站中以查看 URDF 文件并检查关节。

导入选项#

网格文件夹名称#

保存网格 .obj 文件的文件夹名称。默认为 meshes，并放置在保存 URDF 文件的同一目录中。

网格路径前缀#

网格路径前缀有三种选项：

  1. 绝对路径（默认），由前缀 file:// 定义

  2. 包路径，由前缀 package:// 定义

  3. 相对路径，由前缀 ./ 定义

使用 package:// 前缀时，需要在 Package Name 字段中指定包名称。如果留空，包名称将为 urdf 文件的名称。

根 Prim 路径#

如果直接从机器人的资产文件导出，默认 prim 将是其根 prim；但如果从包含机器人和其他多个对象的场景中导出，可以通过指定代表机器人的 prim 来仅导出该机器人。

碰撞对象#

在 URDF 文件中，一个 link 通常关联两个独立的网格：

  • 视觉网格

  • 碰撞网格

在 USD 中，视觉网格和碰撞网格之间没有区别。 USD prim 可以附加 PhysicsCollisionAPI，这告诉物理引擎在与其他物体接触时解析该物体的运动。 此外，prim 可以设置为可见或不可见。 USD 到 URDF 的导出器会根据 prim 是否应用了 PhysicsCollisionAPI 以及是否可见，为每个 link 创建视觉网格和碰撞网格。

要探索几何 prim 如何映射到 URDF 中的视觉网格和碰撞网格，请向 Franka 机器人添加一个几何 prim，并以不同方式导出，以验证每个生成的 URDF 文件中创建了什么。

  1. 打开 Franka 机器人的 USD 文件（位于 /Isaac/Robots_Multiphysics/FrankaRobotics/FrankaPanda/franka/franka.usda）。

  2. 右键单击 panda_hand Xform prim，并从上下文菜单中选择 Create > Mesh > Sphere。

  3. 选择新的 Sphere Mesh prim，并将 x、y 和 z 分量的缩放比例全部更改为 0.3。

  4. 验证 Franka 是否类似于：

  5. 按照上述步骤导出当前 stage（无需保存更改）。

    • 打开 USD to URDF Exporter 菜单。

    • 选择输出目录。

    • 点击 EXPORT 按钮。

  6. 将输出目录拖入 URDF Viewer Example 网站以查看结果。

  7. 验证结果是否类似于：

  8. 启用 Show Collision 选项，该选项会可视化所有碰撞网格并以金色高亮显示。

  9. 观察球体未被金色高亮显示的原因：在 URDF 中，它不是碰撞网格，而是视觉网格。

  10. 返回 Franka USD，为球体添加碰撞 API。

    可以通过选择 Sphere prim 并点击 prim 属性菜单中的 +Add 按钮来完成此操作。

  11. 选择 Physics > Colliders Preset。

  12. 为球体添加碰撞 API 后，重新将 USD stage 导出为 URDF，并再次将输出目录拖入 URDF 查看器。在拖入新的 URDF 之前，可能需要刷新查看器的网页。

  13. 验证 Franka 是否类似于：

  14. 启用 Show Collision 选项。

  15. 请注意，这次球体以金色高亮显示。

    这是因为在 URDF 文件中，该球体既是碰撞网格又是视觉网格。

  16. 回到 Franka USD，通过禁用 Sphere 图元旁边的“眼睛”图标，使球体不可见。

  17. 使球体不可见后，重新将 USD 舞台导出为 URDF，并将输出目录再次拖入 URDF 查看器。

    最初球体并不存在，但在启用 Show Collision 后，球体以金色高亮显示。 这是因为在 URDF 文件中，该球体是碰撞网格，但不是视觉网格。

  18. 验证您是否得到了类似以下内容：

为了正确地将链接碰撞网格导出到 URDF，它们必须具有碰撞 API，并且必须设置为不可见。 要将所有具有碰撞 API 的图元转换为视觉网格，无论图元的可见性状态如何，请在 USD 到 URDF 导出器的高级选项中启用 Visualize Collisions 选项。

限制#

与 URDF 相比，USD 格式提供了更强的表达能力和更多的功能。 可以使用 USD 描述的所有场景和机器人的集合是使用 URDF 描述的场景和机器人集合的超集。 这意味着所有可以由 URDF 文件描述的场景和机器人也可以由 USD 文件描述，但反之则不然。 因此，USD 和 URDF 之间不存在直接的一对一映射关系。 因此，在将 USD 文件转换为 URDF 文件时，会做出若干假设并施加一些约束。

以下是 USD 文件满足以下约束条件时，USD 到 URDF 导出器才能成功导出。

  • 机器人的运动学结构必须是树状结构

  • 球体形状在所有轴上的缩放比例必须相同

  • 圆柱体形状在半径轴（即非高度轴）上的缩放比例必须相同

  • 关节的每个坐标系必须共位且对齐

  • 父链接 prim 应为 Body 0，子链接 prim 应为关节的 Body 1

  • 关节 prim 必须是 prismatic、revolute 或 fixed

  • 链接 prim 必须是 Xform。

  • 传感器 prim 必须是 Camera 或 IsaacImuSensor

  • 几何体 prim 必须是 Cube、Sphere、Cylinder 或 Mesh

  • 几何体 prim 必须是运动学树中的“叶子节点”

如果您的 USD 违反了这些约束条件中的任何一项，则会抛出错误。

注意

根据机器人结构的不同，由于不同坐标系的合并，某些主体名称可能会被覆盖。请检查输出结果并验证其准确性。

总结#

本教程涵盖了以下主题：

  1. 使用导出器 GUI 导出 URDF 文件

  2. 通过在查看器中查看来验证 URDF 结果

  3. 了解如何从 USD 控制 URDF 中的碰撞网格和视觉网格

  4. 概述 USD 到 URDF 导出器的局限性

深入学习#

查阅 USD to URDF Exporter Extension 以了解更多配置选项。
