Lula RMPflow#

Tool Reference

已弃用

对于新开发项目，建议考虑使用较新的 Robot Motion (Experimental) API，该 API 相比 Lula 提供了改进的接口和更多功能。

本教程展示了如何使用 Motion Generation 中的 RMPflow 类来生成平滑运动，以在避开动态障碍物的同时到达任务空间目标。本教程演示了如何：

  • RmpFlow 可以直接实例化，并使用自定义机器人描述文件生成运动

  • RmpFlow 可以加载并在支持的机器人上使用

  • 内置调试功能可以提高易用性和集成度

入门指南#

先决条件

  • 在开始本教程之前，请先完成 Adding a Manipulator Robot 教程。
  • 请查阅 Loaded Scenario Extension Template，以了解本教程的结构和运行方式。

要跟随本教程操作，请运行您的 Isaac Sim 6.0 实例。然后打开 Window > Extensions，搜索 Motion Generation Examples (isaacsim.robot_motion.motion_generation.examples) 并启用它。如果找不到，请从 Extensions 搜索栏中移除 @feature 并重新搜索。 在 isaacsim.robot_motion.motion_generation.examples 扩展中，有一个功能完整的 RMPflow 示例，包括目标跟随、世界感知 和调试选项。本教程的各部分将文件 scenario.py 从基本功能逐步构建到完整代码。

注意

Motion Generation Examples (isaacsim.robot_motion.motion_generation.examples) 自 Isaac Sim 6.0.0 起已弃用。在 Isaac Sim 源代码仓库中，它们位于 source/deprecated/isaacsim.robot_motion.motion_generation.examples 下；扩展 ID 保持不变。

替代方案： 使用 isaacsim.robot_motion.cumotion.examples 扩展和 cuMotion Integration 教程。

使用 RMPflow 实例生成运动#

RMPflow 在 NVIDIA Isaac Sim 中被广泛用于控制机器人机械臂。如 RMPflow Configuration 中所述，直接实例化 RmpFlow 类需要三个配置文件。 加载这些配置文件并指定末端执行器目标后，即可计算动作以将机器人移动到所需目标。

import os

import numpy as np
from isaacsim.core.api.objects.cuboid import FixedCuboid
from isaacsim.core.prims import SingleArticulation as Articulation
from isaacsim.core.prims import SingleXFormPrim as XFormPrim
from isaacsim.core.utils.extensions import get_extension_path_from_name
from isaacsim.core.utils.numpy.rotations import euler_angles_to_quats
from isaacsim.core.utils.stage import add_reference_to_stage
from isaacsim.robot_motion.motion_generation import ArticulationMotionPolicy, RmpFlow
from isaacsim.storage.native import get_assets_root_path


class FrankaRmpFlowExample:
    def __init__(self):
        self._rmpflow = None
        self._articulation_rmpflow = None

        self._articulation = None
        self._target = None

    def load_example_assets(self):
        # Add the Franka and target to the stage
        # The position in which things are loaded is also the position in which they

        robot_prim_path = "/panda"
        path_to_robot_usd = (
            get_assets_root_path() + "/Isaac/Robots_Multiphysics/FrankaRobotics/FrankaPanda/franka/franka.usda"
        )

        add_reference_to_stage(path_to_robot_usd, robot_prim_path)
        self._articulation = Articulation(robot_prim_path)

        add_reference_to_stage(get_assets_root_path() + "/Isaac/Props/UIElements/frame_prim.usd", "/World/target")
        self._target = XFormPrim("/World/target", scale=[0.04, 0.04, 0.04])

        # Return assets that were added to the stage so that they can be registered with the core.World
        return self._articulation, self._target

    def setup(self):
        # RMPflow config files for supported robots are stored in the motion_generation extension under "/motion_policy_configs"
        mg_extension_path = get_extension_path_from_name("isaacsim.robot_motion.motion_generation")
        rmp_config_dir = os.path.join(mg_extension_path, "motion_policy_configs")

        # Initialize an RmpFlow object
        self._rmpflow = RmpFlow(
            robot_description_path=rmp_config_dir + "/franka/rmpflow/robot_descriptor.yaml",
            urdf_path=rmp_config_dir + "/franka/lula_franka_gen.urdf",
            rmpflow_config_path=rmp_config_dir + "/franka/rmpflow/franka_rmpflow_common.yaml",
            end_effector_frame_name="right_gripper",
            maximum_substep_size=0.00334,
        )

        # Use the ArticulationMotionPolicy wrapper object to connect rmpflow to the Franka robot articulation.
        self._articulation_rmpflow = ArticulationMotionPolicy(self._articulation, self._rmpflow)

        self._target.set_world_pose(np.array([0.5, 0, 0.7]), euler_angles_to_quats([0, np.pi, 0]))

    def update(self, step: float):
        # Step is the time elapsed on this frame
        target_position, target_orientation = self._target.get_world_pose()

        self._rmpflow.set_end_effector_target(target_position, target_orientation)

        action = self._articulation_rmpflow.get_next_articulation_action(step)
        self._articulation.apply_action(action)

    def reset(self):
        # Rmpflow is stateless unless it is explicitly told not to be

        self._target.set_world_pose(np.array([0.5, 0, 0.7]), euler_angles_to_quats([0, np.pi, 0]))

RMPflow 是 Motion Policy Algorithm 接口的一种实现。 任何 MotionPolicy 都可以传递给 Articulation Motion Policy， 以开始在 USD 舞台上移动机器人。在第 43 行，使用所需的配置信息实例化了 RmpFlow 的一个实例。 在第 52 行创建的 ArticulationMotionPolicy 充当 RmpFlow 与模拟的 Franka 机器人 Articulation 之间的转换层。您可以直接与 RmpFlow 交互，以传递世界状态、设置末端执行器目标或修改内部设置。 在每一帧中，末端执行器目标会直接传递给 RmpFlow 对象（第 60 行）。 在第 64 行使用 ArticulationMotionPolicy 计算动作，该动作可直接由 Franka Articulation 使用。

注意

RMPflow 算法会考虑由配置 URDF 文件提供的机器人结构。如果处理的是带有装配组件的机器人（例如，安装了夹爪的 UR10），则应更新 URDF 文件以反映正确的机器人结构，并在末端执行器坐标系中包含夹爪的偏移量或额外的控制关节。最终的装配 URDF 可以使用 USD to URDF Exporter 导出。在修改源 URDF 文件时，建议检查并更新 Robot Description file，以确保使用正确的补充文件。

世界状态#

作为一种运动策略算法，RmpFlow 能够在将末端执行器导航至目标的同时实现动态碰撞避免。在 RmpFlow 导航至目标的过程中，世界状态可以随时间变化。使用 isaacsim.core.api.objects 包创建的对象（参见 输入：世界状态）可以注册到 RmpFlow，策略将自动避免与这些障碍物发生碰撞。每当调用 RmpFlow.update_world() 时，都会触发 RmpFlow 以查询所有被跟踪对象的当前状态。

RmpFlow 还可以通过调用 RmpFlow.set_robot_base_pose() 来获知指定帧上机器人基座位姿的变化。 由于对象位置是以世界坐标系查询的，如果机器人在 USD 场景中的基座发生了移动，则必须使用此函数。

import os

import numpy as np
from isaacsim.core.api.objects.cuboid import FixedCuboid
from isaacsim.core.prims import SingleArticulation as Articulation
from isaacsim.core.prims import SingleXFormPrim as XFormPrim
from isaacsim.core.utils.extensions import get_extension_path_from_name
from isaacsim.core.utils.numpy.rotations import euler_angles_to_quats
from isaacsim.core.utils.stage import add_reference_to_stage
from isaacsim.robot_motion.motion_generation import ArticulationMotionPolicy, RmpFlow
from isaacsim.robot_motion.motion_generation.interface_config_loader import (
    get_supported_robot_policy_pairs,
    load_supported_motion_policy_config,
)
from isaacsim.storage.native import get_assets_root_path


class FrankaRmpFlowExample:
    def __init__(self):
        self._rmpflow = None
        self._articulation_rmpflow = None

        self._articulation = None
        self._target = None

    def load_example_assets(self):
        # Add the Franka and target to the stage
        # The position in which things are loaded is also the position in which they

        robot_prim_path = "/panda"
        path_to_robot_usd = (
            get_assets_root_path() + "/Isaac/Robots_Multiphysics/FrankaRobotics/FrankaPanda/franka/franka.usda"
        )

        add_reference_to_stage(path_to_robot_usd, robot_prim_path)
        self._articulation = Articulation(robot_prim_path)

        add_reference_to_stage(get_assets_root_path() + "/Isaac/Props/UIElements/frame_prim.usd", "/World/target")
        self._target = XFormPrim("/World/target", scale=[0.04, 0.04, 0.04])

        self._obstacle = FixedCuboid(
            "/World/obstacle", size=0.05, position=np.array([0.4, 0.0, 0.65]), color=np.array([0.0, 0.0, 1.0])
        )

        # Return assets that were added to the stage so that they can be registered with the core.World
        return self._articulation, self._target, self._obstacle

    def setup(self):
        # RMPflow config files for supported robots are stored in the motion_generation extension under "/motion_policy_configs"
        mg_extension_path = get_extension_path_from_name("isaacsim.robot_motion.motion_generation")
        rmp_config_dir = os.path.join(mg_extension_path, "motion_policy_configs")

        # Initialize an RmpFlow object
        self._rmpflow = RmpFlow(
            robot_description_path=rmp_config_dir + "/franka/rmpflow/robot_descriptor.yaml",
            urdf_path=rmp_config_dir + "/franka/lula_franka_gen.urdf",
            rmpflow_config_path=rmp_config_dir + "/franka/rmpflow/franka_rmpflow_common.yaml",
            end_effector_frame_name="right_gripper",
            maximum_substep_size=0.00334,
        )
        self._rmpflow.add_obstacle(self._obstacle)

        # Use the ArticulationMotionPolicy wrapper object to connect rmpflow to the Franka robot articulation.
        self._articulation_rmpflow = ArticulationMotionPolicy(self._articulation, self._rmpflow)

        self._target.set_world_pose(np.array([0.5, 0, 0.7]), euler_angles_to_quats([0, np.pi, 0]))

    def update(self, step: float):
        # Step is the time elapsed on this frame
        target_position, target_orientation = self._target.get_world_pose()

        self._rmpflow.set_end_effector_target(target_position, target_orientation)

        # Track any movements of the cube obstacle
        self._rmpflow.update_world()

        # Track any movements of the robot base
        robot_base_translation, robot_base_orientation = self._articulation.get_world_pose()
        self._rmpflow.set_robot_base_pose(robot_base_translation, robot_base_orientation)

        action = self._articulation_rmpflow.get_next_articulation_action(step)
        self._articulation.apply_action(action)

    def reset(self):
        # Rmpflow is stateless unless it is explicitly told not to be

        self._target.set_world_pose(np.array([0.5, 0, 0.7]), euler_angles_to_quats([0, np.pi, 0]))

在第 22 行，向场景中添加了一个障碍物，并在第 40 行通过 RmpFlow 将其注册为障碍物。 在每一帧中，都会调用 RmpFlow.update_world()（第 56 行）。这会触发 RmpFlow 查询立方体的当前位置，以考虑任何移动。

在第 59-60 行，查询机器人基座的当前位置并将其传递给 RmpFlow。 此步骤与其他世界状态处理分开，因为 它通常是不必要的（当机器人基座始终位于原点时），或者此步骤可能需要额外考虑 （例如，RmpFlow 正在控制一个安装在移动基座上的机械臂）。

在前面的章节中，请注意 RmpFlow 初始化时需要五个参数。其中三个参数是必需配置文件的文件路径。 end_effector_frame_name 参数指定机器人上的哪个帧（来自所引用 URDF 文件中的帧）应被视为末端执行器。 maximum_substep_size 参数指定在内部执行欧拉积分时的最大步长。

对于 NVIDIA Isaac Sim 库中的机械臂，加载 RmpFlow 所需的适当配置信息可以在 isaacsim.robot_motion.motion_generation 扩展中找到。 这些信息按机器人名称索引，可以方便地访问。 以下更改展示了如何简化为支持的机器人加载配置的过程。

调试功能#

RmpFlow 类包含通常不在 Motion Policy Algorithm 接口中提供的调试功能。 这些调试功能允许将模拟器与 RmpFlow 算法解耦，以帮助诊断遇到的任何不良行为（RMPflow Debugging Features）。

RmpFlow 内部使用碰撞球体来避免与外部对象发生碰撞。这些球体可以通过 RmpFlow.visualize_collision_spheres() 函数进行可视化。 这有助于确定 RmpFlow 是否对模拟机器人具有合理的表示。

可视化功能可与 RmpFlow.set_ignore_state_updates(True) 标志配合使用，以忽略来自机器人 Articulation 的状态更新，并假定 RmpFlow 返回的机器人关节目标始终被完美执行。这导致 RmpFlow 计算出一条随时间变化的机器人路径，该路径独立于模拟机器人 Articulation。在每个时间步，RmpFlow 返回传递给机器人 Articulation 的关节目标。

总结#

本教程回顾了使用 RmpFlow 类生成针对动态环境的反应式运动。RmpFlow 类可以与 Articulation Motion Policy 直接配合使用以生成运动。

本教程回顾了 RmpFlow 的四个主要功能：

  1. 引导机器人穿过环境到达目标位置和姿态。

  2. 在每一帧适应动态世界。

  3. 适应 USD 舞台上机器人位置的变化。

  4. 使用可视化功能将模拟机器人 Articulation 与 RMPflow 算法解耦，以便快速轻松地进行调试。
