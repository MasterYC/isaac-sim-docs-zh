Contact 传感器#

Tool Reference

Deprecated since version 6.0: isaacsim.sensors.physics Contact Sensor 扩展已弃用。 请改用 isaacsim.sensors.experimental.physics.ContactSensor。 有关链接，请参见下方的 API Documentation 部分。

接触传感器使用物理张量 API (IRigidContactView) 生成类似于放置在物体表面的接触单元或基于压力的传感器的传感器读数。该路径同时适用于 PhysX 和 Newton：传感器通过张量接口从当前激活的物理引擎读取净接触数据和原始接触数据。

对于 PhysX，Contact.create() 仍然适用于父刚体 PhysxContactReportAPI，以便 PhysX 能够填充张量视图所消费的接触缓冲区。Newton 通过其张量后端直接暴露接触数据。

Contact Sensor API 提供按放置对象过滤的接触数据，并可选地提供仅考虑对象特定区域内接触的过滤器。例如，想象一个脚部装有传感器的四足机器人。虽然仿真将整个腿部视为刚体，但你只能测量脚垫上的接触，因此可以添加一个区域过滤器，丢弃该边界之外的接触。 Contact Sensor API 还提供持久性接触数据。虽然仿真提供关于接触的完整信息，如接触对、法线和接触点，但 Contact Sensor API 匹配由单单元接触垫获得的真实数据。如果你需要完整的接触数据，Contact Sensor API 会为你提供过滤后的接触信息。

有关 Isaac Sim 约定的完整列表，请参阅 Isaac Sim 约定 文档。

先决条件

  • 传感器必须创建在已启用的刚体祖先节点下（UsdPhysics.RigidBodyAPI 且 physics:rigidBodyEnabled 为 true，或 Rigid Body API 且无禁用覆盖）。

  • 产生接触的几何体需要碰撞 API（例如 Add > Physics > Rigid Body with Colliders Preset）。

  • 使用 Newton 时，对每个动态刚体应用 UsdPhysics.MassAPI 并分配非零质量。仅使用 RigidBodyAPI 无法提供默认 MuJoCo 求解器创建自由关节所需的质量。

接触传感器属性

  1. radius 参数指定传感器可检测到的接触力的距离。值为 -1 时使用 prim 的碰撞几何体。

  2. enabled 参数决定传感器是否正在运行。

  3. min threshold 参数指定触发接触所需的最小力。

  4. max threshold 参数指定传感器输出的最大力。

  5. sensorPeriod 参数指定传感器测量之间的时间间隔。自 isaacsim.robot.schema 6.2.0 起已弃用 — 仅由已弃用的 isaacsim.sensors.physics 扩展使用。新的 isaacsim.sensors.experimental.physics 扩展在每个物理步骤读取数据。

有关完整的 USD 属性定义，请参阅 Contact Sensor schema reference。

GUI#

创建和修改接触传感器#

准备一个带有碰撞体的刚体，然后将传感器附加到该刚体下。

  1. 通过 Create > Mesh > Cube 添加一个立方体，选中它，将其拖拽到原点上方，然后右键点击 Add > Physics > Rigid Body with Colliders Preset。

  2. 使用 Newton 时，对立方体应用 Add > Physics > Mass 并设置一个非零质量。

  3. 通过 Create > Physics > Physics Scene 创建一个物理场景。

  4. 通过 Create > Physics > Ground Plane 添加一个地面平面，以便立方体有可碰撞的表面。

  5. 选择立方体（或其他已启用的刚体 prim），然后通过 Create > Sensors > Contact Sensor 创建传感器。

  6. 要更改接触传感器的位置和方向，请使用 Translate 和 Orient 控件。

  7. 要更改其他接触传感器属性，请点击 Raw USD Properties 并修改最小/最大力阈值以及启用/禁用传感器等属性。

接触传感器示例#

要运行接触传感器示例：

  1. 从 Windows > Examples > Robotics Examples 激活 Robotics Examples 选项卡。

  2. 点击 Robotics Examples > Sensors > Contact Sensor。

  3. 确认您看到一个窗口，其中包含按每只蚂蚁的手臂颜色编码的传感器力读数。

  4. 点击 Open Source Code 按钮以查看源代码。该源代码演示了如何使用 Python API 将蚂蚁身体加载到场景中，并为其添加传感器。

  5. 按下 Play 按钮开始仿真。

  6. 按住 SHIFT + LEFT_CLICK 拖动蚂蚁，观察读数的变化。

OmniGraph 工作流#

以下教程演示了如何使用 OmniGraph 与接触传感器读数进行交互并进行可视化。

场景设置#

  1. 通过 Create > Mesh > Cube 在舞台上添加一个立方体，选中该立方体并将其向上拖动。然后选中立方体并右键单击 Add > Physics > Rigid Body with Colliders Preset。

  2. 通过 Create > Physics > PhysicsScene 添加物理场景。

  3. 通过 Create> Physics > GroundPlane 添加地面平面。

  4. 选中立方体，然后在顶部菜单中选择 Create > Sensors > Contact Sensor 以添加接触传感器。

OmniGraph 设置#

要设置 OmniGraph 以从该传感器收集读数：

  1. 通过导航至 Window > Graph Editors > Action Graph 并在打开的新选项卡中选择 New Action Graph 来创建新的动作图。

  2. 将以下节点添加到图中：

  • On Playback Tick：在每个模拟时间步执行图。

  • Isaac Read Contact Sensor：读取接触传感器。在 Property 选项卡中，将 Contact Sensor Prim 设置为 /World/Cube/Contact_Sensor，以指向接触传感器 prim 的位置。

  • To String：将接触传感器读数转换为字符串格式。

  • Print Text：将字符串读数打印到控制台。在 Property 选项卡中，将 Log Level 设置为 Warning，以便默认情况下在终端或控制台中可见消息。

  1. 按如下方式连接上述节点以打印接触传感器读数：

  2. 在 GUI 上按下 Play 按钮。如果设置正确，请验证 Isaac Sim 内部 Console 是否输出了接触传感器的力输出。

接触传感器可视化

您可以使用 Isaac xPrim Radius Visualizer Node 可视化接触传感器的位置和半径。将 xPrim 输入连接到接触传感器 prim，并将 Tick 连接到 Exec in。然后设置半径、颜色和线条粗细。按下 Play 后，接触传感器将会显示。

注意

球形区域仅确定被计数的接触的边界。所有接触仍然仅发生在由球形区域包围的物体表面上。

独立 Python#

创建和修改接触传感器#

对于以下示例代码片段，请使用以下代码片段准备场景，添加一个具有碰撞和刚体物理属性的 PhysicsScene、GroundPlane 和 Cube prim。 将接触传感器附加到后者。

from isaacsim import SimulationApp

simulation_app = SimulationApp({"headless": False})

import numpy as np
import omni.usd
from isaacsim.core.experimental.objects import Cube, GroundPlane
from isaacsim.core.experimental.prims import GeomPrim, RigidPrim
from pxr import UsdPhysics

# Create physics scene
stage = omni.usd.get_context().get_stage()
UsdPhysics.Scene.Define(stage, "/World/PhysicsScene")

# Add ground plane and a dynamic cube with collision and rigid body
GroundPlane("/World/groundPlane", sizes=10, colors=np.array([0.5, 0.5, 0.5]))
Cube(
    "/World/Cube",
    positions=np.array([-0.5, -0.2, 1.0]),
    scales=np.array([0.5, 0.5, 0.5]),
    colors=np.array([0.2, 0.3, 0.0]),
)
RigidPrim("/World/Cube")
GeomPrim("/World/Cube", apply_collision_apis=True)

使用 Python API#

通过调用 Contact.create()（authoring 类）并使用 ContactSensor 包装返回的 authoring 对象以访问运行时数据，从而使用 Python 创建接触传感器。可用参数及其默认值列于下方；路径必须包含父 prim 路径。

import numpy as np
from isaacsim.sensors.experimental.physics import Contact, ContactSensor

sensor = ContactSensor(
    Contact.create(
        "/World/Cube/Contact_Sensor",
        min_threshold=0.0001,
        max_threshold=100000,
        translations=np.array([[0.0, 0.0, 0.0]]),
    )
)

使用 Python 封装器#

接触传感器也可以通过直接构造 Contact authoring 对象并使用 ContactSensor 包装它来创建，以便访问运行时数据。Contact 构造函数会包装现有的传感器 prim 或使用默认属性创建一个新的；ContactSensor 运行时暴露了 get_sensor_reading()、get_data() 和 get_raw_data() 用于读取传感器输出。属性设置器（set_min_threshold / set_max_threshold / set_radius / 对应的获取器）位于 Contact authoring 对象上，构造后可通过 sensor.contact 访问。

import numpy as np
from isaacsim.sensors.experimental.physics import Contact, ContactSensor

sensor = ContactSensor(
    Contact(
        "/World/Cube/Contact_Sensor",
        translations=np.array([[0.0, 0.0, 0.0]]),
    )
)

注意

translations（局部坐标系）和 positions（世界坐标系）不能同时定义——它们是互斥的。

创建接触传感器需要一个已启用的刚体祖先节点。产生接触的几何体仍然需要碰撞 API。在 PhysX 上，Contact.create() 会在刚体祖先节点上应用 PhysxContactReportAPI，以便 PhysX 能够提供张量接触视图；在 Newton 上，该 PhysX 专用 API 会被跳过，因为 Newton 直接通过张量后端报告接触信息。你也可以通过以下方式手动为 prim 添加 Contact Report API（仅限 PhysX）：

stage = omni.usd.get_context().get_stage()
parent_prim = stage.GetPrimAtPath("/World/Cube")
contact_report = PhysxSchema.PhysxContactReportAPI.Apply(parent_prim)
# Set a minimum threshold for the contact report to zero
contact_report.CreateThresholdAttr(0.0)

要在运行时修改传感器参数，请使用通过 sensor.contact 暴露的 authoring 对象：sensor.contact.set_min_threshold(value)、sensor.contact.set_max_threshold(value)、sensor.contact.set_radius(value)。ContactSensor 本身上的旧版简写方法已在 3.0.0 版本中移除——请在 sensor.contact 上调用它们。

读取传感器输出#

接触传感器是在 Play 模式下动态创建的。在仿真运行期间移动传感器 prim 会使传感器失效。如果你需要对接触传感器进行层级更改（例如更改其刚体父节点），请停止仿真器，进行更改，然后重新启动仿真。

读取传感器输出有三种方法：

  • ContactSensor.get_sensor_reading() — 返回缓存的 ContactSensorReading

  • ContactSensor.get_data() — 返回结构化字典

  • OmniGraph 节点 Isaac Read Contact Sensor

以下代码片段假设你已使用上文中的两个代码片段之一创建了 /World/Cube prim 和接触传感器 prim。

ContactSensor.get_sensor_reading()

返回一个包含 is_valid、time、value（力的大小）和 in_contact 的 ContactSensorReading。

获取当前帧读数的示例用法：

from isaacsim.sensors.experimental.physics import ContactSensor

sensor = ContactSensor("/World/Cube/Contact_Sensor")
sensor.get_sensor_reading()

ContactSensor.get_data()

ContactSensor 运行时类上的 get_data() 成员函数返回一个结构化字典，其中包含 time、physics_step、in_contact、force 和 number_of_contacts。内部调用 get_sensor_reading() 获取接触状态，并调用 get_raw_data() 计算 number_of_contacts。当已调用 add_raw_contact_data_to_frame() 时，字典中还会额外包含一个 contacts 列表，其条目为每个接触点提供 body0、body1、position、normal 和 impulse。

使用示例：

import numpy as np
from isaacsim.sensors.experimental.physics import Contact, ContactSensor

sensor = ContactSensor(
    Contact(
        "/World/Cube/Contact_Sensor",
        translations=np.array([[0.0, 0.0, 0.0]]),
    )
)

value = sensor.get_data()
print(value)

ContactSensor.get_raw_data()

返回原始接触记录列表（当前物理步中的每个接触事件对应一条记录）。每条记录包含 time、dt、body0、body1、position、normal 和 impulse。原始数据忽略传感器的 min_threshold/max_threshold 过滤：低于阈值的接触仍会在此处报告，尽管它们会被过滤后的 ContactSensorReading 丢弃。若要改为传递至帧调用，请使用 ContactSensor.add_raw_contact_data_to_frame() 启用 contacts 列表。

from isaacsim.sensors.experimental.physics import ContactSensor

sensor = ContactSensor("/World/Cube/Contact_Sensor")
raw_data = sensor.get_raw_data()
print(str(raw_data))

API 文档#

自版本 6.0 起弃用： isaacsim.sensors.physics 扩展已弃用。请改用 isaacsim.sensors.experimental.physics.ContactSensor。

有关当前 API，请参阅 isaacsim.sensors.experimental.physics API 文档；有关已弃用的 API，请参阅 isaacsim.sensors.physics API 文档（已弃用）。
