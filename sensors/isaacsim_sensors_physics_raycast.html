物理射线检测传感器#

Tool Reference

物理射线检测传感器使用物理射线检测来测量传感器 prim 与周围几何体之间的距离。 与 Isaac Sim 中的固定模式传感器不同，物理射线检测传感器接受显式的每条射线原点偏移、方向向量以及可选的时间偏移，使其适用于广泛的配置，包括固态传感器、旋转传感器和光束幕。

在每个物理步骤中，传感器从 prim 的世界空间位置（加上每条射线的原点偏移）沿指定方向发射射线。 当提供 rayTimeOffsets 时，仅发射时间偏移落在当前物理步骤时间窗口内的射线子集，从而在多个步骤中产生扫描模式。

有关 Isaac Sim 约定的完整列表，请参阅 Isaac Sim 约定 文档。

物理射线检测传感器属性

  1. enabled 参数决定传感器是否正在运行。

  2. numRays（无符号整数）参数指定权威的射线数量。rayOrigins 和 rayDirections 必须各自包含恰好此数量的元素。使用 Raycast.create() 或 Raycast 编写构造函数时会自动设置此值。

  3. minRange 参数指定以 stage 长度单位表示的最小检测范围。射线从 origin + direction * minRange 开始。

  4. maxRange 参数指定以 stage 长度单位表示的最大检测范围。

  5. rayOrigins 参数指定在传感器局部坐标系中的每条射线原点平移。

  6. rayDirections 参数指定传感器局部坐标系中每条射线的投射方向向量。使用前会对向量进行归一化处理。

  7. rayTimeOffsets 参数指定每条射线的时间偏移量（单位：秒）。提供该参数时，传感器仅发射偏移量落在当前物理步长范围内的射线，从而实现扫描模式。扫描周期为 max(rayTimeOffsets)。

  8. outputFrameOfReference 参数选择命中位置和法线所使用的坐标系。SENSOR 以传感器局部坐标系返回结果；WORLD 以世界坐标系返回结果。

  9. reportHitPrimPaths 参数启用解析每个命中表面的 USD prim 路径。

有关完整的 USD 属性定义，请参阅 Raycast Sensor schema reference。

注意

所有传感器属性仅在仿真启动时读取一次。在仿真播放期间更改属性值无效；请停止并重启仿真以应用更改。

GUI#

创建物理射线投射传感器#

通过 GUI 创建物理射线投射传感器：

  1. 要创建 Physics Scene，请转到顶部菜单栏并点击 Create > Physics > Physics Scene。确认右侧的 Stage 面板中现在存在一个 PhysicsScene Prim。

  2. 可选：在 Stage 面板中选择一个父级 prim。

  3. 转到顶部菜单栏，点击 Create > Sensors > Physics Raycast Sensor，然后选择以下预设配置之一：

    • Solid State Physics Raycast Sensor：具有可配置水平和垂直视场角的矩形射线网格。

    • Rotating Physics Raycast Sensor：射线分布在 360 度范围内，带有时间偏移，以 1 Hz 的频率产生扫描图案。

    • Beam Curtain Physics Raycast Sensor：垂直分布的平行射线，用于接近检测。

  4. 要更改传感器的位置和方向，请选择传感器 prim，并在 Property 选项卡下修改 Transform 属性。

  5. 要更改传感器属性，请展开 Raw USD Properties 部分以修改范围、射线几何形状和输出帧设置。

物理射线投射传感器示例#

要运行物理射线投射传感器示例：

  1. 从 Windows > Examples > Robotics Examples 激活 Robotics Examples 选项卡。

  2. 点击 Robotics Examples > Sensors > Physics Raycast Sensor > Load Scene。

  3. 验证是否创建了三个物理射线投射传感器：固态传感器（绿色射线）、旋转传感器（蓝色射线）和光束幕传感器（红色射线）。

  4. 按下 Play 按钮开始仿真。

  5. 观察视口中的调试射线可视化效果，以及示例窗口中的命中次数 / 最小深度读数。

OmniGraph 工作流#

以下教程介绍如何使用 OmniGraph 读取并可视化物理射线投射传感器数据。

场景设置#

  1. 通过 Create > Physics > Physics Scene 创建物理场景。

  2. 添加碰撞几何体（例如，Create > Mesh > Cube 并应用 Add > Physics > Colliders Preset）。

  3. 通过 Create > Physics > GroundPlane 添加地面平面。

  4. 通过 Create > Sensors > Physics Raycast Sensor > Solid State Physics Raycast Sensor 创建物理射线投射传感器。

OmniGraph 设置#

要设置 OmniGraph 以从该传感器收集读数：

  1. 通过导航至 Window > Graph Editors > Action Graph 并在新打开的选项卡中选择 New Action Graph 来创建新的动作图。

  2. 向图中添加以下节点：

    • On Playback Tick (omni.graph.action.OnPlaybackTick)：在每个模拟时间步执行图。

    • Isaac Read Physics Raycast Sensor (isaacsim.sensors.physics.IsaacReadRaycastSensor)：读取物理射线投射传感器。在 Property 选项卡中，将 Physics Raycast Sensor Prim 设置为传感器 prim 的路径（例如，/World/Sensors/Solid_State_Physics_Raycast_Sensor）。

    • Debug Draw RayCast (isaacsim.util.debug_draw.DebugDrawRayCast)：在视口中可视化射线。

  3. 配置 Debug Draw RayCast 节点：

    • 将 inputs:doTransform 设置为 False。读取节点已经提供了世界空间中的光束起点和终点；应用额外的变换会导致可视化结果不正确。

  4. 使用 全部五个 必需连接来连接节点：

    • On Playback Tick outputs:tick → Isaac Read Physics Raycast Sensor inputs:execIn

    • Isaac Read Physics Raycast Sensor outputs:execOut → Debug Draw RayCast inputs:exec

    • Isaac Read Physics Raycast Sensor outputs:beamOrigins → Debug Draw RayCast inputs:beamOrigins

    • Isaac Read Physics Raycast Sensor outputs:beamEndPoints → Debug Draw RayCast inputs:beamEndPoints

    • Isaac Read Physics Raycast Sensor outputs:numRays → Debug Draw RayCast inputs:numRays

    重要

    numRays 连接是必需的。如果没有它，Debug Draw 节点将默认使用 0 条射线，从而不渲染任何内容。同样，doTransform 必须设置为 False，因为读取节点提供的光束起点和终点已经处于世界坐标系中。

  5. 按下 Play 按钮。如果设置正确，视口中将显示从传感器到命中点的射线。

以编程方式设置 OmniGraph#

可以使用 og.Controller 以编程方式创建相同的图：

# Programmatic OmniGraph setup: Physics Raycast Sensor + Debug Draw visualization
import omni.graph.core as og

sensor_prim_path = "/World/Sensors/Solid_State_Physics_Raycast_Sensor"

action_graph, _, _, _ = og.Controller.edit(
    {"graph_path": "/World/ActionGraph", "evaluator_name": "execution"},
    {
        og.Controller.Keys.CREATE_NODES: [
            ("OnPlaybackTick", "omni.graph.action.OnPlaybackTick"),
            ("ReadRaycast", "isaacsim.sensors.physics.IsaacReadRaycastSensor"),
            ("DebugDraw", "isaacsim.util.debug_draw.DebugDrawRayCast"),
        ],
        og.Controller.Keys.SET_VALUES: [
            ("ReadRaycast.inputs:raycastSensorPrim", sensor_prim_path),
            ("DebugDraw.inputs:doTransform", False),
        ],
        og.Controller.Keys.CONNECT: [
            ("OnPlaybackTick.outputs:tick", "ReadRaycast.inputs:execIn"),
            ("ReadRaycast.outputs:execOut", "DebugDraw.inputs:exec"),
            ("ReadRaycast.outputs:beamOrigins", "DebugDraw.inputs:beamOrigins"),
            ("ReadRaycast.outputs:beamEndPoints", "DebugDraw.inputs:beamEndPoints"),
            ("ReadRaycast.outputs:numRays", "DebugDraw.inputs:numRays"),
        ],
    },
)

注意

与可能导致可视化失败的简单设置相比，主要区别如下：

  • ``doTransform`` 必须为 False：读取节点输出的是世界空间坐标。Debug Draw 节点的 doTransform 输入默认会应用额外的矩阵变换，这会导致射线被移动到错误的位置。

  • ``numRays`` 必须连接：如果不连接，绘制节点将不知道要渲染多少条射线，并默认值为零。

  • 执行链必须完整：execIn → execOut → exec 确保绘制节点在读取节点填充其输出之后触发。

独立 Python#

创建物理射线投射传感器#

对于以下示例代码片段，请使用以下代码片段准备场景，添加一个 PhysicsScene、碰撞几何体以及一个传感器父级 Xform。

import omni.usd
from pxr import Gf, Sdf, UsdGeom, UsdPhysics

stage = omni.usd.get_context().get_stage()

UsdGeom.SetStageUpAxis(stage, UsdGeom.Tokens.z)
UsdGeom.SetStageMetersPerUnit(stage, 1.0)

UsdPhysics.Scene.Define(stage, Sdf.Path("/World/PhysicsScene"))

ground = UsdGeom.Cube.Define(stage, "/World/GroundPlane")
ground.GetSizeAttr().Set(1.0)
ground.AddTranslateOp().Set(Gf.Vec3d(0, 0, -0.05))
ground.AddScaleOp().Set(Gf.Vec3f(50, 50, 0.1))
UsdPhysics.CollisionAPI.Apply(ground.GetPrim())

wall = UsdGeom.Cube.Define(stage, "/World/Obstacles/Wall")
wall.GetSizeAttr().Set(1.0)
wall.AddTranslateOp().Set(Gf.Vec3d(5, 0, 1.5))
wall.AddScaleOp().Set(Gf.Vec3f(0.2, 8, 3))
UsdPhysics.CollisionAPI.Apply(wall.GetPrim())

UsdGeom.Xform.Define(stage, "/World/Sensors")

使用 Python API#

物理射线投射传感器通过 Raycast.create()（编写类）创建，返回的编写对象会包装在 RaycastSensor 中以便在运行时访问数据。您必须提供长度相同的 ray_origins 和 ray_directions 数组。路径必须包含父级 prim 路径。

import math

from isaacsim.sensors.experimental.physics import Raycast, RaycastSensor

# Generate a simple grid of ray directions for a solid state physics raycast sensor.
h_count, v_count = 10, 5
h_fov, v_fov = 60.0, 20.0
origins = []
directions = []
for vi in range(v_count):
    v_angle = math.radians(-v_fov / 2 + v_fov * vi / max(v_count - 1, 1))
    for hi in range(h_count):
        h_angle = math.radians(-h_fov / 2 + h_fov * hi / max(h_count - 1, 1))
        dx = math.cos(v_angle) * math.cos(h_angle)
        dy = math.cos(v_angle) * math.sin(h_angle)
        dz = math.sin(v_angle)
        origins.append([0.0, 0.0, 0.0])
        directions.append([dx, dy, dz])

sensor = RaycastSensor(
    Raycast.create(
        "/World/Sensors/Physics_Raycast_Sensor",
        min_range=0.4,
        max_range=100.0,
        ray_origins=origins,
        ray_directions=directions,
        output_frame="WORLD",
        translations=[[0.0, 0.0, 1.5]],
    )
)

使用时间偏移#

要创建具有扫描模式的传感器，请提供 ray_time_offsets。仅当射线的时间偏移落在当前物理步的时间窗口内时，才会发射射线。扫描周期等于 max(ray_time_offsets)。

import math

from isaacsim.sensors.experimental.physics import Raycast, RaycastSensor

# Generate rays for a rotating physics raycast sensor with time offsets.
# Each azimuthal column is assigned a time offset within the sweep period.
# Only rays whose offsets fall in the current physics step are fired.
v_count = 8
azimuth_steps = 36
v_fov = 30.0
rotation_rate = 1.0
period = 1.0 / rotation_rate

origins = []
directions = []
time_offsets = []
for ai in range(azimuth_steps):
    h_angle = math.radians(360.0 * ai / azimuth_steps)
    t_offset = period * ai / azimuth_steps
    for vi in range(v_count):
        v_angle = math.radians(-v_fov / 2 + v_fov * vi / max(v_count - 1, 1))
        dx = math.cos(v_angle) * math.cos(h_angle)
        dy = math.cos(v_angle) * math.sin(h_angle)
        dz = math.sin(v_angle)
        origins.append([0.0, 0.0, 0.0])
        directions.append([dx, dy, dz])
        time_offsets.append(t_offset)

sensor = RaycastSensor(
    Raycast.create(
        "/World/Sensors/Rotating_Physics_Raycast_Sensor",
        min_range=0.4,
        max_range=100.0,
        ray_origins=origins,
        ray_directions=directions,
        ray_time_offsets=time_offsets,
        output_frame="WORLD",
        translations=[[0.0, 0.0, 1.5]],
    )
)

使用 RaycastSensor 运行时#

RaycastSensor 类封装了现有的 Raycast authoring 对象或现有的 IsaacRaycastSensor prim，用于运行时数据访问。使用 Raycast.create() 配置并创建新的 prim。

from isaacsim.sensors.experimental.physics import Raycast, RaycastSensor

sensor = RaycastSensor(
    Raycast.create(
        "/World/Sensors/My_Sensor",
        ray_origins=[[0, 0, 0], [0, 0, 0]],
        ray_directions=[[1, 0, 0], [0, 1, 0]],
        min_range=0.4,
        max_range=100.0,
        output_frame="WORLD",
    )
)

# After simulation starts:
frame = sensor.get_data()
print(f"Depths: {frame['depths']}")
print(f"Hit positions: {frame['hit_positions']}")

读取传感器输出#

物理射线投射传感器在 Play 时动态创建。使用 RaycastSensor.get_sensor_reading() 读取原始传感器数据，或使用 RaycastSensor.get_data() 获取结构化字典。读取结果包括深度、命中位置、命中法线，以及可选的命中 prim 路径。

以下代码片段假设你已使用上述代码片段之一创建了传感器 prim。

from isaacsim.sensors.experimental.physics import Raycast, RaycastSensor

sensor = RaycastSensor(
    Raycast.create(
        "/World/Sensors/Physics_Raycast_Sensor",
        ray_origins=[[0.0, 0.0, 0.0]],
        ray_directions=[[1.0, 0.0, 0.0]],
    )
)
reading = sensor.get_sensor_reading()

if reading.is_valid:
    print(f"Ray count: {reading.ray_count}")
    print(f"Depths: {reading.depths}")
    print(f"Hit positions: {reading.hit_positions}")
    print(f"Hit normals: {reading.hit_normals}")

get_sensor_reading() 函数返回一个 RaycastSensorReading 对象，具有以下属性：

  • is_valid：读取结果是否包含有效数据。

  • ray_count：读取结果中的射线数量。

  • time：此读取结果的模拟时间（秒）。

  • depths：每条射线的命中距离，单位为 stage 长度单位。未命中的射线返回 maxRange。

  • hit_positions：每条射线的命中位置，作为 Nx3 数组，位于 outputFrameOfReference 指定的坐标系中。

  • hit_normals：命中点处每条射线的表面法线，作为 Nx3 数组。

  • hit_prim_paths：命中表面每条射线的 USD prim 路径（仅在启用 reportHitPrimPaths 时填充）。

  • ray_origins_world：每条射线在世界空间中的起点，作为 Nx3 数组。

  • ray_end_points_world：每条射线在世界空间中的终点，作为 Nx3 数组（适用于调试可视化）。

get_data() 函数返回一个结构化字典，包含 depths、hit_positions、hit_normals、hit_prim_paths、time 和 physics_step。ray_origins_world 和 ray_end_points_world 仅在原始 get_sensor_reading() 结果中可用。
