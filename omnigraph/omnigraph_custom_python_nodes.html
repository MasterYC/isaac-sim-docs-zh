自定义 Python 节点#

Tool Reference

Isaac Sim 自带了大量默认节点。您可以在 OmniGraph 节点库 或 API 文档 中查找它们的定义和说明。如果这些默认节点无法满足需求，您可以编写自己的节点并将其集成到 Isaac Sim 中。

节点由两个文件定义：一个是 .ogn 文件，这是一个 JSON 文件，用于定义节点的结构，包括其输入、输出和参数。另一个可以是 Python 文件或 C++ 文件，用于定义节点的功能。本文将重点介绍 Python 节点。

节点文件#

所有 OmniGraph 节点文件均以“Ogn”作为前缀开头。解析器要求遵循此命名规范。

节点定义 (.ogn)#

.ogn 文件是一个 JSON 文件，用于定义节点的结构，包括其输入、输出和参数。以下是一个简单节点定义的示例：

 1{
 2 "NodeName": {
 3     "version": 1,
 4     "categories": "examples",
 5     "description": ["Minimum Example"],
 6     "language": "python",
 7     "metadata": {
 8         "uiName": "minimum example"
 9     },
10     "inputs": {
11                        "execIn": {
12             "description": "the trigger input that starts the node",
13             "type": "execution",
14         },
15                        "value_input": {
16             "type": "double",
17             "description": "a number",
18             "default": 0.0,
19          },
20     },
21     "outputs": {
22         "output_bool": {
23             "type": "bool",
24             "description": "let output be a boolean",
25          }
26      }
27   }
28}

关于输入“execIn”的说明。这是一个特殊输入，用于触发节点。此触发仅在 Action Graph 中相关，在该图中，你必须显式触发节点以运行，例如在物理 tick 或阶段事件（如打开和关闭阶段）时。在 Push Graph 中，节点将在每一帧自动运行，因此不需要“execIn”输入。

函数定义#

以下是一个 Python 节点的最小示例，该节点接受一个数字输入，并根据输入是否大于 0 输出一个布尔值：

class OgnNodeName:
    @staticmethod
    def compute(db):
        db.outputs.out = bool(db.inputs.value_input > 0.0)
        return True

注意：

  • 类名必须与 .ogn 文件中的节点名称匹配，且文件名必须与类名匹配。

  • “compute”函数是由“execIn”输入触发的。它接受一个参数，即数据库，其中包含节点的输入和输出。如果节点成功运行，该函数应返回 True，如果失败则返回 False。

  • 此节点没有内部状态，这意味着通过它的所有数据在下一个 tick 都会丢失。如果你需要在 tick 之间存储数据，可以使用“内部状态”来存储。

使用自定义节点#

你可以简单地将自定义节点的 .py 和 .ogn 文件插入到任何已包含现有节点的 .py 和 .ogn 文件的扩展中，从而避免创建自己的扩展。

你也可以创建自己的扩展并将文件插入其中。（链接到新模板生成器）

Isaac Sim 节点示例#

欢迎深入研究我们现有 OmniGraph 节点背后的代码，以查找如何构建节点的示例，甚至可以根据自身需求对其进行修改。若要查找特定节点的后端 .py 和 .ogn 文件，请将鼠标悬停在编辑器窗口中的节点上，此时会显示一个工具提示窗口，括号内会注明扩展的名称。然后，你可以导航到包含节点后端脚本的扩展文件夹，路径为 exts/isaacsim.<ext_name>/isaacsim/<ext_name>/ogn/python/nodes/。

并非所有节点都使用 Python 编写，部分节点具有 C++ 后端，因此你可能不会在列表中的所有节点上看到对应的 .py 和 .ogn 文件。请注意，如果你找到一个包含 Ogn<node_name>Database.py 列表的文件夹，该目录并不包含节点的 Python 描述。
