教程 5：装配移动机器人#

Tutorial

如果您在 Omniverse USD Composer 中构建了机器人，或者使用了不保留关节信息的导入器，则需要在机器人能够像关节机器人一样移动并受 Isaac Sim API 控制之前对其进行装配（rig）。这包括定义身体部件之间的关节类型，以及设置控制关节行为的参数，例如刚度和阻尼。本教程将逐步介绍如何装配叉车。

学习目标#

在本教程中，一个未装配的叉车 USD 资产将被转换为可以移动并由 Isaac Sim 命令驱动的叉车。

30 分钟教程

入门指南#

先决条件

  • 完成 Isaac Sim 基础 系列，学习在 Isaac Sim 中导航的基本核心概念。

  • 完成 组装简单机器人 和 添加传感器和相机 教程，学习刚体 API、碰撞 API、关节、驱动器和关节体（articulations）的概念。

参考 USD

我们在此教程的 Isaac Sim Assets 中提供了相关的 USD 资产，可在 Content Browser 中找到。

  • 未绑定骨架的叉车：Isaac Sim/Samples/Rigging/Forklift/forklift_b_unrigged_cm.usd

  • 已绑定骨架的叉车：Isaac Sim/Samples/Rigging/Forklift/forklift_b_rigged_cm.usd

本教程将指导您完成从文件到文件的各个步骤。已绑定骨架的资产可作为最终目标的参考。

为机器人绑定骨架#

识别关节#

在对资产进行任何修改之前，为机器人绑定骨架的第一步是识别机器人上的关节，包括驱动关节和非驱动关节。关节决定了所有网格组件的组织方式，识别关节类型及其自由度（DOF）对于确保机器人在绑定骨架后按预期运动至关重要。

对于叉车，总共有七个自由度：

  • 前部有四个较小的滚轮。它们具有非驱动的旋转关节，每个关节都有一个绕单轴旋转的自由度。

  • 叉相对于叉车主体做线性运动，上下移动以拾取堆放在托盘上的物体，这意味着叉与主体之间有一个驱动的棱柱关节。

  • 后端的较大车轮负责驱动叉车前进并使其转向。与该车轮相关的有两个驱动关节：

    • 一个旋转关节，使车轮绕其中心轴旋转，从而提供前后移动。

    • 一个位于后轮轴距与叉车主体之间的旋转关节，提供使叉车转向的枢轴。

组织层级结构#

从 Content Browser 中打开未绑定的叉车资产：Isaac Sim/Samples/Rigging/Forklift/forklift_b_unrigged_cm.usd。 根据所使用的导入器以及原始资产的设置，USD 中未绑定结构的部件组织方式可能没有层级关系。它可能在 stage tree 上独立列出每一个组件。这使得读取和导航变得困难，但更重要的是，它没有定义哪些对象是作为一组移动的，以及这些组之间如何相互关联。

作为父级 prim 子级的所有网格，在父级 prim 移动时预期会一起移动。例如，网格上的贴纸和链条是叉车主体的一部分，而整个主体，无论由多少螺丝或块组成，都可以被视为该机器人的一个连杆。将它们全部组织在一个名为 ‘body’ 的父级 prim 下。这确保了当 ‘body’ 移动时，构成主体的所有子部件都会一起移动。

要组织叉车的 prims：

  1. 创建两个名为 body 和 lift 的 XForms。

  2. 将所有构成叉车车身的网格移动到 body Xform 下，并将操作员驾驶室网格移动到 lift Xform 下。为了便于使用，USD 文件中提供的网格已按其层级结构排序。Looks 上方的所有网格都属于 lift XForm。Looks 下方（从 Right Chain Wheel 到 Body Glass）的网格属于 body XForm。其余网格用于底盘和车轮。

  3. 为 back wheel、back wheel swivel 以及每个前滚轮支撑创建新的 Xform 和独立的 prim。

  4. 为四个前滚轮车轮分别创建新的 Xform。将它们命名为 roller_front_left、roller_front_right、roller_back_left 和 roller_back_right。将正确的引导轮网格和圆柱体碰撞体移动到它们下面。

  5. 确保上述所有 Xform 的物理属性设置为刚体，方法是点击 Add > Physics > Rigid Body。

    注意

    刚体 prim 不能包含也是刚体的子级。

  6. 如果将 Xform 的框架与各自车轮的框架对齐，则更容易设置关节。为此，对于每个车轮，选择网格，并在其属性选项卡的 Transform 下，有两个组件 Translate 和 Translate:pivot。新创建的 Xform 的变换必须是这两个组件的总和。例如，如果 translate 位于 \(X=x_1, Y=y_1, Z=z_1\)，且 translate:pivot 位于 \(X=x_p, Y=y_p, Z=z_p\)，则新创建的 Xform 的变换必须设置为：\(X = x_1+ x_p , Y = y_1 + y_p , Z = z_1 + z_p\)。

  7. Translate 需要设置为对应网格体 Translate:pivot 属性的逆值。例如，如果 Translate 为 \(X, Y, Z\) 且 Translate:pivot 为 \(X_p, Y_p, Z_p\)，则将平移设置为 \(-X_p, -Y_p, -Z_p\)。

  8. 将对应的网格体移动到 XForm 下，这将定义它们之间的父子关系。

分配碰撞网格体#

确保网格体的碰撞属性设置正确。如果未设置碰撞属性，则当机器人移动时，根据关节配置，它可能会发生自穿透。

对于提供的 USD，车身和升降台的正确碰撞网格体已经设置好，因此您无需手动设置。 但作为参考，为 SM_Forklift_Body_B01_01 设置碰撞的步骤如下：

  1. 在 lift Xform 下选择 SM_Forklift_OperatorCab_B01_01 网格体，右键单击并选择 Add > Physics > Collider Preset。默认的碰撞近似方法是 Convex Hull，您可以在所选网格体的属性选项卡下滚动找到碰撞部分来查看此设置。

  2. 要可视化碰撞体，请点击视口右上角附近的眼睛图标，选择按类型显示 Type > Physics > Colliders > Selected。验证当你选择刚添加到碰撞中的网格时，是否能看到粉色轮廓。这种近似方法不合适，因为碰撞区域覆盖了不属于叉齿的大片区域，而这些区域需要允许其他对象存在。

  3. 可以使用不同的近似方法来定义不同的碰撞网格。要查看这一点，请选择一个带有碰撞的网格，并导航到其属性面板的碰撞体部分。选择 Convex Decomposition 近似方法。更新碰撞网格的可视化效果。验证此次生成的网格由于具有更紧密的近似，因此覆盖了更多的可碰撞表面。尝试其他近似方法，看看哪种最适合你。

对使用关节相互交互的其他网格遵循相同的过程。为作为旋转部件一部分的 SM_Forklift_BackWheelbase_B01_01 网格设置 Convex Decomposition 近似方法。

车轮的处理过程略有不同，任何不平滑且精确捕捉车轮形状和曲率的碰撞近似方法，在尝试驱动车轮时都会导致颠簸运动。通过使用圆柱体来近似碰撞网格可以避免这种情况。

  1. 转到 Create > Shape > Cylinder。

  2. 将缩放设置为 X=0.16、Y=0.16、Z=0.08`,` and Orient along ``Y=90。

  3. 右键单击并创建此圆柱体的四个副本，每个前滚轮对应一个。

  4. 将圆柱体拖到各自车轮的 Xform 下，并将它们在所有轴上的变换更改为 0。这可以使圆柱体轴与 Xform 轴完全对齐。

  5. 右键单击圆柱体，然后选择 Add > Physics > Collider。

  6. 对后轮执行相同操作，由于其尺寸较大，请将圆柱体的缩放比例修改为 X=0.3、Y=0.3、Z=0.1，并沿 Y=90 方向进行定向。

所有适当的碰撞网格和属性均已设置完毕，您可以继续添加关节。

添加关节和驱动器#

在此步骤中，为叉车添加适当的关节。

棱柱关节

第一个关节是叉车车身与货叉之间的关节。两个刚体之间需要线性运动，且货叉必须相对于叉车车身上下移动。

  1. 选择 lift Xform，同时按住 Ctrl 键选择 body Xform。当两个图元被高亮显示时，右键单击并选择 Create > Physics > Joints > Prismatic Joint。

  2. 找到新创建的棱柱关节并选中它。在属性选项卡下，将轴设置为 Z 轴，这表示两个刚体之间的线性运动沿 Z 轴方向。

  3. 在 Property > Physics > Prismatic Joint 选项卡中设置关节的下限和上限，目前将其设置为 -15 和 200。

  4. 通过左键单击该关节并选择 Add > Physics > Linear Drive，为此关节添加线性驱动器。

  5. 在 Property > Physics > Drive > Linear 选项卡中，将目标位置（target position）设置为 -15，以便货叉可以从靠近地面的初始位置开始，并将阻尼（Damping）设置为 10000，刚度（Stiffness）设置为 100000。

  6. 右键单击舞台（stage）创建一个 Scope，并将其命名为 lift_joint。将棱柱关节（prismatic joint）拖入该 Scope 下。

旋转关节（Revolute Joints）

为所有滚轮支撑轮创建旋转关节：

  1. 选择 body XForm，按住 Ctrl 键并选择任意一个滚轮 XForm。右键单击 Create > Physics > Joint > Revolute Joint。确认在车轮的 Xform 下已添加旋转关节。

  2. 确认关节出现在预期位置。如果不是，请确保关节位置与车轮的旋转轴匹配，并确保将旋转轴设置为“X”。

  3. 对叉车剩余的三个滚轮支撑执行相同操作。

  4. 右键单击舞台（stage）创建一个 Scope，并将其命名为 roller_joints。将滚轮关节拖入该 Scope 下。

接下来，添加最后两个关节，它们负责驱动和转向叉车：

  1. 选择 back_wheel_swivel 和 back_wheel XForm，并在它们之间添加一个旋转关节。此关节的位置必须与后轮中心匹配。

  2. 为此关节添加一个角度驱动器（angular drive），属性如下：Damping=10000、stiffness = 100。

  3. 选择 body 和 back_wheel_swivel XForm，并在它们之间添加一个旋转关节。确保旋转轴设置为 Z。

  4. 将关节的轴更改为 Z 轴，并将上限和下限设置为 -60 和 60，因为此关节用于实现叉车的转向。这是轴距旋转的角度范围（以度为单位）。

  5. 添加一个角驱动，其属性如下：Damping = 100，stiffness = 100000。

  6. 转到 Create > Scope，将其命名为 back_wheel_joints，并将后轮关节拖入该 Scope 下。

  7. 在按下 Play 之前，请务必添加 Physics Scene 和 Ground Plane。

添加 Articulations#

最后一步是为叉车添加 articulation，并将所有关节放入单个 articulation 链中，这有助于物理求解器更高效地求解机器人等 articulated 对象。在参考 USD 资产中，该 prim 已预先添加了此设置。如果尚未添加，请选择并右键单击 ‘SMV_Forklift_B01_01’ Xform，然后选择 Add > Physics > Articulation Root。在属性中，取消选中 Self collision 复选框。

关于 articulation root 的放置位置，有几点需要注意。

如果将 articulation root 放置在资产的根 Xform prim 上（这是所有 Isaac Sim 资产的标准做法），则模拟会自动将 articulation root 分配给机器人中的某个 rigid body，从而最小化 articulation 树的深度。

但是，如果您希望手动确定 articulation root 的位置，请将其分配给机器人的某个 rigid body 组件。建议将 articulation root 放置在移动机器人的 base 或 chassis 上，或者放置在机械臂的固定 joint 上。

验证您拥有的资产是否与提供的 Rigged Forklift 资产类似。

将资产转换为不同的单位#

原始资产单位为厘米。当资产被添加到以米为单位的场景中时，它会自动转换为米（参见 Metrics Assembler）。将资产添加到 stage 时，它必须与提供的 Rigged Forklift in Meters 资产相匹配。

现在您可以尝试操作 Forklift，在 joint 的 Angular Drive 部分将后轮速度设置为 -200。按下 play 后，验证您是否可以看到叉车向前移动。

总结#

在本教程中，您对一个未绑定骨骼的叉车 USD 资产执行了以下操作：

  • 整理了其结构

  • 添加了碰撞体、joint 和 drive

  • 将其转换为可由 Isaac Sim 命令驱动的、能够移动的叉车

故障排除提示#

如果在播放模拟或经过一些运动后，您的机器人发生爆炸，请检查是否有任何 collision mesh 相互碰撞。
