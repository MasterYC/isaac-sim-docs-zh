版本说明#

6.1.0 正式版#

版本亮点#

常规更新#

  • 将 Isaac Sim 更新至 Kit SDK 110.3.0。

  • 在 SimulationApp 中添加了 active_cuda_gpus，用于按 CUDA 设备顺序选择渲染 GPU，并将默认 CPU 线程限制从 32 减少到 16。

PhysX 和 Newton#

  • 将实验性 Newton 集成更新至 Newton 1.5.0。

  • 添加了对 Newton 求解器的支持，包括顶点块下降法 (VBD) 和扩展位置基动力学 (XPBD)。

  • 添加了对弹性流体接触的支持。

  • 添加了用于使用 MuJoCo 和 Newton 模式创建机器人的 UI 工作流。

  • 扩展了张量 API，以提高与 PhysX 后端的对等性，并增强 PhysX 与 Newton 之间的互操作性。

  • 修复了可用性问题，并缩小了 Newton 与 PhysX 后端之间的行为差异。

合成数据生成#

感知数据生成 (Replicator)#

  • 添加了一个使用 NVIDIA 3D 物体重建资产的合成数据生成 (SDG) 示例。

  • 将 UR10 码垛和行为随机化示例迁移至 Replicator 函数式 API 和 isaacsim.core API。

动作和事件数据生成#

  • 角色模拟与合成数据生成 (isaacsim.replicator.agent)

    • 添加了显式的生成位置和朝向，用于固定角色和机器人的起始姿态。您可以在组面板中编辑这些值。

    • 将传感器组放置设为可选，并添加了 push_cart 示例配置。

    • 添加了一个使用 RTX 后处理的视觉噪声和图像退化示例。

    • 通过 isaacsim.anim.robot 更新了基于 Fabric 的机器人动画。

  • 物体模拟与合成数据生成 (isaacsim.replicator.object)

    • 改进了装箱算法，实现了重力稳定放置、更多样化的布局以及可选的填充率。

    • 提高了标注器输出的稳定性以及与 Kit SDK 110 的兼容性。

  • 物理空间事件生成 (isaacsim.replicator.incident)

    • 在语义分割输出中包含了泄漏液体。

  • 视觉语言模型 (VLM) 场景描述 (isaacsim.replicator.caption)

    • 改进了相机选择，并在 UI 和 CaptionAPI 中公开了描述模型设置。

  • 基于 AI 的行为树生成 (omni.ai.behavior_tree_gen)

    • 提高了场景规划和树生成的准确性与稳定性。

  • 基于 AI 的场景生成 (omni.ai.langchain.agent.chat_iro)

    • 添加了对用户提供的模型和端点的支持，包括 OpenAI 兼容端点和自托管的 NVIDIA NIM 部署。

  • 传感器放置与校准 (isaacsim.sensors.rtx.placement 和 isaacsim.sensors.rtx.calibration)

    • 提高了最大覆盖相机放置的准确性。

  • 在 skills/ 下新增了十一个用于运行规划、配置扫描、相机放置、事件生成、装箱和场景描述的动作与事件数据生成代理技能。

  • 为动作与事件数据生成工具集添加了遥测功能，用于监控系统效率和行为趋势。

遥操作合成数据生成#

  • 添加了基于物理速度的运动控制、MCAP 录制与回放、配置驱动的浮动夹爪、共享的 Kit OpenXR 和 CloudXR 会话，以及针对非 VR 和调试工作流的 Windows 支持。

  • 添加了类型化的实时和 MCAP 输入提供程序以及跨平台功能发现。

机器人#

  • 添加了 SO-101 系统辨识 (SysID) 以及 Clearpath A300、J100 和 DO100 机器人。

  • 扩展了 URDF 和 MJCF 导入器，以导入更多 Newton 参数。

  • 通过大量错误修复提高了 URDF 导出器的可靠性。

  • 扩展了增益调谐器 (Gain Tuner)，以支持 PhysX 和 Newton 后端、调谐 Newton 执行器以及编辑高级关节驱动参数。

  • 添加了 Beta 版系统辨识工具，用于在无头模式和交互模式下优化机器人仿真参数。

  • 扩展了导出的机器人策略部署，支持 ONNX、导出的执行器配置、观测历史以及 PhysX 和 Newton 示例。

  • 添加了虚拟龙门架 (Virtual Gantry) 运行时、架构和用户界面，用于在使用 PhysX 或 Newton 进行初始化和策略测试期间悬挂机器人。

传感器#

相机与深度传感器#

  • 新增了一个相机制作教程，演示如何创建具有镜头畸变、tick 率、分辨率和支持输出功能的可复用相机资产。您可以将生成的资产添加到机器人或环境中，用于合成数据生成和软件在环（SIL）工作流。

  • 更新了 SingleViewDepthSensor，以封装使用现有用户定义渲染产品的深度传感器。

  • 扩展了 SICK 和 Luxonis 资产的传感器目录文档。

  • 修复了 RtxCamera 和 CameraSensor API 中的若干问题。

RTX 非视觉传感器#

  • 新增了传感器处理图（SPG）制作 API。

  • 新增了根据元数据（如强度和径向速度）对 RTX LiDAR 和 Radar 点云进行视口着色的功能。

  • 减少或消除了在不同传感器模态或 tick 率下运行以及长时间仿真期间出现的 CUDA 错误。

  • 修复了 isaacsim.sensors.experimental.rtx API 中的若干问题。

  • 为惯性测量单元（IMU）和接触传感器添加了 Newton 支持，并提高了接触、力和惯性传感器的正确性与性能。

桥接#

ROS 2#

  • 通过新的 isaacsim.ros2.control 扩展添加了 ROS 2 Control 支持。其进程内、物理驱动的 Controller Manager 支持 ROS 2 Humble 和 Jazzy、PhysX 和 Newton、多机器人、传感器、mimic joints 以及生成的 URDF。

  • 新增将兼容的变换（TF）发布者聚合为每帧单个合并 TFMessage 的功能，从而减少 ROS 2 发布调用的数量。

  • 为 Python 启动器添加了自动捆绑的 ROS 2 环境设置。使用 --no-ros-env 可选择退出。

  • 添加了支持硬件加速编码的 ROS 2 高效视频编码 (HEVC)/H.265 压缩 RGB 图像发布功能。

  • 添加了公共点云实用工具。

Isaac Sim ROS Workspaces 仓库#

  • 将仓库拥有的启动文件从 Python 迁移到 XML。

  • 扩展了 Pixi 支持，包括 ROS 2 Humble、AArch64、示例接口和 Greenwave Monitor。

  • 为 UR10 添加了适用于 ROS 2 Humble 和 Jazzy 的 ROS 2 Control 和 MoveIt 2 演示。

  • 添加了启动时的 Isaac Sim Python 脚本。

  • 添加了自动 H.264 和 HEVC 图像解码。

  • 修复了 Ackermann 转换、H1 IMU 集成、ROS 2 Control 启动、Windows 脚本以及 Pixi 环境隔离问题。

  • 升级了 Docker 构建、ROS 密钥处理、依赖项，并扩展了受支持的 ROS 和 Ubuntu 组合的持续集成覆盖率。

ZeroMQ#

  • 添加了一个示例扩展，演示通过 ZeroMQ 实现 Isaac Sim 与外部进程之间的通信。

  • 新增 ZeroMQ OmniGraph 发布和订阅节点，并将共享的 protobuf 架构移至 isaacsim.zmq.protos。

Docker#

  • 新增了一个可选启用的工作流，用于在容器开发期间热重载通过绑定挂载的 Python 扩展。

  • 新增了一个跨容器运行持久化的 Kit 着色器缓存挂载。

  • 新增了关于如何为无根容器用户配置可写主机绑定挂载的指南。

实时流式传输#

  • 更新了 Docker Compose WebRTC 查看器，以使用基于 React 的 Omniverse Web SDK 示例。

运动生成#

  • 将 isaacsim.robot_motion.controllers 中的差速驱动、阿克曼和全向控制器移植到 BaseController API，以实现统一的控制器接口。

  • 新增了可复用的 Franka 和 UR10 操作示例。

SimReady 资产目录#

  • 将 SimReady 资产库扩展至 1,533 个资产，其中包括大量医院相关资产。

  • 为大多数资产添加了许可证归属文件，以定义其支持的使用方式。

  • 新增了资产区域配置文件，以便更快、更便捷地访问 SimReady 资产，并更新了 Isaac Sim 6.1 目录的默认资产根目录。

  • 为资产包添加了许可证和所有者元数据。

通用变更#

以下仓库范围的变更影响许多扩展，因此在此处统一列出，而不在每个扩展条目中重复说明：

  • 将机器人资产引用从 Isaac/Robots/ 迁移至 Isaac/Robots_Multiphysics/ 下支持多物理场的资产。

  • 将 C++ 头文件从 .h 重命名为 .hpp。请更新下游的 include 指令。

  • 明确定义了受支持的包根 Python API，从生成的 API 文档中移除了生命周期实现类，并更新了跨扩展导入以使用受支持的公共入口点。

  • 将若干可复用组件拆分为独立打包的 wheel 包或扩展，包括 Asset Transformer、机器人模式、机器人运动模式、Gain Tuner UI、Python Server UI 以及 ZeroMQ protobuf 模式。
