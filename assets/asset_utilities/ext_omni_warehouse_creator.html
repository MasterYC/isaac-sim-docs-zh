Warehouse Creator 扩展#

Warehouse Creator 是一个交互式规划构建器，可将 2D 网格布局转换为基于 Modular Warehouse 资产包构建的 USD 仓库。在俯视编辑器中绘制平面图，从块库中放置图块，并在当前活动舞台上生成对应的 USD prim。

该功能包含两个扩展：

  • omni.warehouse.creator.api — 无头逻辑（网格引擎、自动铺贴、规划到舞台同步以及列编辑控制器）。可在脚本和测试中使用，无需依赖 UI。

  • omni.warehouse.creator.ui — Warehouse Builder 窗口、工具栏、块库调色板、变体属性控件以及列放置工作流。

安装并启用扩展#

  1. 从顶部菜单打开 Window > Extensions。

  2. 在 Extension Manager 窗口中搜索 omni.warehouse.creator.ui。

  3. 如有需要，点击 Install 或 Update。

  4. 启用该扩展。勾选 Autoload 以便在每次启动时自动加载。

UI 扩展会自动引入 omni.warehouse.creator.api。支持单独启用 API 扩展，以用于无头/脚本化工作流。

打开编辑器#

打开 Window > Warehouse Creator 以显示 Warehouse Builder 窗口。该窗口包含：

  • 一个以网格原点为中心的 俯视 2D 视口。

  • 视口底部沿边放置的 浮动工具栏，包含所有编辑工具。

  • 停靠在窗口侧边的区块库面板。

  • 包含生成仓库按钮和可折叠的列编辑器部分的仓库创建器面板。

该窗口在首次打开时构建，并在关闭后保留在内存中，因此重新打开时是瞬时的。

配置数据集源#

通过编辑 > 首选项 > 仓库创建器配置资产路径。该页面提供：

设置

用途

单元格大小（世界单位）

单个网格单元格的世界空间大小。同时控制编辑器网格和生成的瓦片间距。

墙体高度（世界单位）

应用于墙体资产预设的高度。

中心（地板）资产

相对于资产根目录的中心/地板 USD 资产的文件名。

墙体资产

相对于资产根目录的墙体 USD 资产的文件名。

资产根路径

包含仓库资产的本地或 Nucleus 根文件夹。将其指向您下载的 Isaac Sim 资产文件夹，以获得最快的编辑器和生成体验。

云资产 URL

当资产根路径未设置或无法访问时使用的 HTTPS 回退地址。

注意

Cell Size、Wall Height 和资产名称设置取决于您使用的资产包。默认值与 Isaac Sim 资产包匹配；对于自定义包，请手动设置这些值。资产包是 Center/Floor 和 Wall 资产的集合，它们共享一个变体系统，将每种资产类型的所有可用选项作为引用暴露出来。请参阅 Modular Warehouse 包，了解如何构建此类包的示例。

为了获得本地性能，请下载 Isaac Sim 资产包（参见 Latest Release），并将 Asset Root Path 指向 [Isaac Sim Assets Path]/Isaac/Environments/Modular_Warehouse_New/。块库调色板和仓库生成器都从此位置读取数据。

编辑器工作流#

编辑器在逻辑网格上运行。在生成时，每个占用的单元格都会变成一个 center/floor prim，每个暴露的单元格边缘都会变成一个 wall prim。生成器会省略两个相邻占用单元格之间的墙壁。

工具栏使用三类按钮：

  • 模态工具 — 互斥。激活一个模态工具会停用之前激活的模态工具。

    • Select

    • Move

    • Rotate

    • Draw

    • Line

    • Box

    • Erase

  • 切换按钮 — 与任何模态工具共存。激活对称功能会将所有绘制或擦除操作沿所选轴镜像。

    • 水平对称

    • 垂直对称

  • 即时操作 — 一次性操作。它们在点击时执行，而不会成为当前激活的工具。

    • 水平翻转

    • 垂直翻转

    • 编组

    • 取消编组

    • 合并

    • 减去

    • 放大

    • 缩小

依赖于选区的操作（ 水平翻转、 编组、 取消编组、 合并 以及 减去）在当前选区不满足其要求时，会在工具栏中禁用。

绘制图块#

  1. 在 Block Library Palette 中选择一个资源。下一次绘制操作会将该资源作为手动图块放置。

  2. 激活 Draw 以进行自由绘制，激活 Line 以进行直线拖拽，或激活 Box 以绘制填充矩形。

  3. 在视口内点击并拖拽以添加单元格。 Erase 使用相同的手势移除单元格。

若要在不更改当前激活工具的情况下，在光标位置放置单个图块，请将调色板卡片直接拖拽到视口上。

Symmetry Horizontal 和 Symmetry Vertical 会在所选轴上，以世界原点为中心镜像所有绘制或擦除操作。您可以随时切换这些选项，而无需退出当前激活的绘制工具。

选择与编辑#

  • Select — 点击单元格以选中它。点击并拖拽以绘制选择框。选中组内的单元格将选中整个组。

  • Move — 将选中的单元格或组拖拽到新的网格位置。

  • Rotate — 点击以将选区顺时针旋转 90 度。使用下方的键盘快捷键进行更精细的控制。

  • 水平翻转 / 垂直翻转 — 沿对应轴镜像选区，位置保持不变。

快捷键#

该窗口拥有其快捷键作用域，因此仅当光标位于 Warehouse Builder 窗口上方时，快捷键才会生效。

快捷键

操作

Delete / Backspace

删除当前选区（单元格和组）。

Esc

清除当前选区。

Ctrl+Z / Ctrl+Y

撤销 / 重做上一个网格命令。

Left / Right

将选中的单元格逆时针 / 顺时针旋转 90 度。按住 Shift 可在原地旋转。

Space

切换到下一个工具（当在扩展设置中启用 enable_hotkeys 时）。

单元格分组#

组将一组单元格视为单个浮动对象。您可以作为一个整体移动、旋转和翻转组，生成器会将每个组作为单独的仓库根 prim 输出。

  • 分组 — 将选区合并为一个新组。至少需要两个未分组的单元格或现有组。

  • 取消分组 — 将选中的组中的单元格作为未分组单元格重新放置回网格上。

  • Merge — 将两个或多个选中的组合并为一个。

  • Subtract — 从首个选中的组中移除后续选中组的单元格。

在生成时，每个组都会成为其自己的 /Warehouse_group_<id> 根 prim，其墙壁由边界派生而来。相邻的组可以紧邻未分组的单元格放置，而不共享墙壁。

变体属性小部件#

生成器会发出两种瓦片类型 — Wall 和 Center — 并且每种瓦片都附带一组视觉变体，例如装卸平台、检修面板或窗户。生成后，在 stage 中选择一个或多个瓦片 prim，并使用 Property 面板中的 Warehouse Tiles 部分，为该类型的所有选中瓦片切换变体。

提示

在视口中，将 Select Mode 设置为 Component（右键单击工具栏），以便可以选择单个瓦片，而不是整个仓库层级结构。

生成仓库#

Warehouse Creator 面板中的 Generate Warehouse 按钮会将当前计划转换为活动 stage 上的 USD prim：

  • 所有未分组的单元格都位于 /Warehouse 下。

  • 每个组都位于其自己的 /Warehouse_group_<id> 下。

  • 每个占用单元格都会放置一个中心/地面 prim，并在每条暴露的边缘添加一个 wall prim，旋转使其朝外。

一个模态 Generating Warehouse 弹窗会阻止输入，直到 USD 层稳定下来。这能在大型布局流式加载时保持编辑器响应。

重新运行 Generate Warehouse 会用新的布局替换现有的根 prim，因此你可以迭代方案并重新生成，而无需手动清理。

编辑柱子位置#

每个仓库区块在每个角落都带有一个四分之一柱。相邻区块将它们的四分之一柱合并为一个完整的柱子。Column Editor 允许在仓库生成后单独开启或关闭完整的柱子，而无需手动为每个区块创建变体。

  1. 生成仓库，然后选择仓库根节点下的任意 prim。当选择项位于生成的仓库下时，Edit Column Placement 按钮将变为可用。

  2. 点击 Edit Column Placement 进入编辑模式。编辑器会隐藏天花板和非柱子几何体，高亮显示每个柱子（绿色表示保留，红色表示待移除），并强制开启视口轮廓叠加层，以便高亮保持可见。

  3. 在视口中点击柱子，可在 Enabled（绿色）和 Disabled（红色）之间切换每个柱子。拖动框选可一次切换多个。使用 Enable All、Disable All 和 Flip All 按钮进行批量操作。

  4. 点击 Confirm 以在根图层上确认变体选择，或点击 Cancel 以丢弃待处理的更改。这两个操作都会退出编辑模式并清除临时可见性覆盖。

无头 API#

对于脚本、批处理作业和测试，omni.warehouse.creator.api 无需任何 UI 即可暴露相同的生成流水线：

import omni.usd
from omni.warehouse.creator.api import CellData, GridConfig, GridEngine, StageSyncer

cells = {
    (0, 0): CellData(),
    (1, 0): CellData(),
    (1, 1): CellData(),
}

engine = GridEngine(GridConfig(cell_size=10.0))
stage = omni.usd.get_context().get_stage()

placed = StageSyncer().sync(cells, engine, stage)

ColumnEditorController 为无头使用场景镜像了 Column Editor 工作流。调用 enter() 开始会话，使用 set_all()、flip_all() 或 toggle_keys() 修改待禁用集合，然后调用 leave() 并传入 commit=True 以确认选择。
