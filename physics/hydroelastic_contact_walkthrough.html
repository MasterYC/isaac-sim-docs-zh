为螺母-螺栓装配体配置水弹性接触#

Tool Reference

水弹性接触表示在接触面上的相互作用，而不仅仅是在少量点上的相互作用。这种接触模型适用于贴合几何体，其中界面的形状会影响物体之间的力、扭矩和相对运动。

本教程使用螺纹螺母-螺栓装配体来演示如何在 Isaac Sim UI 中为 Newton 水弹性接触准备现有的 USD 碰撞网格。它还将区分在 USD 资产上编写的接触属性与在运行时配置的碰撞管线设置。

完成本教程后，您将了解如何：

  • 从属性面板为水弹性接触准备现有的碰撞网格。

  • 为贴合几何体配置 SDF 细节和接触属性。

  • 区分资产级 USD 属性与运行时 NewtonConfig 设置。

  • 在仿真中验证已编写的接触对。

有关接触模型和参数参考，请参阅 Hydroelastic Contact。

先决条件#

  • 具有可用 Newton 后端的 Isaac Sim (isaacsim.physics.newton)。

从 Newton 开始#

水弹性接触仅在使用 Newton 物理引擎时可用。启动启用了 Newton 的 Isaac Sim（例如 isaacsim.newton.sh / isaacsim.newton.bat，或将默认引擎设置为 Newton），然后确认视口指示 Newton 处于活动状态。

当 Newton 为当前活动引擎时，Add > Physics > Newton 下的 Newton 架构条目才会显示。如果没有这些条目，则无法从 UI 中应用 NewtonSDFCollisionAPI。

加载螺母和螺栓#

Factory 资产为示例螺母和螺栓提供了碰撞网格。打开 Window > Script Editor，粘贴以下脚本并运行。该脚本会创建一个新阶段（stage），加载这两个资产，并将螺母放置在螺栓尖端，具有较小的初始螺纹啮合量。

# SPDX-FileCopyrightText: Copyright (c) 2026 NVIDIA CORPORATION & AFFILIATES. All rights reserved.
# SPDX-License-Identifier: Apache-2.0

"""Load and position the Factory nut-and-bolt assets."""

import asyncio
import math

import isaacsim.core.experimental.utils.stage as stage_utils
import omni.kit.actions.core
import omni.kit.app
from isaacsim.core.experimental.prims import XformPrim
from isaacsim.storage.native import get_assets_root_path_async
from pxr import UsdPhysics

BOLT_PATH = "/World/bolt"
NUT_PATH = "/World/nut"
BOLT_BODY_PATH = f"{BOLT_PATH}/factory_bolt_loose"
BOLT_ROOT_JOINT_PATH = f"{BOLT_PATH}/root_joint"

BOLT_TIP_HEIGHT = 0.035
NUT_MESH_BASE_OFFSET = 0.010
NUT_ENGAGEMENT = 0.0005
NUT_YAW = math.pi / 8.0


async def load_factory_fasteners_async() -> None:
    """Create a stage and place the Factory nut on the bolt tip."""
    assets_root_path = await get_assets_root_path_async()
    if assets_root_path is None:
        raise RuntimeError("Could not find the Isaac Sim assets root.")

    await stage_utils.create_new_stage_async()
    action_registry = omni.kit.actions.core.get_action_registry()
    action_registry.get_action("omni.kit.viewport.menubar.lighting", "set_lighting_mode_camera").execute()

    factory_directory = f"{assets_root_path}/Isaac/IsaacLab/Factory"

    stage_utils.add_reference_to_stage(
        usd_path=f"{factory_directory}/factory_bolt_m16.usd",
        path=BOLT_PATH,
    )
    XformPrim(BOLT_PATH, reset_xform_op_properties=True).set_local_poses(
        translations=[[0.0, 0.0, 0.0]],
        orientations=[[1.0, 0.0, 0.0, 0.0]],
    )

    stage = stage_utils.get_current_stage(backend="usd")
    bolt_body = stage.GetPrimAtPath(BOLT_BODY_PATH)
    # Keep the bolt fixed as a static collider instead of a one-joint articulation.
    bolt_body.RemoveAPI(UsdPhysics.RigidBodyAPI)
    bolt_body.RemoveAPI(UsdPhysics.ArticulationRootAPI)
    stage.GetPrimAtPath(BOLT_ROOT_JOINT_PATH).SetActive(False)

    stage_utils.add_reference_to_stage(
        usd_path=f"{factory_directory}/factory_nut_m16.usd",
        path=NUT_PATH,
    )
    XformPrim(NUT_PATH, reset_xform_op_properties=True).set_local_poses(
        translations=[[0.0, 0.0, BOLT_TIP_HEIGHT - NUT_MESH_BASE_OFFSET - NUT_ENGAGEMENT]],
        orientations=[[math.cos(NUT_YAW * 0.5), 0.0, 0.0, math.sin(NUT_YAW * 0.5)]],
    )

    await omni.kit.app.get_app().next_update_async()


asyncio.ensure_future(load_factory_fasteners_async())

此设置使用异步函数，因为资产根查找、阶段创建以及最终的 Kit 更新都需要等待（await）。本页面上的其余 Script Editor 代码片段执行同步 USD 编写，不需要异步包装器。

该脚本还将螺栓从固定基座关节体（fixed-base articulation）转换为静态碰撞体，并启用 Camera Light。螺母保持动态，以便重力能使螺纹啮合。若要手动启用相同的照明模式，请打开视口 Lighting 菜单并选择 Camera Light。

应用 Newton SDF 碰撞体#

水弹性接触需要在每个参与的碰撞体上具有有符号距离场（SDF）。应用 Newton SDF Collider 是使网格启用该路径的 UI 步骤：它会添加 NewtonSDFCollisionAPI，为该形状启用 SDF 生成，并继承 NewtonCollisionAPI 和 PhysicsCollisionAPI。

  1. 在 Stage 面板中，选择 /World/bolt/factory_bolt_loose/collisions 处的螺栓碰撞网格。

  2. 在 Property 面板中，点击 Add > Physics > Newton > Newton SDF Collider。

  3. 对位于 /World/nut/factory_nut_loose/collisions 处的螺母碰撞网格重复上述操作。

配对中的两个形状都必须应用此 API。仅在一个网格上应用该 API 不会产生水弹性接触。

启用水弹性接触#

NewtonSDFCollisionAPI 仅用于准备 SDF。您仍然需要为每个形状启用水弹性接触，并调整 SDF 尺寸以解析螺旋螺纹。应用 Newton SDF Collider 后，选中每个碰撞体，在 Property 面板中设置以下属性：

  1. 将螺母和螺栓碰撞体的 Hydroelastic Enabled (newton:hydroelasticEnabled) 设置为 true。

  2. 可选：设置 Hydroelastic Stiffness (newton:hydroelasticStiffness)。值越高，接触越刚性。默认值为 1e10。

  3. 将 SDF Max Resolution (newton:sdfMaxResolution) 设置为足够高的值以捕捉螺纹细节。对于此类 Factory 网格，128 是一个合理的起始值。

  4. 可选：针对精细特征收紧 SDF Narrow Band Inner / Outer（例如 -0.005 和 0.005）。

  5. 将 Contact Margin (newton:contactMargin) 设置为 0.0，将 Contact Gap (newton:contactGap) 设置为 0.005，以便在螺纹相互穿透之前检测到接触，同时避免膨胀碰撞表面。

两个形状都必须具有 newton:hydroelasticEnabled = true。仅对配对中的一个形状启用该属性不会产生水弹性接触。

Factory 资产还携带了 PhysX SDF 碰撞体设置。NewtonSDFCollisionAPI 取代了它，并且 Newton 会警告 physics:approximation 被忽略。将碰撞体的 Approximation 设置为 none 可清除该警告。

完成 UI 步骤后，你可以通过 Script Editor 执行相同的编辑操作。以下脚本将 NewtonSDFCollisionAPI 和上述 水弹性设置应用于两个 Factory 碰撞网格：

# SPDX-FileCopyrightText: Copyright (c) 2026 NVIDIA CORPORATION & AFFILIATES. All rights reserved.
# SPDX-License-Identifier: Apache-2.0

"""Configure the Factory colliders for Newton hydroelastic contact."""

import omni.usd
from pxr import Sdf

COLLIDER_PATHS = (
    "/World/bolt/factory_bolt_loose/collisions",
    "/World/nut/factory_nut_loose/collisions",
)


def configure_hydroelastic_colliders() -> None:
    """Configure both fastener colliders for hydroelastic contact."""
    stage = omni.usd.get_context().get_stage()

    for collider_path in COLLIDER_PATHS:
        prim = stage.GetPrimAtPath(collider_path)
        if not prim.IsValid():
            raise RuntimeError(f"Collider prim does not exist: {collider_path}")
        if not prim.HasAPI("NewtonSDFCollisionAPI"):
            prim.ApplyAPI("NewtonSDFCollisionAPI")

        prim.GetAttribute("newton:hydroelasticEnabled").Set(True)
        prim.GetAttribute("newton:hydroelasticStiffness").Set(1.0e10)
        prim.GetAttribute("newton:sdfMaxResolution").Set(128)
        prim.GetAttribute("newton:sdfNarrowBandInner").Set(-0.005)
        prim.GetAttribute("newton:sdfNarrowBandOuter").Set(0.005)
        prim.GetAttribute("newton:contactMargin").Set(0.0)
        prim.GetAttribute("newton:contactGap").Set(0.005)
        approximation_attr = prim.GetAttribute("physics:approximation")
        if not approximation_attr.IsValid():
            approximation_attr = prim.CreateAttribute("physics:approximation", Sdf.ValueTypeNames.Token)
        approximation_attr.Set("none")


configure_hydroelastic_colliders()

绑定接触材质#

NewtonSDFCollisionAPI 配置了碰撞表示，但它不 定义摩擦或其他材质响应。在此示例中，摩擦 决定了螺母是沿螺纹转动还是在首次啮合时锁定。使用 1.0 的默认摩擦时，螺母会在几毫米后楔住。

  1. 选择 Create > Physics > Physics Material，选择 Rigid Body Material，并在 /World/PhysicsMaterials/fastener 处创建材质。

  2. 在该材质上，将 Static Friction 和 Dynamic Friction 设置为 0.01， 并将 Restitution 设置为 0.0。

  3. 选中该材质后，选择 Add > Physics > Newton > Newton Material。将 Torsional Friction 和 Rolling Friction 设置为 0.0，Contact Stiffness 设置为 1e7，Contact Damping 设置为 1e4。

  4. 选择螺栓碰撞网格。在 Physics Materials on Selected Models 中， 绑定 /World/PhysicsMaterials/fastener。

  5. 对螺母碰撞网格重复材质绑定操作。

以下脚本编辑器代码片段执行相同的设置。它创建材质，应用 NewtonMaterialAPI，编写 USD Physics 和 Newton 材质属性，并将材质绑定到用于物理目的的两个碰撞网格。

# SPDX-FileCopyrightText: Copyright (c) 2026 NVIDIA CORPORATION & AFFILIATES. All rights reserved.
# SPDX-License-Identifier: Apache-2.0

"""Author and bind a low-friction Newton contact material."""

import omni.usd
from pxr import UsdPhysics, UsdShade

COLLIDER_PATHS = (
    "/World/bolt/factory_bolt_loose/collisions",
    "/World/nut/factory_nut_loose/collisions",
)


def bind_fastener_material() -> None:
    """Create a Newton material and bind it to both fastener colliders."""
    stage = omni.usd.get_context().get_stage()

    material = UsdShade.Material.Define(stage, "/World/PhysicsMaterials/fastener")
    material_api = UsdPhysics.MaterialAPI.Apply(material.GetPrim())
    material_api.CreateStaticFrictionAttr().Set(0.01)
    material_api.CreateDynamicFrictionAttr().Set(0.01)
    material_api.CreateRestitutionAttr().Set(0.0)

    material_prim = material.GetPrim()
    if not material_prim.HasAPI("NewtonMaterialAPI"):
        material_prim.ApplyAPI("NewtonMaterialAPI")
    material_prim.GetAttribute("newton:torsionalFriction").Set(0.0)
    material_prim.GetAttribute("newton:rollingFriction").Set(0.0)
    material_prim.GetAttribute("newton:contactStiffness").Set(1.0e7)
    material_prim.GetAttribute("newton:contactDamping").Set(1.0e4)

    for collider_path in COLLIDER_PATHS:
        collider_prim = stage.GetPrimAtPath(collider_path)
        if not collider_prim.IsValid():
            raise RuntimeError(f"Collider prim does not exist: {collider_path}")
        UsdShade.MaterialBindingAPI.Apply(collider_prim).Bind(
            material,
            UsdShade.Tokens.weakerThanDescendants,
            materialPurpose="physics",
        )


bind_fastener_material()

配置求解器和管线设置#

上述 USD 工作使形状具备流体弹性（hydroelastic）就绪状态。螺纹接触还取决于仿真频率、求解器设置以及运行时碰撞管线容量。NewtonConfig 不存储在 USD 中，因此请在加载 Stage 之后、按下 Play 之前应用此配置：

  • 物理频率为 240 Hz，num_substeps 设置为 2，因此对于 2 mm 的螺纹螺距，接触以 480 Hz 的频率进行解析。

  • rigid_contact_max 以及 MuJoCo 的 nconmax / njmax 均远高于其默认值。螺旋螺纹上的流体弹性补丁每步会产生数百个接触点，而默认值（1000 个管线接触点，200 个求解器接触点）会丢弃这些接触点，从而导致螺母穿过螺栓。

  • 将 MuJoCo 的 iterations 设置为 15，并将 ls_iterations 设置为 100，以匹配独立示例中使用的求解器配置。

  • mc_edge_clamp_min 为 0.0。Marching-cubes 边缘钳制会使接触表面顶点产生偏差，而螺纹对这种偏差非常敏感。

  • buffer_mult_iso 为 2。等值面缓冲区必须能够容纳完整的螺纹补丁；默认大小会溢出并丢弃接触点。

# SPDX-FileCopyrightText: Copyright (c) 2026 NVIDIA CORPORATION & AFFILIATES. All rights reserved.
# SPDX-License-Identifier: Apache-2.0

"""Configure solver and pipeline settings that have no USD attribute equivalent."""

import omni.kit.app
from isaacsim.core.simulation_manager import SimulationManager

ext_mgr = omni.kit.app.get_app().get_extension_manager()
ext_mgr.set_extension_enabled_immediate("isaacsim.physics.newton", True)

from isaacsim.physics.newton import (
    CollisionConfig,
    HydroelasticConfig,
    MuJoCoSolverConfig,
    NewtonConfig,
    configure_newton,
)

MAX_CONTACTS = 40_000

SimulationManager.setup_simulation(dt=1.0 / 240.0, device="cuda")

configure_newton(
    NewtonConfig(
        num_substeps=2,
        solver_cfg=MuJoCoSolverConfig(
            njmax=MAX_CONTACTS,
            nconmax=MAX_CONTACTS,
        ),
        collision_cfg=CollisionConfig(
            rigid_contact_max=MAX_CONTACTS,
            hydroelastic=HydroelasticConfig(mc_edge_clamp_min=0.0, buffer_mult_iso=2),
        ),
    )
)

该代码片段使用 SimulationManager.setup_simulation() 将物理时间步长设置为 240 Hz，然后调用 configure_newton()。 每次打开或重新加载舞台时，请重新运行该代码片段。其他字段（enabled、reduce_contacts 等）的默认值列在 Hydroelastic Contact 和 isaacsim.physics.newton Python API 中。
