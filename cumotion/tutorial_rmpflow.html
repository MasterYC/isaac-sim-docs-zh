RMPflow 教程#

Tutorial

本教程演示如何在 cuMotion 集成中使用 RmpFlowController 类，以生成平滑且具备反应性的运动，从而在避开动态障碍物的同时到达任务空间目标。

完成本教程后，您将了解：

  • 如何创建和配置 RmpFlowController

  • 如何为动态环境更新世界状态

先决条件

  • 请阅读 Robot Configuration 教程，以了解如何加载机器人配置。

  • 请阅读 Controllers and the RobotState 教程，以了解 BaseController 接口和 RobotState。

  • 请阅读 World Interface 教程，以了解如何设置 CumotionWorldInterface。

要跟随本教程操作，请运行您的 Isaac Sim 实例。打开 Window > Examples > Robotics Examples，然后选择 Motion Generation > cuMotion > RMPflow。 在 isaacsim.robot_motion.cumotion.examples 扩展中，有一个功能完整的 RMPflow 示例，包括目标跟随、世界感知和障碍物避让。

关键概念#

RmpFlowController 实现了 Motion Generation API 中的 BaseController 接口，支持以下反应式运动控制功能：

  • 到达任务空间目标：控制器驱动机器人末端执行器到达目标位置和姿态

  • 避开障碍物：使用 CumotionWorldInterface 获取障碍物信息以实现避障

设置控制器#

首先，按照 World Interface 教程 中的说明设置 CumotionWorldInterface。 在本教程中，我们将使用 WorldBinding 来方便地初始化 CumotionWorldInterface 中的障碍物。 一旦拥有 CumotionWorldInterface，即可创建控制器：

    # Get robot joint and site names
    robot_joint_space = articulation.dof_names
    robot_site_space = cumotion_robot.robot_description.tool_frame_names()
    tool_frame = robot_site_space[0]

    # Create RMPflow controller
    controller = RmpFlowController(
        cumotion_robot=cumotion_robot,
        cumotion_world_interface=world_binding.get_world_interface(),
        robot_joint_space=robot_joint_space,
        robot_site_space=robot_site_space,
        tool_frame=tool_frame,
    )

控制器需要：

  • 机器人配置：一个 cuMotion 机器人配置（通过 load_cumotion_supported_robot() 获取）。有关加载机器人配置的详细信息，请参阅 Robot Configuration tutorial。

  • 世界接口：一个 CumotionWorldInterface 实例

  • 关节和站点空间：机器人关节和站点的完整有序控制空间（更多详细信息请参阅 Motion Generation API 文档）

  • 工具坐标系：要控制的末端执行器坐标系的名称 - 在初始化时，控制器将确认工具坐标系位于站点空间中

如果未提供工具坐标系，控制器将使用 cuMotion 机器人描述中定义的第一个工具坐标系。

创建 RobotState 对象#

控制器需要 RobotState 对象来表示估计状态（当前机器人状态）和设定点状态（目标末端执行器位姿）。有关 RobotState 创建的详细信息，请参阅 Motion Generation API 文档。

估计状态（当前机器人配置）：

    # Get current robot state
    robot_joint_space = articulation.dof_names

    # Create estimated state (current robot state)
    estimated_state = mg.RobotState(
        joints=mg.JointState.from_name(
            robot_joint_space=robot_joint_space,
            positions=(robot_joint_space, articulation.get_dof_positions()),
            velocities=(robot_joint_space, articulation.get_dof_velocities()),
        )
    )

设定值状态（目标末端执行器位姿）：

    # Create setpoint with target end-effector pose
    tool_frame_name = cumotion_robot.robot_description.tool_frame_names()[0]
    robot_site_space = cumotion_robot.robot_description.tool_frame_names()

    # Get target pose (example: from a target object)
    target_positions, target_orientations = target_object.get_world_poses()

    setpoint_state = mg.RobotState(
        sites=mg.SpatialState.from_name(
            spatial_space=robot_site_space,
            positions=([tool_frame_name], target_positions),
            orientations=([tool_frame_name], target_orientations),
        ),
    )

重置控制器#

在使用控制器之前，必须使用估计状态、设定点状态和时钟时间对其进行一次重置。reset() 方法：

  • 清除工具坐标系上的任何内部 RMPflow 设定点

  • 将关节空间设定点设置为等于机器人当前的估计关节位姿（即，初始期望状态是机器人当前所在的位置，这是最安全的）

  • 初始化内部 RMPflow 算法

forward() 方法不能在成功调用 reset() 之前运行（它必须返回 True）。

    # Reset the controller - must return True before forward can be called
    success = controller.reset(estimated_state, setpoint_state, t=t)
    if not success:
        raise RuntimeError("Controller reset failed. Check that estimated_state contains all required joint positions.")

运行控制器#

控制器使用 BaseController 接口。在每个更新步骤中，您需要：

  1. 获取当前机器人状态（估计状态）

  2. 使用目标末端执行器位姿创建设定值状态

  3. 调用控制器的 forward() 方法

  4. 将生成的期望状态应用到机器人

如果设定点状态设置为 None，则控制器将继续跟踪之前的设定点状态。

    # Get desired state from controller (t is the clock time, not a time step)
    desired_state = controller.forward(estimated_state, setpoint_state, t)

    # Apply action to articulation
    if desired_state is not None and desired_state.joints.positions is not None:
        articulation.set_dof_position_targets(
            positions=desired_state.joints.positions,
            dof_indices=desired_state.joints.position_indices,
        )

更新世界状态#

必须每帧更新世界绑定，以跟踪移动障碍物和机器人基座的移动。这对于动态环境至关重要：

    # Update robot base transform
    world_binding.get_world_interface().update_world_to_robot_root_transforms(articulation.get_world_poses())

    # Synchronize transforms (updates all obstacles and world state)
    world_binding.synchronize_transforms()

有关世界状态同步的更多详细信息，请参阅 World Interface 教程。

访问 cuMotion 参数#

控制器提供对底层 cuMotion RMPflow 配置的访问权限，以便修改参数：

    # Get the underlying cuMotion config
    rmpflow_config = controller.get_rmp_flow_config()

    # Modify parameters using set_param
    rmpflow_config.set_param("cspace_target_rmp/damping_gain", 0.9)

有关可用参数及其用法的完整列表，请参阅 cuMotion Python 和 C++ API 文档。

配置 rmp_flow.yaml#

rmp_flow.yaml 文件控制所有 RMPflow 参数。请将其与 robot.urdf 和 robot.xrdf 一起保存在机器人配置目录中（参见 Robot Configuration 教程）。

自碰撞避免#

body_capsules 定义固定坐标系下的胶囊体（由两个绝对坐标端点和一个半径指定），用于近似机器人基座或其他静止连杆。body_collision_controllers 在移动臂上的命名 URDF 坐标系处放置球体。RMPflow 防止任何控制器球体与任何身体胶囊体相交。

首先使用一个覆盖机器人基座的胶囊体和一个靠近末端执行器的球体，仅当在实际操作中观察到自碰撞时再添加更多几何体。

有关逐步调整过程，请参阅 RMPflow 调整指南。

总结#

本教程演示了：

  1. RmpFlowController 设置：创建 RmpFlowController 并使用 CumotionWorldInterface 实现障碍物感知
