生成 XRDF 文件#

本教程面向需要配置 load_cumotion_supported_robot() 中未提供的自定义机器人的用户。教程演示了如何使用 Robot Description Editor 生成用于 XRDF 文件，以便与 cuMotion 配合使用。该编辑器允许您直接从舞台上的机器人 USD 资产定义关节属性和 碰撞球几何体，然后将结果导出为 XRDF 文件。

先决条件#

  • 启用 cuMotion/Lula Robot Description Editor 扩展：前往 Window > Extensions，搜索 isaacsim.robot_setup.xrdf_editor， 点击 ENABLE，并勾选 AUTOLOAD。

  • 作为单个 Articulation 加载到舞台上的机器人 USD 资产。通过将文件拖放到空白舞台上而不是直接打开它来打开文件。

注意

Robot Description Editor 不兼容 Instanceable Assets。 为非实例化资产生成的 XRDF 文件在该资产的实例化版本上仍然可用。

要使用编辑器，请取消勾选机器人层级结构中所有几何体 prim 的 Instanceable 复选框。 在选中几何体 prim 时，可在 Property 面板中找到此设置。

入门指南#

从菜单栏打开 Robot Description Editor： Tools > Robotics > cuMotion/Lula Robot Description Editor。

点击 Play 按钮。在 Selection Panel 中，从 Select Articulation 字段选择机器人 Articulation 的 prim 路径。 选择 Articulation 后，Select Link 下拉菜单将填充机器人的连杆名称，其他所有面板也将填充与机器人相关的数据。

重要

在导出 XRDF 文件之前，请保持仿真运行。

设置关节属性#

在 Set Joint Properties 面板中，为每个关节分配 Joint Position 和 Joint Status：

  • Active joints 由 cuMotion 直接控制 — 通常是机械臂中的每个关节。至少必须将一个关节标记为 active。

  • Fixed joints 保持在恒定的默认位置 — 通常是夹爪关节。固定关节的位置定义了机器人的默认配置，并影响反应式控制期间的零空间行为。

添加碰撞球体#

cuMotion 使用附加到每个机器人连杆的一组球体来进行碰撞避免。通过在 Select Link 字段中选择连杆，可以逐个连杆添加球体。

Link Sphere Editor 面板提供三种方法：

  • Add Sphere：在相对于连杆原点的指定平移位置添加单个球体。创建后，可以通过在舞台上移动 prim 或编辑其半径来调整它。

  • Connect Spheres：选择连杆下的两个现有球体，并使用指定数量的插值球体填充间隙，这些球体的大小足以覆盖它们之间的圆锥部分。

  • Generate Spheres：选择定义连杆体积的网格，并自动生成 N 个球体以覆盖该体积。在通过 Generate Spheres 确认之前，会显示预览。此方法要求网格为水密三角形网格。对于具有简单圆柱形状的连杆，Connect Spheres 通常能提供更好的覆盖效果。

Editor Tools 面板提供 Undo / Redo、球体颜色控制以及机器人可见性切换功能。

球体调整技巧

  • 调整球体大小以覆盖连杆，但不要过大——过大的球体会增加求解器的保守性，并可能降低运动质量。

  • 更多的球体可以提高碰撞检测精度，但会降低求解器性能。请找到能提供足够覆盖的最小球体数量。

  • 对于长圆柱形连杆，请在两端生成球体，并使用 Connect Spheres 均匀填充中间部分。

  • 使用 Scale Spheres in Link 可统一调整连杆上所有球体的大小。

  • Generate Spheres 需要一个水密三角形网格。如果针对某个连杆生成失败，请使用 Add Sphere 和 Connect Spheres 手动放置球体。

导出 XRDF 文件#

完成关节属性和碰撞球体设置后，导出 XRDF 文件： Export To File > Export to cuMotion XRDF。使用 .xrdf 作为文件 扩展名（如果您使用的是 Lula，即 cuMotion 的遗留前身，则 .yaml 也是可接受的）。输入有效路径后，Export 按钮将变为可用状态。

版本下拉菜单允许您选择 XRDF 格式版本 1.0 或 2.0（推荐版本 2.0；版本 1.0 使用 collision，版本 2.0 使用 world_collision）。导出时，编辑器会：

  • 创建一个用于 world_collision（或 版本 1.0 中的 collision）和 self_collision 的单一碰撞组，其中包含您定义的球体。

  • 在 self_collision 中设置每个连杆以忽略其父连杆以及共享同一父连杆的任何兄弟 连杆。

  • 不写入 Tool Frames。

  • 不写入 Modifiers。

文件保存后，您可以停止模拟。

与现有 XRDF 文件合并#

如果文件路径指向现有的 XRDF 文件，则会出现 Merge With Existing XRDF 选项。合并时，编辑器会：

  • 从现有文件中复制 Tool Frames。

  • 从现有文件中复制 Modifiers。

  • 当 self_collision > geometry 与导出的碰撞组几何形状匹配时，从现有文件中复制 self_collision > ignore 条目。

  • 从现有文件中复制编辑器中未表示的连杆的碰撞球体。

添加工具坐标系#

cuMotion 需要在 XRDF 文件中定义一个工具坐标系，以指定运动规划末端执行器的参考。Robot Description Editor 不会写入工具坐标系，因此您必须在导出后手动添加一个。

在文本编辑器中打开导出的 XRDF 文件，并添加一个 tool_frames 条目，将名称替换为您机器人的末端执行器连杆名称：

tool_frames: ["wrist_3_link"]

如果您使用 Merge With Existing XRDF 选项，现有文件中的工具坐标系会自动保留 — 请参阅上文中的 Merging with an existing XRDF file。

导入 XRDF 文件#

要将现有的 XRDF 文件加载到编辑器中：Import From File > Import XRDF File。支持格式版本 1.0 和 2.0。编辑器会导入碰撞球体和关节属性；不会导入 Modifiers、Tool Frames 和 self_collision 条目。导入操作会覆盖当前所有编辑器状态。

总结#

本教程涵盖了：

  1. 扩展设置：启用 Robot Description Editor 并准备机器人资产

  2. 关节属性：将关节分类为活动或固定，并设置默认位置

  3. 碰撞球体：使用 Add Sphere、Connect Spheres 和 Generate Spheres 添加每个连杆的球体

  4. XRDF 导出：导出 XRDF 文件，选择格式版本，并可选择与现有文件合并

  5. 工具坐标系：手动向导出的 XRDF 添加工具坐标系

  6. XRDF 导入：将现有的 XRDF 文件重新加载到编辑器中

此处生成的 XRDF 文件是所有 cuMotion 运动规划和控制组件的必需输入。
