偏好设置#

Developer Reference

“Preferences”（首选项）面板位于 Edit > Preferences 下，其中包含适用于当前应用的一系列设置。此处列出最常修改的设置。这些设置适用于整个应用程序，并且不会随各个 USD 阶段一起存储。

音频#

有一些应用首选项可用于在 Omniverse USD Composer 中全局控制音频输出的行为。这些首选项会影响 Omniverse USD Composer 中加载的所有 USD 阶段。这些设置不会作为 USD 阶段的一部分进行存储。可以通过转到 Edit（编辑）菜单并选择 Preferences（首选项）来打开应用首选项窗口。通过在左侧的章节列表中选择 Audio（音频），可以找到音频首选项。

音频输出#

输入和输出设备首选项。

选项

描述

输出设备
显示一个下拉框，其中包含连接到系统的所有音频输出设备的名称。这可用于在 Omniverse USD Presenter 中选择所需的输出设备。此设置会影响主 USD 舞台和所有 UI 音频的输出。从列表中选择设备后，必须单击 Apply 按钮以接受更改。同时更改此设置和下方的扬声器配置将导致所有打开的音频上下文的输出发生更改。如果最近连接到系统的设备状态发生了变化（即：连接了新设备或从系统断开了设备），可以使用 Refresh 按钮来收集新的设备列表。默认情况下，将选择系统的默认输出设备。

如果在 Omniverse USD Presenter 的启动之间选定的设备与系统断开连接，或者设备列表在启动之间发生变化，则在下次启动时将首先尝试查找之前选定的设备。如果它仍连接到系统，则将其使用。如果在设备列表中找不到它，则改用系统的默认输出设备。

输入设备
显示一个下拉框，其中包含连接到系统的所有音频输入设备的名称。这可用于选择在 Omniverse View 中用于录制的所需设备。此设置会影响所有 USD 阶段的输入。从列表中选择设备后，必须单击 Apply 按钮以接受更改。输入设备不受“Speaker Configuration”设置的影响。如果最近连接到系统的设备状态发生了变化（即：连接了新设备或从系统断开了设备），则可以使用 Refresh 按钮来收集新的设备列表。默认情况下，将选择系统的默认输入设备。

如果在 Omniverse USD Presenter 的两次启动之间选定的设备从系统断开，或者设备列表在两次启动之间发生变化，则在下次启动时将首先尝试查找先前选定的设备。如果它仍连接到系统，则将其使用。如果在设备列表中找不到它，则改用系统的默认输出设备。

扬声器配置
设置输出使用的扬声器配置。无论设备功能如何，所有配置均受支持（即：立体声设备也支持 5.1 配置）。如果所选设备不直接支持输出模式，音频系统的最终输出将向下混音至设备首选配置。在向下混音的输出中，将尽可能保留原始流的内容。

如果选择了“auto-detect”（自动检测）配置，输出将尝试匹配设备首选格式。请注意，由于扬声器通道数量较多，这可能会导致某些设备需要额外的处理资源。

更改此设置后，必须单击 Apply 按钮（或重新启动 Omniverse USD Composer）才能使设置生效。Refresh 按钮用于刷新音频输入和输出设备列表。如果系统连接了新设备或移除了现有设备，单击此按钮将刷新设备列表，以反映输入和输出的新设备集。

注意：此按钮未来可能会消失，以支持自动检测系统设备变更。

应用
将所有更改应用到音频输入和输出设备选择。如果未更改任何选项，则此操作无效。但是，如果某个设备当时正在使用中（即：正在积极录制音频或在舞台中积极播放音频），这可能会导致音频短暂中断。建议在按下此按钮之前，确保已停止所有音频录制和播放。

音频参数#

选项

描述

自动流式传输阈值
定义音频系统决定对流式传输压缩音频资产而不是将其解压到内存中的资产大小阈值。此阈值以千字节为单位表示。如果将其设置为零，则禁用自动流式传输功能。如果将其设置为任何更大的值，则任何解压后大小大于此阈值的压缩音频资产将从原始压缩对象进行流式传输，而不是被解压。这样做的优点是内存使用量更低，资产加载速度更快。但是，流式传输声音确实需要稍多的处理时间。默认值为 0KB。

音频播放器参数#

选项

描述

自动流式传输阈值
定义音频播放器在播放期间对压缩资源进行即时解压而非在加载时解压到内存中的资源大小阈值。这样做的好处是占用更少的内存，并允许播放更早开始（至少对于大型资源而言）。此阈值以千字节为单位。如果设置为零，则所有资源将在播放前解压。如果设置为非零值，则任何解压后大小大于此值的压缩资源将在播放时进行解压。默认值为 256KB。

停止时关闭音频播放器
确定在声音首次播放完成后，音频播放器是否自动关闭。这在从内容浏览器预览大量音频资源时非常有用。如果未选中此选项，音频播放器窗口将在播放完成后保持打开状态。默认情况下未选中。

音量级别#

调整声音的音量属性。

选项

描述

主音量
定义所有音频输出的主音量级别。所有其他音量级别实际上都会乘以该音量级别，以得到最终的总体音量。将其设置为 0.0 将导致静音（尽管音频数据仍会被完全处理）。将其设置为 1.0 将为满音量。音量级别在此范围内线性变化。默认值为 1.0。

如果所选设备在启动之间从系统断开连接，或者设备列表在启动之间发生变化，则在下次启动时将首先尝试查找之前选择的设备。如果该设备仍连接到系统，则使用它。如果在设备列表中找不到该设备，则改用系统的默认输出设备。

USD 音量
定义 USD 舞台音频输出的所有音频使用的音量级别。这会影响所有空间音效和非空间音效。将其设置为 0.0 将导致静音（尽管音频数据仍会被完全处理）。将其设置为 1.0 将为满音量。音量级别在此范围内线性变化。默认值为 1.0。

空间语音音量
定义用于 USD 阶段中所有空间声音的音量级别。在输出之前，此音量级别实际上还会与“USD Volume”级别设置相乘，以获取空间声音的最终音量级别。将其设置为 0.0 将导致静音（尽管音频数据仍会被完全处理）。将其设置为 1.0 将为最大音量。在此范围内，音量级别呈线性变化。默认值为 1.0。

非空间语音音量
定义用于 USD 阶段中所有非空间声音的音量级别。在输出之前，此音量级别实际上还会与“USD Volume”级别设置相乘，以获取非空间声音的最终音量级别。将其设置为 0.0 将导致静音（尽管音频数据仍会被完全处理）。将其设置为 1.0 将为最大音量。在此范围内，音量级别呈线性变化。默认值为 1.0。

UI 音频音量
定义用于 Omniverse USD Presenter 中所有 UI 音频声音的音量级别。将其设置为 0.0 将导致静音（尽管音频数据仍会被完全处理）。将其设置为 1.0 将为最大音量。在此范围内，音量级别呈线性变化。默认值为 1.0。

调试#

声音调试选项。

选项

描述

流转储文件名
定义将 USD Stage 音频输出转储到文件时使用的文件名。无论文件扩展名如何，该文件均以 WAVE 文件格式写出。声道数和数据格式将与当前输出设备所选的声道数和格式匹配。该文件将在播放音频时写入磁盘，并始终尝试保持与设备上正在播放的音频仅相差几毫秒（尽可能接近）。

输出文件必须位于本地文件卷上。不支持将输出发送到 Omniverse 位置。启用流转储后，将创建输出文件，并在产生新的音频数据时向其写入数据。输出将持续进行，直到禁用流转储或退出 Omniverse App。此设置的默认值为空字符串。

请注意，只要此功能保持启用状态，数据就会持续写入输出文件。由于这是以未压缩数据形式写入的，因此该文件往往会迅速增长。例如，48KHz 立体声浮点信号每分钟大约写入 22MB。因此，“Enable Stream Dump”设置在此 Omniverse app 的用户配置中不是持久化的。当 Omniverse App 启动时，它始终处于关闭状态。

启用流转储
定义当前是否启用流转储。一旦启用此项并在“Stream Dump Filename”中选择了有效的文件名，系统将开始向输出文件写入数据。流转储将持续进行，直到禁用此设置或退出当前 Omniverse 应用为止。此设置不会保存在当前 Omniverse 应用的用户配置中。每次全新启动时，该设置始终处于禁用状态。
