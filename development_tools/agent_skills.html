Agent Skills#

Developer Reference

Agent 技能是受版本控制的工作流指南，用于指导 AI 编码代理（如 Cursor、Claude Code 和 Codex 命令行界面 (CLI)）执行 Isaac Sim 任务：导入机器人、配置物理、生成合成数据、渲染、驱动运行实例等。每个技能都是一个 Markdown 文件 (SKILL.md)，当您的请求与技能主题匹配时，代理会按需加载该文件。

这些技能随 Isaac Sim 一起发布在 skills/ 目录中，因此您无需克隆源代码仓库即可使用它们。它们存在于源代码树中，并打包在 pip 包和二进制包中。当支持技能的代理能够看到 skills/ 目录时，代理将遵循 Isaac Sim 团队编码的相同流程并避免相同的陷阱。


技能的工作原理#

技能是一个目录，其中包含一个 SKILL.md 文件以及可选的 scripts/ 和 references/ 子目录：

  • SKILL.md 前置元数据包含 name 和 description。代理读取描述以决定何时加载该技能。

  • Markdown 正文包含流程、代码片段、参考表和已知注意事项。仅当您的任务与描述匹配时，代理才会读取正文。

  • scripts/ 包含技能调用的可运行辅助脚本；references/ 包含技能链接到的更长的参考资料。

支持技能的代理通过仓库根目录中的指针文件发现技能：

代理

发现机制

Cursor

.cursor/rules/agent_skills.mdc 将代理指向 skills/ 下的每个 SKILL.md。

Claude Code

CLAUDE.md 和 .claude/skills/ 下的符号链接向原生技能发现机制暴露了相同的技能。

Codex CLI 和其他支持 AGENTS.md 的工具

AGENTS.md 指示代理在会话开始时读取 skills/ 下的每个 SKILL.md。

该库分为两层：

层级

用途

仓库原生

构建、测试、调试和分析此 Isaac Sim 源代码仓库。这些技能调用仓库内的工具（build.sh、tools/、基准测试脚本、python_server 套接字），因此在源代码构建工作流中最有用。

机器人仿真

作为下游用户构建、渲染和验证 Isaac Sim 仿真。这些技能通过 Python 脚本驱动已构建的 Isaac Sim（SimulationApp、isaacsim.core.experimental.*、USD 编写），因此适用于以下所有三种工作流。


可用技能#

下表列出了随 Isaac Sim 提供的技能。包含技能间组合顺序的分类索引位于 skills/SKILLS.md（在 GitHub 上查看）。

仓库原生技能#

技能

功能说明

isaac-sim-installation

通过独立归档文件、Docker 镜像或 Python 包安装公共 Isaac Sim 构建版本，包含系统预检、兼容性检查、审批和预热门控。报告安装位置而不启动主应用程序。

isaac-sim-remote

通过 isaacsim.code_editor.python_server 传输控制协议 (TCP) 套接字驱动正在运行的 Isaac Sim：运行代码、打开阶段、检查或修改 prim、截取屏幕截图、步进物理模拟并读取控制台日志。支持无头模式。

profile-isaac-sim

使用仓库内的基准测试脚本和 Tracy 对 Isaac Sim 进行性能分析和优化。比较运行结果，对比帧时间差异，并隔离热点区域。

validation-diff-gifs

生成像素差异 GIF，将验证捕获与黄金数据进行对比——这是快速排查基准测试图像失败原因的最快方法。

meta-skills

组合模式与元技能框架。首先阅读此部分以了解如何导航、组合和编写技能。

isaac-sim-validator

isaac-sim-troubleshooting

大型通用场景描述 (USD) 阶段的挂起、冻结和性能参考。

合成数据生成#

技能

功能说明

actor-sdg-sweep-config

生成确定性的、经过模式验证的 Actor SDG 配置变体，并可选择以顺序批处理模式预览或运行这些变体。

data-collection-sim

使用标准写入器进行静态场景 Replicator 合成数据生成。

action-and-event-data-generation

Action 和 Event Data Generation 参考应用程序的入口点：包括扩展堆栈、启动器、配置版本规则、阶段排序以及路由到各个专注的子技能。

vlm-scene-captioning

使用 Isaac Sim Replicator Caption (IRC) 扩展生成用于视觉语言模型 (VLM) 训练的图像-字幕对和场景图——可独立运行，通过 CaptionAPI Python 接口运行，或作为 Actor 或对象合成数据运行中的逐帧写入器。

behavior-tree-generation

使用由大型语言模型 (LLM) 驱动的 omni.ai.behavior_tree_gen 规划器，通过用户界面或脚本化应用程序编程接口 (API)，将自然语言场景转换为行为树输出。

generate-incident-config

编写并验证 Isaac Sim Replicator Incident (IRI) 事件配置文件，该文件定义倾倒、火灾和泄漏事件、其目标物品及其触发器。

run-incident-events

通过 isaacsim.replicator.incident.core Python 应用程序编程接口 (API) 标记场景物品并在已加载的阶段上驱动 IRI 事件，然后记录事件报告。

object-bin-packing

使用 Isaac Sim Replicator Object (IRO) 的 bin_pack 协调器，将箱子、包裹和纸箱密集打包到料箱、托盘或容器中并渲染结果。以重力稳定方式放置物品，确保没有物品悬浮，并支持部分装载的料箱。

配置环境#

设置分为两部分：使技能对您的智能体可见，并定义技能所依赖的环境变量契约。

步骤 1：定位技能并将其暴露给您的智能体#

技能随每次安装一同提供。其位置取决于您的工作流：

工作流

技能位置

源代码构建

<repo>/skills/（并镜像到构建输出中的 $ISAAC_SIM_DIR/skills）。

Pip 包

<isaacsim package>/skills/。使用 pip show isaacsim 查找包目录。

二进制包

位于安装根目录下的 $ISAAC_SIM_DIR/skills/。

每次安装还会在 skills/ 旁边捆绑 AGENTS.md 和 CLAUDE.md 指针指南（位于仓库根目录、安装根目录或 isaacsim 包目录中）。这些指南指示代理读取 skills/ 下的 SKILL.md 文件。

通过以下任一方式将技能暴露给你的代理：

  • 源码构建 — 将仓库作为代理的工作区根目录打开。指针文件（AGENTS.md、CLAUDE.md 和 .cursor/rules/agent_skills.mdc）会自动加载技能。

  • Pip 或二进制安装 — 将包含 skills/、AGENTS.md 和 CLAUDE.md 的目录作为代理的工作区根目录打开：Cursor 和 Codex CLI 读取 AGENTS.md，而 Claude Code 读取 CLAUDE.md。或者，将 skills/ 复制或符号链接到你自己的项目中，将其链接到代理的技能目录（例如 ~/.claude/skills/），或者指示代理读取该路径下的 SKILL.md 文件。

注意

发布的包包含公共技能目录、SKILLS.md 索引以及公共的 AGENTS.md 和 CLAUDE.md 指南。.cursor/rules/ 下的 Cursor 规则未捆绑，但 AGENTS.md 对于 Cursor 来说已经足够。skills/_internal 下的仅开发技能未打包。

从源代码构建#

当您开发 Isaac Sim 本身或需要仓库原生技能时，请使用此工作流。

  1. 克隆并构建仓库（Linux 上使用 ./build.sh，Windows 上使用 build.bat）。

  2. 将 ISAAC_SIM_DIR 设置为构建输出：<repo>/_build/linux-x86_64/release。

  3. 在您的代理中打开仓库。所有技能都会加载，包括依赖于仓库内基准测试和验证工具的仓库原生 profile-isaac-sim 和 validation-diff-gifs 技能。

  4. 使用 ./python.sh path/to/script.py 运行脚本，或通过 Python server 驱动正在运行的实例。

Pip 包#

当您将 Isaac Sim 作为 Python 包安装到虚拟环境中时，请使用此工作流。

  1. 按照使用 PIP 安装 Isaac Sim中的说明安装这些包，例如 pip install "isaacsim[all,extscache]==6.1.0.0" --extra-index-url https://pypi.nvidia.com。isaacsim 包捆绑了 skills/ 目录。

  2. 将 ISAAC_SIM_DIR 设置为 pip 安装位置。使用 pip show isaacsim 查询该位置。技能位于 $ISAAC_SIM_DIR/skills。

  3. 按照配置您的环境中所述，将捆绑的技能暴露给您的代理。

  4. 使用虚拟环境的 python 运行脚本，或使用 isaacsim 入口点启动体验。robotics-sim 技能可直接应用；由于 repo-native 剖析和验证技能期望源代码树，因此其功能受限。

二进制包#

当您安装预打包的二进制构建版本时，请使用此工作流。

  1. 按照下载 Isaac Sim和工作站安装中的说明下载并安装二进制文件。二进制文件在安装根目录中捆绑了 skills/ 目录。

  2. 将 ISAAC_SIM_DIR 设置为安装根目录（例如，~/isaacsim）。技能位于 $ISAAC_SIM_DIR/skills。

  3. 按照配置您的环境中所述，将捆绑的技能暴露给您的代理。

  4. 在 Linux 上使用 ./isaac-sim.sh 或在 Windows 上使用 isaac-sim.bat 启动应用，并在 Linux 上使用 ./python.sh 或在 Windows 上使用 python.bat 运行脚本。与 pip 工作流一样，robotics-sim 技能直接适用，而 repo-native 技能则受到限制。


安全性#

诸如 isaac-sim-remote 之类的技能会在正在运行的 Kit 进程内执行任意 Python 代码，该进程拥有完整的文件系统和网络访问权限。代理的工具允许列表仅约束代理自身的文件工具；它无法限制在进程内运行的 Python 代码。

  • 仅在您信任代理可以操作的环境中运行由技能驱动的代理。围绕 Isaac Sim 进程建立的操作系统沙箱（限制文件系统和网络出口）才是真正的安全边界。

  • 保持 isaacsim.code_editor.python_server host 设置绑定到 127.0.0.1。将其绑定到 0.0.0.0 会使网络上的任何机器都能在你的会话中执行任意 Python 代码。请参阅 Python Server (Remote Code Execution)。
