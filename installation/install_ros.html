ROS 2 安装#

NVIDIA Isaac Sim 提供了一个 ROS 2 桥接器，用于 ROS 系统集成。模拟器使用同一组通用组件来定义发布和接收的数据类型。

Isaac Sim 支持的 ROS 发行版如下：

平台

ROS 发行版

ROS 安装说明

Ubuntu 24.04

Jazzy（推荐）

默认 Linux 安装

Ubuntu 22.04

Humble

使用默认安装（Python 3.10）。 使用 ROS 2 工作区的 Python 3.12 构建版本，以便在 Isaac Sim 中使用自定义 ROS 接口。

Ubuntu 22.04

Jazzy

从源码构建（Python 3.10）。 使用 ROS 2 工作区的 Python 3.12 构建版本，以便在 Isaac Sim 中使用自定义 ROS 接口。

Windows 11

Humble

WSL 安装（已弃用）。不支持自定义 ROS 接口。

Windows 11

Jazzy

Pixi：基于 Pixi 的原生 ROS 安装。Isaac Sim 可以直接加载 Pixi ROS 安装。 WSL（已弃用）：不支持自定义 ROS 接口。

对于 ROS 2 桥接器，Isaac Sim 兼容 ROS 2 Humble 和 ROS 2 Jazzy。

注意

实验性功能：原生 ROS 2 发行版支持 – Isaac Sim 现在实验性地支持加载在您的平台（Ubuntu 22.04 或 Ubuntu 24.04）上原生安装的任何 ROS 2 发行版。要使用此功能，请在同一终端中加载您本地安装的 ROS 2 发行版并启动 Isaac Sim。虽然 Humble 和 Jazzy 仍然是官方测试和推荐的发行版，但其他原生支持的发行版可能也能通过此工作流运行。

    sudo apt install ros-jazzy-vision-msgs

注意

目前，基于 Pixi 的原生 ROS 2 安装仅支持 ROS 2 Jazzy。请选择 Jazzy 作为您的 ROS 2 发行版，或切换至 WSL2 安装方法以使用 Humble。

使用 WSL2 在 Windows 上运行 ROS 2，该方式通过内部 ROS 2 库与 Isaac Sim ROS Bridge 进行通信。

  1. 在您的 Windows 机器上安装 WSL2。

  2. 以管理员权限打开 PowerShell，并将 WSL 版本更改为 2。

    wsl --set-default-version 2

  3. 在 WSL 中安装 Ubuntu 22.04 发行版。

    wsl --install -d Ubuntu-22.04

  4. 安装完成后，重启计算机并在 Windows 中打开 Ubuntu 22.04 应用。安装过程需要几分钟时间。

    注意

    如果在启用虚拟化时遇到错误，请遵循 Windows 虚拟化启用指南。

  5. 在 WSL2 中安装 Ubuntu 22.04 后，请按照官方网站上的说明下载 ROS 2：

    • ROS 2 Humble Ubuntu 22.04

  6. （可选）ROS 2 Bridge 中的某些消息类型（Detection2DArray 和 Detection3DArray，用于发布边界框）依赖于 vision_msgs_package。运行以下命令在您的系统上安装该包。如果您是从源代码构建 ROS 2，请在重新构建之前克隆该包并将其包含在您的 ROS 2 安装工作空间中。如果您不需要运行 vision_msgs 发布者，可以跳过此步骤。

    sudo apt install ros-humble-vision-msgs

  7. （可选）ROS 2 Bridge 中的某些消息类型（AckermannDriveStamped，用于发布和订阅 Ackermann 转向命令）依赖于 ackermann_msgs_package。运行以下命令在您的系统上安装该包。如果您是从源代码构建 ROS 2，请在重新构建之前克隆该包并将其包含在您的 ROS 2 安装工作空间中。如果您不需要运行 ackermann_msgs 发布者或订阅者，可以跳过此步骤。

    sudo apt install ros-humble-ackermann-msgs

  8. 确保在终端或您的 WSL2 ~/.bashrc 文件中加载了 ROS 环境。每次使用任何 ROS 命令之前，都必须执行此步骤：

    source /opt/ros/humble/setup.bash

  9. ROS 2 安装完成后，打开 WSL2 并运行以下命令以获取 WSL2 的 IP 地址：

    hostname -I

  10. 以管理员身份打开 Powershell 并运行以下命令以获取 Windows 主机的 IPv4 地址：

    ipconfig /all

  11. 在 Powershell 中根据相应的 IP 地址设置变量：

    $Windows_IP = "<WINDOWS_IP>"
$WSL2_IP = "<WSL2_IP>"

  12. 在 Powershell 中为 ROS 中默认 DDS (FastDDS) 使用的特定端口设置端口转发：

    netsh interface portproxy add v4tov4 listenport=7400 listenaddress=$Windows_IP connectport=7400 connectaddress=$WSL2_IP
netsh interface portproxy add v4tov4 listenport=7410 listenaddress=$Windows_IP connectport=7410 connectaddress=$WSL2_IP
netsh interface portproxy add v4tov4 listenport=9387 listenaddress=$Windows_IP connectport=9387 connectaddress=$WSL2_IP

  1. 在您的 Windows 机器上安装 WSL2。

  2. 以管理员权限打开 PowerShell，并将 WSL 版本更改为 2。

    wsl --set-default-version 2

  3. 在 WSL 中安装 Ubuntu 24.04 发行版。

    wsl --install -d Ubuntu-24.04

  4. 安装完成后，重启机器并在 Windows 中打开 Ubuntu 24.04 应用。安装需要一些时间。

    注意

    如果在启用虚拟化时遇到错误，请遵循 Windows 虚拟化启用说明。

  5. 在 WSL2 中安装 Ubuntu 24.04 后，请按照官方网站上的说明下载 ROS 2：

    • ROS 2 Jazzy Ubuntu 24.04

  6. （可选）ROS 2 Bridge 中的某些消息类型（Detection2DArray 和 Detection3DArray，用于发布边界框）依赖于 vision_msgs_package。运行以下命令在您的系统上安装该包。如果您是从源代码构建 ROS 2，请在重新构建之前克隆该包并将其包含在您的 ROS 2 安装工作空间中。如果您不需要运行 vision_msgs 发布者，可以跳过此步骤。

    sudo apt install ros-jazzy-vision-msgs

  7. （可选）ROS 2 Bridge 中的某些消息类型（AckermannDriveStamped，用于发布和订阅 Ackermann 转向命令）依赖于 ackermann_msgs_package。运行以下命令在您的系统上安装该包。如果您是从源代码构建 ROS 2，请在重新构建之前克隆该包并将其包含在您的 ROS 2 安装工作空间中。如果您不需要运行 ackermann_msgs 发布者或订阅者，可以跳过此步骤。

    sudo apt install ros-jazzy-ackermann-msgs

  8. 确保在终端或您的 WSL2 ~/.bashrc 文件中加载了 ROS 环境。每次使用任何 ROS 命令之前，都必须执行此步骤：

    source /opt/ros/jazzy/setup.bash

  9. ROS 2 安装完成后，打开 WSL2 并运行以下命令以获取 WSL2 的 IP 地址：

    hostname -I

  10. 以管理员身份打开 Powershell 并运行以下命令以获取 Windows 主机的 IPv4 地址：

    ipconfig /all

  11. 在 Powershell 中根据相应的 IP 地址设置变量：

    $Windows_IP = "<WINDOWS_IP>"
$WSL2_IP = "<WSL2_IP>"

  12. 在 Powershell 中为 ROS 中默认 DDS (FastDDS) 使用的特定端口设置端口转发：

    netsh interface portproxy add v4tov4 listenport=7400 listenaddress=$Windows_IP connectport=7400 connectaddress=$WSL2_IP
netsh interface portproxy add v4tov4 listenport=7410 listenaddress=$Windows_IP connectport=7410 connectaddress=$WSL2_IP
netsh interface portproxy add v4tov4 listenport=9387 listenaddress=$Windows_IP connectport=9387 connectaddress=$WSL2_IP

RMW_IMPLEMENTATION=rmw_zenoh_cpp 已在 Pixi 工作区配置中永久设置。默认情况下，通过 pixi shell 或 pixi run 启动的所有 ROS 2 节点均启用 Zenoh。

  • 按 Play 按钮。

/clock
/parameter_events
/rosout

    export RMW_IMPLEMENTATION=rmw_zenoh_cpp

    source /opt/ros/jazzy/setup.bash
./isaac-sim.sh

    cd IsaacSim-ros_workspaces/jazzy_ws/src
git clone https://github.com/ros2/rmw_zenoh.git -b jazzy

  3. 使用 Dockerfile 构建包含 Zenoh 的 ROS 2 和工作区（使用 Python 3.12）：

    cd IsaacSim-ros_workspaces

./build_ros.sh -d jazzy -v 22.04

    包含 Zenoh 的已构建工作区位于 build_ws/jazzy/jazzy_ws 下。

  4. 在单独的终端中，启动 Zenoh 路由器。在任何 ROS 2 节点能够相互发现之前，路由器必须处于运行状态。

    使用 在 Docker 容器中运行 ROS 部分中的 Docker 容器。如果您尚未启动 ros_ws_docker 容器，请先按照该部分的步骤操作。然后，在容器内安装 ros-jazzy-rmw-zenoh-cpp 并启动路由器：

    # Inside the ros_ws_docker container
apt-get update && apt-get install -y ros-jazzy-rmw-zenoh-cpp
source /opt/ros/jazzy/setup.bash
export RMW_IMPLEMENTATION=rmw_zenoh_cpp
ros2 run rmw_zenoh_cpp rmw_zenohd

    注意

    如果没有 Zenoh 路由器，节点将无法相互发现，因为节点的会话配置默认禁用了多播发现。相反，节点通过 Zenoh 路由器的 gossip 功能接收关于其他对等体的发现信息。

  5. 在运行 Isaac Sim 之前，请在启动 Isaac Sim 的终端中设置 RMW_IMPLEMENTATION 环境变量。此后，如果任何示例显示将该环境变量设置为 rmw_fastrtps_cpp，您可以将其替换为以下命令：

    export RMW_IMPLEMENTATION=rmw_zenoh_cpp

  6. 源化 jazzy_ws 和 isaac_sim_ros_ws 的 Python 3.12 构建版本，然后运行 Isaac Sim：

    cd IsaacSim-ros_workspaces
source build_ws/jazzy/jazzy_ws/install/local_setup.bash
source build_ws/jazzy/isaac_sim_ros_ws/install/local_setup.bash
cd ~/isaacsim
./isaac-sim.sh

  7. 对于任何需要与 Isaac Sim 通信并运行 ROS 2 节点的额外终端，请在同一个 Docker 容器中打开一个新终端：

    docker exec -it ros_ws_docker /bin/bash -c \
  "source /opt/ros/jazzy/setup.bash && \
   export RMW_IMPLEMENTATION=rmw_zenoh_cpp && \
   cd /jazzy_ws && source install/local_setup.bash && \
   bash"

在 isaac-sim.sh 中禁用 ROS Bridge#

注意

在 Windows 中，ROS Bridge 默认处于禁用状态。

要禁用 ROS bridge，请执行以下步骤：

  1. 打开位于 ~/isaacsim/apps/isaacsim.exp.full.kit 的文件。

  2. 找到 isaac.startup.ros_bridge_extension = "isaacsim.ros2.bridge" 这一行。

  3. 将其更改为 isaac.startup.ros_bridge_extension = "" 以禁用 ROS 2 bridge。

  4. 保存并关闭文件。

在 Docker 容器中运行 ROS#

注意

Windows WSL2 不支持 Docker 工作流。

注意

基于 Pixi 的安装不需要 Docker 工作流。Pixi 工作区原生处理所有依赖项。

  1. 确保您已克隆 Isaac Sim ROS Workspace Repository。

  2. 导航到克隆仓库的根目录并运行以下命令。如果仓库克隆到了其他位置，请确保将 ~/IsaacSim-ros_workspaces 中的路径更新为正确的路径：

    cd ~/IsaacSim-ros_workspaces
git submodule update --init --recursive

  3. 运行相应的 ROS 2 Docker 容器，并从 Isaac Sim ROS Workspaces 仓库挂载相应的工作区。如果仓库克隆到了其他位置，请确保将 -v ~/IsaacSim-ros_workspaces 中的路径更新为正确的路径。

    xhost +

docker run -it --net=host --env="DISPLAY" --env="ROS_DOMAIN_ID" -v ~/IsaacSim-ros_workspaces/humble_ws:/humble_ws --name ros_ws_docker osrf/ros:humble-desktop /bin/bash

    xhost +

docker run -it --net=host --env="DISPLAY" --env="ROS_DOMAIN_ID" -v ~/IsaacSim-ros_workspaces/jazzy_ws:/jazzy_ws --name ros_ws_docker osrf/ros:jazzy-desktop /bin/bash

    xhost +

docker run -it --net=host --env="DISPLAY" --env="ROS_DOMAIN_ID" -v ~/IsaacSim-ros_workspaces/jazzy_ws:/jazzy_ws --name ros_ws_docker arm64v8/ros:jazzy /bin/bash

    此处 --net=host 允许 Isaac Sim 与 ROS Docker 容器之间进行通信，而 xhost + 和 --env="DISPLAY" 用于传递 DISPLAY 环境变量，这使得 rviz 等 GUI 应用程序能够从 Docker 容器中打开。--name <container name> 允许您使用固定名称来引用该容器。

  4. 在 Docker 容器内导航至 ros 工作区。

    cd /${ROS_DISTRO}_ws

  5. 在 Docker 容器内，按照使用 Fast DDS 启用 ROS 2 桥接中的说明设置 FASTRTPS_DEFAULT_PROFILES_FILE 环境变量。

  6. 要安装其他依赖项、构建工作区，并在构建完成后加载工作区环境：

    cd /${ROS_DISTRO}_ws
apt-get update
git submodule update --init --recursive # If using Docker, perform this step outside the container and relaunch the container
rosdep install --from-paths src --ignore-src --rosdistro=$ROS_DISTRO -y
source /opt/ros/$ROS_DISTRO/setup.sh
colcon build
source install/local_setup.bash

  7. 如果需要打开新终端，请打开现有的 Docker 容器：

    docker exec -it ros_ws_docker /bin/bash -c 'source /opt/ros/$ROS_DISTRO/setup.bash; exec bash'

  8. 可选地，若要测试安装情况，您可以使用 Isaac Sim OmniGraph 教程 中的 OmniGraph 节点，在 Isaac Sim 中设置一个基本的时钟发布器：

    1. 在模拟器中按下 play。

    2. 打开一个单独的终端，进入 Docker，设置 FASTRTPS_DEFAULT_PROFILES_FILE 环境变量。

    3. 加载 ROS 2 环境。

    4. 验证 ros2 topic echo /clock 是否打印来自 Isaac Sim 的时间戳。

  9. （可选）若要将包含所有已安装依赖项和已构建工作区的容器保存为新的 Docker 镜像以供将来使用：

    1. 在主机上打开一个新终端，并将容器提交为镜像：

      docker commit ros_ws_docker isaac_sim_ros_ws:latest

    2. 在启动同名新容器之前，先移除旧容器：

      docker rm ros_ws_docker

    3. 若要在未来的会话中复用已保存的镜像，请从该镜像启动一个新容器：

      xhost +

docker run -it --net=host --env="DISPLAY" --env="ROS_DOMAIN_ID" -v ~/IsaacSim-ros_workspaces/humble_ws:/humble_ws --name ros_ws_docker isaac_sim_ros_ws:latest /bin/bash

      xhost +

docker run -it --net=host --env="DISPLAY" --env="ROS_DOMAIN_ID" -v ~/IsaacSim-ros_workspaces/jazzy_ws:/jazzy_ws --name ros_ws_docker isaac_sim_ros_ws:latest /bin/bash

    4. 在容器内，加载工作区环境，即可直接使用而无需重新构建：

      source /opt/ros/$ROS_DISTRO/setup.bash
cd /${ROS_DISTRO}_ws
source install/local_setup.bash
